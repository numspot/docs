# Decision Log

> **Single source of truth for decisions taken across documentation sessions** (AI coding agents, maintainer reviews). `AGENTS.md` stays the operational rulebook (what to do); this file records **what was decided and why**. Problems & their guards live in [`PROBLEMS.md`](PROBLEMS.md). Newest first — add a row whenever a session takes a lasting decision. Some historic IDs are absent: they record decisions that belong to Numspot's internal tooling, not to this public repository.

| D-023 | 2026-10-13 | The site search gains a **query language** and **bilingual FR/EN synonym expansion**, implemented query-side only in `numspotSearch.js` (injected into `docusaurus-search-local` by the patch-package patch, required by the worker): an input carrying an operator (`+`/`-`, `AND`/`OR`/`NOT`, quoted phrases, `*`, `~N`, `title:`) bypasses the stock smart-query combinatorics and runs deterministic lunr clauses; a plain input keeps the stock behavior and gains a **stemmed recall query** plus bounded extra synonym union queries (boost 0.5). Browser testing revealed a stock defect on the `word*` operator path: lunr runs **no pipeline on wildcard clauses**, so a raw wildcard can only match stems at or longer than itself (`template*` could never reach the indexed stem `templat`) — the fix stems prefixes through a replica of the index pipeline; plain complete words already matched (their exact/fuzzy clauses run through the query pipeline) and the plain-path stemmed query is kept as harmless extra recall. Quoted phrases and synonym members are split and stopword-filtered through the index tokenizer: a REQUIRED clause on an index-removed stopword (`de`) voids the whole lunr query, and a stopword lookup key polluted unrelated French queries (see PROBLEMS.md). The 100-item list cap stays, but a capped list must never read as complete, hence the "> N" label. The grammar is documented in a popover next to the search field (a one-line hint on the /search page was tried first and replaced: it is less precise and the navbar popover is visible everywhere, not only on the results page). `SEARCH.md` documents the grammar |
