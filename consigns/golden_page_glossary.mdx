# Glossary

This glossary has been designed to give you a clear and concise understanding of the key terms used in the cloud field, making it easier for you to navigate and use it.

## A

<!-- H2 = letter. Alphabetical order within the section, case-insensitive. -->

#### Access Control List (ACL)

<!-- H4 = term. Full name first, acronym in parentheses at first
     occurrence — the reverse of body pages, where the acronym comes
     first and expands once. Here the term IS the entry. -->

Reference to granular permissions, which specify which users or system processes have access to a given object or resource, as well as the operations they are authorized to perform.

#### Application Programming Interface (API)

A set of rules and protocols that allows different software applications to communicate with each other, making it easier to exchange data and functionality.  
Find out more: [What is an API? | api.gouv.fr](https://api.gouv.fr/guides/api-definition)

## B

#### Block Storage

<!-- "Find out more:" links only to public, vendor-neutral references. -->

A data storage system that divides information into fixed-size blocks, each with a unique address, enabling fast and efficient access.
