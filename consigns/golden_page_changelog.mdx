<!--
  GOLDEN PAGE — reference entry for the changelogs (English version).

  The changelog tells END USERS what is new or different in the products
  and services Numspot documents — never what happened inside the docs
  project. Two files, kept ISO in the same commit:

    - English (source of truth): docs/docs/changelog.json
    - French: i18n/fr/docusaurus-plugin-content-docs/current/docs/changelog.json

  Timing (D-007): entries land WHEN THE PAGES BECOME PUBLIC — one
  consolidated entry per PR, written in the PR that ships the change,
  never one per unit commit.

  Scope (D-006): product and service changes ONLY.
    ✅ new service/feature/capability documented, page or section
       added/modified/deleted for a product, product renames, content
       corrections that change product facts
    ❌ linter rules and tests, CI, build/deps, i18n plumbing, internal
       scripts, site UI and cosmetics, meta announcements about the docs

  Enforcement: linter/tests/changelog-sync.test.js (FR/EN alignment),
  changelog-format.test.js (canonical serialization, D-020),
  changelog-scope.test.js (product scope).

  Do not route this file; mirror the structure below instead.
-->
