# Increase the size of a volume

You can increase the storage capacity of an existing `volume` without losing the data stored on it.

You can modify the size of any type of `volume`, whether it is a system `volume` on which the operating system of the [VM (Virtual Machine)](/docs/compute/concept/) is installed, or a secondary `volume` of the VM.

:::info
The modification works whether the `volume` is attached to a running VM (**hot** modification) or not (**cold** modification). It is asynchronous: the API returns the previous value and a `taskId`, and the new size is applied within a few seconds to a few minutes. You can check the current size of the `volume` at any time from the **Volumes** dashboard or with the `ReadVolumes` method. You can only increase the size of a `volume`: it is not possible to reduce it.
:::

:::warning
Before modifying a `volume`, we recommend that you create a [snapshot](/docs/storage/block-storage/snapshots/actions/create/) of it, in case a problem occurs during the process.
:::

## Change the volume tier

You can also change the **tier** of a `volume` (Magnetic, Performance or Enterprise) at any time, whether the `volume` is attached to a running VM or not:

1. From the left-hand side menu, click **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Select the `volume` and click **Modify** (or **Change tier**).
3. In the "Type" field, select the new tier.
4. If you select **Enterprise**, you must also set the number of **IOPS** (from `100` to `13,000`, with a maximum performance ratio of 300 IOPS per GB).
5. Click **Modify**.

The `volume` is then modified with the performance characteristics and the billing of the new tier. For more information, see the [catalog](/docs/catalog/concepts/).

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.blockStorage.update**

:::

## Linux {#tabhead-linux}

### Increase the size of a volume

1. From the left-hand side menu, click **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Select the `volume`.
3. Click **Modify**.
4. In the "Size" field, enter the new size of the `volume` (greater than the current size).
5. Click **Modify**.

    The modification is asynchronous: the new size is applied within a few seconds to a few minutes, whether the `volume` is attached to a running VM or not.

### Extend the file system inside the VM

The platform-side modification does not extend the file system of the `volume`. Inside the VM:

1. (optional) To display the block devices and their sizes, run the following command:
    ```bash
    $ lsblk
    ```
2. If the `volume` uses a partition table, grow the partition (example for the first partition of the device):
    ```bash
    $ sudo growpart /dev/DEVICE_NAME 1
    ```
3. Resize the file system:
    - To resize an ext4 file system, run the following command:
    ```bash
    $ sudo resize2fs /dev/DEVICE_NAME
    ```
    - To resize an XFS file system, run the following command:
    ```bash
    $ sudo xfs_growfs /MOUNT_POINT
    ```
4. (optional) Run the `df -hT` command to view the sizes of your file systems.

The file system of the `volume` is configured.

:::info
For VM created from an Image, the cloud-init package automatically adjusts the file system of the system `volume` at the next boot after its size has been modified. For more information, see the official cloud-init documentation (in English).
:::

## Windows {#tabhead-windows}

### Increase the size of a volume

1. From the left-hand side menu, click **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Select the `volume`.
3. Click **Modify**.
4. In the "Size" field, enter the new size of the `volume` (greater than the current size).
5. Click **Modify**.

    The modification is asynchronous: the new size is applied within a few seconds to a few minutes, whether the `volume` is attached to a running VM or not.

### Extend the file system inside the VM

1. Connect to your VM.
2. Click the **Start** menu, type "diskmgmt.msc" and click the program that appears.
3. Right-click the `volume` and select **Extend Volume**.

    The **Extend Volume Wizard** appears.

4. Keep the default information and click **Next**.
5. Click **Finish** to confirm.

    The `volume` is configured and its file system appears in the "Disk Management" list.
