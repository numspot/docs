# Create a DHCP options set

You can create a [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/) options set to associate with a [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/). You can specify one or more NTP (Network Time Protocol) servers and DNS (Domain Name System) servers to use, along with a corresponding domain name.

Numspot automatically provides a default DHCP options set. However, you can create as many custom sets as you want.

You can associate a DHCP options set with a VPC to customize the DHCP configuration used with the [VM (Virtual Machine)](/docs/compute/concept/) created in that VPC.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.dhcpOptions.create**

:::

<Tabs>
<TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **DHCP Options** to access the list of DHCP options sets.
2. Click the **Create DHCP options** button.
3. (Optional) In the "Domain name" field, enter the domain name of the DHCP options set. Leave the field empty to use the Numspot domain name.
4. In the "Domain name servers" list, select:
   - "Continue with a default DNS" to use the Numspot domain name;
   - "Select one or more DNS" to use a custom domain name.
5. Specify at least one of the following values:
   - (Optional) In the "NTP servers" field, enter the IP (Internet Protocol) addresses of one or more NTP servers;
   - (Optional) In the "Log servers" field, enter the IP addresses of one or more log servers.
6. Click **Next**.
7. Review the settings of the DHCP options set.
8. Click **Create**.

A confirmation message appears at the bottom of the page indicating that the DHCP options set has been created.

:::warning
Specifying the same information as an existing DHCP options set creates a new set with a different ID.
:::

</TabItem>
