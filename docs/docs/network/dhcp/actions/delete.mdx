# Supprimer un groupe d'options DHCP

Vous pouvez supprimer un groupe d'options [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/) dont vous n'avez plus besoin. Celui-ci ne doit être associé à aucun [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/).

Vous ne pouvez pas supprimer le groupe d'options DHCP par défaut.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.dhcpOptions.delete**

:::

## Prérequis

:::info
## Avant de commencer

Dissociez le groupe d'options DHCP de tous les VPC auxquels il est associé. Pour ce faire, effectuez l'une des actions suivantes pour chaque VPC :

- Associez le VPC à un autre groupe d'options DHCP. Pour plus d'informations, consultez la section [Modifier le groupe d'options DHCP associé à un VPC ↗](./update.mdx) ;
- Supprimez le VPC et ses ressources associées.
:::

## Console {#tabhead-console}

La suppression d'un groupe d'options DHCP n'est pas disponible depuis la Console. Utilisez l'API ou Terraform.

</TabItem>
<TabItem value="api" label="API">

## API {#tabhead-api}


La commande `DELETE /compute/spaces/{spaceId}/dhcpOptions/{id}` supprime un ensemble d'options DHCP spécifié.

Avant de supprimer un ensemble d'options DHCP, vous devez le dissocier des réseaux auxquels il est associé. Pour ce faire, associez à chaque réseau un nouvel ensemble d'options DHCP ou l'ensemble par défaut.

[Exemple de requête : Suppression d'un ensemble d'options DHCP ↗](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/dhcpOptions/{id})
