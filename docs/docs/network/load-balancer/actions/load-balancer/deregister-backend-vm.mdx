# Deregister a VM from a load balancer

You can detach one or more backend [VM](/docs/compute/concept/) (Virtual Machine) from a [load balancer](/docs/network/load-balancer/concepts/) when you no longer need them to receive traffic from it.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.update**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer from which you want to deregister a VM.
3. In the "Backend VM" tab, identify the VM to deregister.
4. Click the **Remove** button next to the VM.
5. Confirm the deletion.
   The VM is deregistered from the load balancer.

  </TabItem>
  <TabItem value="api" label="API">

The `PUT /compute/spaces/{spaceId}/loadBalancers/{id}/backendMachines/unlink` command detaches one or more backend VM from a load balancer. You must specify at least the `backendIps` or `backendVmIds` parameter.

[Example request: Detach a VM from a load balancer](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/loadBalancers/{id}/backendMachines/unlink)
  </TabItem>
  <TabItem value="terraform" label="Terraform">

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/load_balancer).

  </TabItem>
