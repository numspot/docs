# Obtenir des informations sur vos load balancers

Vous pouvez consulter les informations concernant un ou plusieurs [load balancer (équilibreurs de charge)](/docs/network/load-balancer/concepts/) dans votre espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.loadBalancer.get**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Load Balancers** pour accéder à la liste des load balancers.
2. La liste affiche les informations de chaque load balancer : nom, ID, type, état, [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) associé, etc.

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/loadBalancers` permet de lister vos load balancers.

[Exemple de requête : Lister tous vos load balancers](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/loadBalancers)

La commande `GET /compute/spaces/{spaceId}/loadBalancers/{id}` permet de récupérer des informations concernant un load balancer.

[Exemple de requête : Récupérer les informations d'un load balancer](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/loadBalancers/{id})
