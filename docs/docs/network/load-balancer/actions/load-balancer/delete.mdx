# Delete a load balancer

You can delete a [load balancer](/docs/network/load-balancer/concepts/) that you no longer need.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.loadBalancer.delete**

:::

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer you want to delete.
3. Click **Delete** in the list of actions.
4. Confirm the deletion.

The load balancer is deleted.

:::info
Before you begin: Ensure that the [security groups](/docs/compute/security-groups/concepts/concept-sg/) of your backend [VM](/docs/compute/concept/) (Virtual Machine) allow traffic from a source other than the load balancer.
:::

The `DELETE /compute/spaces/{spaceId}/loadBalancers/{id}` command deletes a specified load balancer.

[Example request: Deleting a load balancer](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/loadBalancers/{id})
