# Supprimer un load balancer

Vous pouvez supprimer un [load balancer (équilibreur de charge)](/docs/network/load-balancer/concepts/) dont vous n'avez plus besoin.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.loadBalancer.delete**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Load Balancers** pour accéder à la liste des load balancers.
2. Sur la ligne du load balancer à supprimer, ouvrez le menu **Actions**, puis cliquez sur **Supprimer**.
3. Une confirmation forte est requise : saisissez le nom du load balancer dans le champ, puis cliquez sur **Supprimer le Load Balancer**.

Le load balancer est supprimé.

## API {#tabhead-api}


:::info
Avant de commencer : Assurez-vous que les [security group (groupes de sécurité)](/docs/compute/security-groups/concepts/concept-sg/) de vos [VM (Virtual Machine)](/docs/compute/concept/) de backend autorisent les flux provenant d'une autre source que le load balancer.
:::

La commande `DELETE /compute/spaces/{spaceId}/loadBalancers/{id}` supprime un load balancer spécifié.

[Exemple de requête : Suppression d'un load balancer](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/loadBalancers/{id})
