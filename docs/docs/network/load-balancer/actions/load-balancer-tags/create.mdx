# Add or remove tags on a load balancer

You can add or remove tags associated with a [load balancer](/docs/network/load-balancer/concepts/) to organize and identify your resources.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.update**

:::

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer for which you want to manage the tags.
3. In the "Tags" tab, click **Add a tag** or the delete button next to an existing tag.
4. Enter the key and the value of the tag, then click **Add**.

  </TabItem>
  <TabItem value="api" label="API">

The `PATCH /compute/spaces/{spaceId}/bulk/loadBalancersTags` command adds one or more tags to the specified load balancer. If a tag with the same key already exists for the load balancer, the value of the tag is replaced.

[Example request: Adding tags to the load balancer ↗](/openapi/#tag/compute/PATCH/compute/spaces/{spaceId}/bulk/loadBalancersTags)
