# Get information about the tags associated with your load balancers

You can view the tags associated with your [load balancers](/docs/network/load-balancer/concepts/) to identify and organize your resources.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.get**

:::

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer for which you want to view the tags.
3. In the "Tags" tab, the list of tags associated with the load balancer is displayed.

The `GET /compute/spaces/{spaceId}/loadBalancersTags` command lists the tags associated with a specified load balancer.
