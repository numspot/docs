# Update a load balancer listener rule

You can update a traffic redirection rule of a [load balancer](/docs/network/load-balancer/concepts/) listener to adjust the redirection conditions or actions.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.update**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer containing the rule to update.
3. In the "Listeners" tab, click the listener containing the rule.
4. In the "Rules" section, identify the rule to update and click **Edit**.
5. Update the rule parameters as required.
6. Click **Save**.
   The rule is updated.

  </TabItem>
  <TabItem value="api" label="API">

The `PUT /compute/spaces/{spaceId}/listenerRules/{id}` command updates the listener rule pattern. This call updates the pattern-matching algorithm for inbound traffic.

[Example request: Updating a rule for a Listener](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/listenerRules/{id})
