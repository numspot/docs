# Add a rule to a load balancer listener

You can add a traffic redirection rule to a [load balancer](/docs/network/load-balancer/concepts/) listener to direct requests to different backend [VM](/docs/compute/concept/) (Virtual Machine) based on defined criteria.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.create**

:::

<Tabs>
<TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer for which you want to add a rule.
3. In the "Listeners" tab, click the listener to which you want to add a rule.
4. In the "Rules" section, click **Add a rule**.
5. Configure the rule parameters (priority, conditions, actions).
6. Click **Create**.

   The rule is added to the listener.

</TabItem>
<TabItem value="api" label="API">

The `POST /compute/spaces/{spaceId}/listenerRules` command creates a traffic redirection rule for the specified listener. Each rule must specify either the "hostNamePattern" or the "pathPattern" parameter. Rules are processed in order of priority, from the highest value to the lowest.

Once the rule is created, you must register backend VM with this rule.

[Example request: Creating a rule for a listener ↗](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/listenerRules)

</TabItem>
