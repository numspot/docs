# Delete a rule from a load balancer listener

You can delete a traffic redirection rule from a [load balancer](/docs/network/load-balancer/concepts/) listener that you no longer need.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.delete**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer containing the rule to delete.
3. In the "Listeners" tab, click the listener containing the rule.
4. In the "Rules" section, identify the rule to delete and click **Delete**.
5. Confirm the deletion.
   The rule is deleted from the listener.

  </TabItem>
  <TabItem value="api" label="API">

The `DELETE /compute/spaces/{spaceId}/listenerRules/{id}` command deletes a listener rule.

The rule that was previously active is disabled after the deletion.

[Example request: Deleting a rule for a Listener](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/listenerRules/{id})
