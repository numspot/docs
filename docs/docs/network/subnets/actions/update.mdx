# Modifier un attribut d'un subnet

Vous pouvez modifier un attribut d'un subnet (sous-réseau) : l'attribut `mapPublicIpOnLaunch`.

Cet attribut détermine si une IP (Internet Protocol) publique est attribuée automatiquement aux interfaces réseau créées dans le subnet, y compris les interfaces réseau créées lorsque vous lancez une [VM (virtual machine)](/docs/compute/concept/) dans un subnet. Il est désactivé par défaut.

Pour connaître le comportement de l'IP publique ainsi attribuée, consultez [À propos des IP publiques](/docs/network/public-ip/concepts/).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.subnet.update**

:::

 1. Connectez-vous sur la console Numspot.
 2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **[VPC](/docs/network/vpc/concepts/)** → **VPC**.
 3. La liste des VPC apparaît. Cliquez sur l'ID du VPC concerné.
 4. La page "Détails VPC" apparaît.
 5. En dessous des détails du VPC apparaît la section "Subnets" dans laquelle se trouve la liste des subnets associés au VPC.
 6. Sur la page détaillée du VPC, identifiez le subnet depuis la section "Subnets". Dans cette section, vous avez la possibilité de :  
     \- gérer les `tags`  
     \- ajouter et modifier la [Route Table](/docs/network/route-table/concepts/) associée

 :::info
 En cliquant sur le bouton **Modifier**, vous pouvez activer ou désactiver l'attribut `mapPublicIpOnLaunch` du subnet, qui attribue automatiquement une IP publique aux interfaces réseau créées dans celui-ci, y compris lorsque vous lancez une VM dans le subnet.
