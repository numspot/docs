# Obtaining information about your subnets

You can obtain information about one or several of your subnets, such as the [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) they belong to, their CIDR (Classless Inter-Domain Routing) block or their Sub-region.

Information about your subnets is also available from the [VM (Virtual Machines)](/docs/compute/concept/) themselves.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.subnet.get**

:::

 1. Log in to the Numspot console.
 2. From the left-hand side menu, click **Network** → **VPC** → **VPC**.

     
 3. The list of VPC appears. Click the ID of the relevant VPC.
 4. The "VPC details" page appears.
 5. Below the VPC details, the "Subnets" section appears, containing the list of subnets associated with the VPC.

  <TabItem value="API">

The `GET /compute/spaces/{spaceId}/subnets` command lists the subnets.

[Request example: List all subnets](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/subnets)

The `GET /compute/spaces/{spaceId}/subnets/{id}` command retrieves the information of a specified subnet.

[Request example: Retrieve the information of a subnet](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/subnets/{id})
