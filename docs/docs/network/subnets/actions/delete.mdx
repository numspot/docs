# Delete a subnet

You can delete an empty subnet that you no longer need. This action does not delete the [route table](/docs/network/route-table/concepts/) and the [security groups](/docs/compute/security-groups/concepts/concept-sg/) used for this subnet.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.subnet.delete**

:::

:::info
**Prerequisite:** All the [VM (Virtual Machines)](/docs/compute/concept/) that are in the subnet must be deleted.
:::

1.  Log in to the Numspot console.
2.  From the left-hand side menu, click **Network** → **[VPC](/docs/network/vpc/concepts/)** → **VPC**.
3.  The list of VPC appears. Click the ID of the relevant VPC.
4.  The "VPC details" page appears.
5.  Below the VPC details, the "Subnets" section appears, containing the list of subnets associated with the VPC.

6.  Identify the subnet that you want to delete by clicking the **Delete** button.

7.  A confirmation message appears at the bottom indicating that the subnet has been deleted, and you are redirected to the detailed page of the associated VPC.

:::info
**Before you begin:** Delete all the VM that are in the subnet.
:::

The `DELETE /compute/spaces/{spaceId}/subnets/{id}` command deletes a specified subnet.
Before deleting the subnet, you must delete all the resources associated with it:

* VM
* Network interface cards — NIC (Network Interface Card)
* NAT services ([NAT Gateway](/docs/network/nat/concepts/))
* Load balancers ([load balancer](/docs/network/load-balancer/concepts/))

[Example request: Deleting a subnet](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/subnets/{id})
