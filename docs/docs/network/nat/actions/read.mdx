# Get information about your nat gateways

You can get information about one or more of your [nat gateways](/docs/network/nat/concepts/), such as their public IP or the [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) and subnet they belong to.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.natGateway.get**

:::

  <TabItem value="api" label="API">

The `GET /compute/spaces/{spaceId}/natGateways` command lists the nat gateways.

[Example request: List all nat gateways ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/natGateways)

The `GET /compute/spaces/{spaceId}/natGateways/{id}` command retrieves information about a nat gateway.

[Example request: Retrieve the information of a nat gateway ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/natGateways/{id})
