# Delete a nat gateway

You can delete a [nat gateway](/docs/network/nat/concepts/) that you no longer need.

This action dissociates the public IP from the nat gateway, but does not release this public IP from your account. The routes linked to this nat gateway are not removed from your [route tables](/docs/network/route-table/concepts/).

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.natGateway.delete**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

You can delete a single nat gateway or delete several of them in a single action.

### Delete a nat gateway

1.  From the left-hand side menu, click **Network** → **[VPC](/docs/network/vpc/concepts/)** → **NAT Gateways**.
    ![menu_vpc.png](/img/console/network/vpc/en-menu_vpc.png)
2.  Identify the nat gateway you want to delete, then from the list of actions, click **Delete**.
    ![actions_nat.png](/img/console/network/vpc/nat/actions_nat.png)  
    A new "NAT Gateway deletion" dialog box appears.
    ![delete_one_nat_form.png](/img/console/network/vpc/nat/delete_one_nat_form.png)
3.  To continue, a strong confirmation is required. Enter the name of the resource to delete in the corresponding field.
4.  Click **Delete**. The nat gateway is deleted.  
    A "The NAT Gateway has been deleted" confirmation message appears.
    ![delete_one_nat_success.png](/img/console/network/vpc/nat/delete_one_nat_success.png)  
    

### Delete several nat gateways

1.  From the left-hand side menu, click **Network** → **VPC** → **NAT Gateways**.
    ![menu_vpc.png](/img/console/network/vpc/en-menu_vpc.png)
2.  Select the nat gateways you want to delete, then click **Delete**.
    ![NAT_selection.png](/img/console/network/vpc/nat/NAT_selection.png)  
    A new "NAT Gateways deletion" dialog box appears.
    ![delete_multiple_nat_form.png](/img/console/network/vpc/nat/delete_multiple_nat_form.png)
3.  To continue, a strong confirmation is required. Enter the term **Delete** in the corresponding field.
4.  Click **Delete**. The nat gateways are deleted.  
    A "The NAT Gateways have been deleted" confirmation message appears.
    ![delete_multiple_nat_success.png](/img/console/network/vpc/nat/delete_multiple_nat_success.png)

  </TabItem>
  <TabItem value="api" label="API">

The `DELETE /compute/spaces/{spaceId}/natGateways/{id}` command deletes a specified nat gateway.
This action dissociates the public IP from the nat gateway, but does not release this public IP address from your account.
However, it does not remove the routes of the nat gateway from your route tables.

[Example request: Deleting a nat gateway](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/natGateways/{id})
