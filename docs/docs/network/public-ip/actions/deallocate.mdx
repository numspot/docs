# Release a public IP from your account

You can release a public IP allocated to your account if you no longer need it. This public IP then becomes available to be allocated by another account.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.publicIp.delete**

:::

You can release a single public IP or release several in a single action.

To release public IP, make sure you have first dissociated them from any other resource.

### Release a public IP

1.  From the left-hand side menu, click **Network** → **Public IP**.
2.  Identify the public IP that you want to release, then from the list of actions, click **Release**.
    A new **Release a Public IP** dialog box appears.
3.  To continue, strong confirmation is required. Enter the name of the resource to release in the corresponding field.
4.  Click **Release**. The public IP is released.  
    A confirmation message "The Public IP has been released" appears.
    

### Release several public IP

1.  From the left-hand side menu, click **Network** → **Public IP**.
2.  Select the public IP that you want to release, then click **Release**.
    A new **Release Public IP** dialog box appears.
3.  To continue, strong confirmation is required. Enter the term "Delete" in the corresponding field.
4.  Click **Release** the public IP.
    A confirmation message "The Public IP have been released" appears.

:::info
**Before you begin:**

1.  Make sure that no application or script is using the public IP that you want to release.
2.  Stop the use of the public IP by your resources:

- Detach the public IP from any [VM](/docs/compute/concept/) or network interface.
- Delete any [nat gateway](/docs/network/nat/concepts/) to which the public IP is associated.
:::

You can only release the public IP associated with your account. The `DELETE /compute/spaces/{spaceId}/publicIps/{id}` command releases a public IP. This address is returned to the pool of public IP and can be reused by another person. Before releasing a public IP, make sure you have updated all the resources communicating with this address.

[Example request: Release a public IP](/openapi/#tag/compute/DELETE/compute/spaces/%7BspaceId%7D/publicIps/%7Bid%7D)
