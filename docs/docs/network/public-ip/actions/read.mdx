# Get information about your public IP

You can get information about the **public IP** allocated to your account.

By default, this action describes all your public IP, whether they are available, associated with a **[VM](/docs/compute/concept/)** (Virtual Machine) or a network interface, or used for a **[NAT Gateway](/docs/network/nat/concepts/)**.

Information about your public IP is also available from the VM themselves.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.publicIp.get**

:::

[Example request: List all public IP](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/publicIps)

The `GET /compute/spaces/{spaceId}/publicIps/{id}` command retrieves the information of a public IP.
