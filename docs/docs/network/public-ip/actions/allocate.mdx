# Allouer une IP publique

Vous pouvez allouer une IP publique que vous pouvez ensuite associer avec une [VM (Virtual Machine)](/docs/compute/concept/) ou une interface réseau.

Les IP publiques sont également nécessaires pour créer des [nat gateways (passerelles NAT)](/docs/network/nat/concepts/).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.publicIp.create**

:::

1.  Depuis le menu latéral gauche, cliquez sur **Réseau** → **Public IP**.
2.  Depuis la liste des IP publiques, cliquez sur le bouton **Réserver une Public IP**.
    Une nouvelle fenêtre de dialogue **Réserver une Public IP** apparaît.
3.  Dans le champ "Nom", tapez un nom pour l'IP publique.

:::info
Cette action ajoute un tag Name de 255 caractères maximum. Vous pouvez utiliser tous les caractères, y compris les lettres accentuées.
:::

4.  Cliquez sur **Réserver**. L'IP publique est réservée. Un message de confirmation "La Public IP a bien été réservée" apparaît.

## API {#tabhead-api}

      La commande `POST /compute/spaces/{spaceId}/publicIps` permet d'acquérir une IP publique pour votre compte. Une IP publique est une adresse IP statique conçue pour l'informatique en Cloud dynamique. Elle peut être associée à une VM, à une carte d'interface réseau (NIC), ou à un service NAT.

[Exemple de requête : Création d'une IP publique](/openapi/#tag/compute/POST/compute/spaces/%7BspaceId%7D/publicIps)
