# Dissocier une Public IP d'une ressource

Vous pouvez dissocier une Public IP (adresse IP publique) que vous avez liée à une [VM (Virtual Machine)](/docs/compute/concept/) ou à une interface réseau.

Pour dissocier une Public IP d'une [NAT Gateway (passerelle NAT)](/docs/network/nat/concepts/), vous devez supprimer la NAT Gateway.

:::info
Une fois détachée, la Public IP est toujours allouée à votre compte et peut être de nouveau liée. Si vous n'avez plus besoin de cette Public IP, vous pouvez la libérer.
:::

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.publicIp.update**

:::

## Console {#tabhead-console}

:::info
L'action **Dissocier** n'est proposée que si l'IP publique est **effectivement associée** à une VM ou à une NIC (Network Interface Card) : sur une IP publique libre, l'entrée du menu **Actions** reste grisée.
:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Public IP** ;
2. Repérez l'IP publique à dissocier — ses colonnes **VM ID** et **NIC ID** sont renseignées — puis ouvrez son menu **Actions** ;
3. Cliquez sur **Dissocier**.

   La boîte de dialogue **Dissociation de la Public IP** apparaît et récapitule l'IP publique ainsi que la ressource à laquelle elle est associée ;
4. Cliquez sur **Dissocier la Public IP**.

   L'IP publique est dissociée : elle reste réservée à votre compte et peut être associée à une autre ressource.

## API {#tabhead-api}

  La commande `PUT /compute/spaces/{spaceId}/publicIps/{id}/unlink` dissocie une Public IP de la ressource associée.

  [Exemple de requête : Dissociation d'une Public IP](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/publicIps/{id}/unlink)
