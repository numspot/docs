# Lier une route table à un subnet

Vous pouvez lier une [route table (table de routage)](/docs/network/route-table/concepts/) à un ou plusieurs subnets (sous-réseaux) du [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) pour lequel elle est créée. Les routes contenues dans la route table sont ainsi automatiquement appliquées aux [VM (Virtual Machine)](/docs/compute/concept/) placées dans le subnet pour router le trafic réseau.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.routeTable.update**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Route Table**.


2. Identifiez la route table que vous souhaitez associer à un subnet, puis depuis la liste des actions, cliquez sur **Associer à un Subnet**.


    Une nouvelle boîte de dialogue **Associer à un Subnet** apparaît.


3. Sélectionnez le subnet que vous souhaitez associer à la route table.

4. Cliquez sur le bouton **Associer** (la multi-sélection est disponible).


5. Le subnet a été associé et le message "La route table a bien été associée au subnet" apparaît.

## api {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/routeTables/{id}/subnets/link` associe un subnet à une route table. Le subnet et la route table doivent être dans le même VPC. Le trafic est routé selon la route table définie dans ce VPC. Vous pouvez associer une route table à plusieurs subnets.

[Exemple de requête : Lier une route table ↗](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/routeTables/{id}/subnets/link)
