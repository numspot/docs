# Obtenir des informations sur vos VPC

Vous pouvez obtenir des informations à propos d'un ou plusieurs de vos [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/), comme leur bloc CIDR (Classless Inter-Domain Routing) ou leur option d'allocation.
Des informations sur vos VPC sont également disponibles depuis les [VM (Virtual Machines)](/docs/compute/concept/) elles-mêmes.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vpc.get**

:::

La commande `GET /compute/spaces/{spaceId}/vpcs` permet de lister les VPC.

[Exemple de requête : Lister tous les VPC ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/vpcs)

La commande `GET /compute/spaces/{spaceId}/vpcs/{id}` permet de récupérer les informations d'un VPC.

[Exemple de requête : Récupérer les informations d'un VPC ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/vpcs/{id})
