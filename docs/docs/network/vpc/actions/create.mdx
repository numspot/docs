# Create a VPC

You can create a network to isolate your resources in a virtual network dedicated to your account.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.vpc.create**

:::

     1. Log in to the Numspot console.   

     2. From the left-hand side menu, click **Network** → **[VPC](/docs/network/vpc/concepts/)** → **VPC**. 

     3. Once on the **VPC** page, click the **Create a VPC** button. The **VPC creation** page appears.

     4. In the "Name" field, enter a name for the VPC.

     5. In the "IP range" field, enter the IP address range for your VPC, in CIDR format.
         :::warning 
          Note that the CIDR cannot be changed.
         ::: 
    
     6. (Optional) Tick the "Use a dedicated server for each [VM](/docs/compute/concept/) in this VPC" box if required.
     
     7. Click the **Create a VPC** button. 
     
     8. A confirmation message is displayed at the bottom indicating that the VPC has been created successfully, and you are redirected to the VPC detail page.

        :::info
        A [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/), a [security group](/docs/compute/security-groups/concepts/concept-sg/) and a [route table](/docs/network/route-table/concepts/) will be created automatically.
        :::

The `POST /compute/spaces/{spaceId}/vpcs` command lets you create a VPC (Virtual Private Cloud) with a specified IP (Internet Protocol) address range.
The IP address range (network range) of your VPC must be between a /28 subnet mask (16 IP) and a /16 subnet mask (65536 IP).

[Example request: Creating a VPC](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/vpcs)
