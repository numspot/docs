# Create an internet gateway

You can create an [internet gateway](/docs/network/internet-gateway/concepts/) that you can then attach to a [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud) to connect [VM](/docs/compute/concept/) (Virtual Machine) of one or more subnets directly to the Internet.

To do so, you must also add a route to the [route table](/docs/network/route-table/concepts/) of these subnets directing Internet traffic to the internet gateway, and update your [security groups](/docs/compute/security-groups/concepts/concept-sg/). For more information, see the [Tutorial: Set up a direct connection between the VM of a VPC and the Internet ↗](/docs/network/internet-gateway/actions/administration/tutorial).

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.internetGateway.create**

:::

1. Log in to the Numspot console.
2. From the left-hand side menu, click **Network** → **VPC** → **Internet Gateways**.


3. Click the **Create an Internet Gateway** button.


A new "Create an Internet Gateway" window appears.


4. In the "Name" field, enter a name for the internet gateway.

:::warning
This action adds a Name tag of up to 255 characters. You can use any characters, including accented letters.
:::

5. Click **Create the internet gateway**.

A confirmation message appears at the bottom of the page indicating that the internet gateway has been created.

<TabItem value="api" label="API">

The `POST /compute/spaces/{spaceId}/internetGateways` command creates an internet gateway that you can use with a VPC.

An internet gateway allows VM launched in a network to connect to the Internet. It enables the routing of inbound and outbound Internet traffic as well as the management of public IP.

[Example request: Creating an internet gateway ↗](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/internetGateways)
