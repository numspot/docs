# Détacher une internet gateway d'un VPC

Vous pouvez détacher une [internet gateway](/docs/network/internet-gateway/concepts/) d'un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) pour supprimer sa connexion à Internet.

Cette action supprime également les routes utilisant l'internet gateway comme target.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.internetGateway.update**

:::

## Prérequis

:::info
Le VPC ne doit pas contenir de [VM (Virtual Machine)](/docs/compute/concept/) utilisant des IP publiques ni de [load balancer](/docs/network/load-balancer/concepts/) exposés à Internet.
:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Internet Gateways**.


2. Identifiez l'internet gateway que vous souhaitez détacher du VPC, puis depuis la liste des actions, cliquez sur **Détacher du VPC**.


Une nouvelle boîte de dialogue **Détacher le VPC** apparaît.


3. Confirmez la dissociation en cliquant sur **Détacher**. L'internet gateway est dissociée du VPC.  

    Un message de confirmation "Le VPC a bien été dissocié" apparaît.

## API {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/internetGateways/{id}/vpcs/unlink` détache une internet gateway d'un VPC. Cette action désactive et détache un service Internet d'un VPC.

[Exemple de requête : Détacher une internet gateway d'un VPC](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/internetGateways/%7Bid%7D/vpcs/unlink)

La commande qui détache une internet gateway d'un VPC retourne un code HTTP 204 NO CONTENT, indiquant que l'opération a été effectuée et qu'aucun contenu n'est renvoyé dans la réponse.
