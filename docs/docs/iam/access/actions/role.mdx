# View the permissions of a role

You can view a role's information and the permissions it contains via the console or the API.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.role.get**

:::

<Tabs>
<TabItem value='console' label="Console" default>

## Console {#tabhead-console}


Roles are viewed from the identity details pages (users and service accounts).

1. From the left-hand side menu, click **IAM** → **Users** (or **Service Accounts**).
2. Click the identifier of the relevant identity: the "Assigned spaces" section lists their spaces.
3. Click **X roles** for the relevant space: the list of roles assigned on that space is displayed.
4. Select a role: the list of permissions it contains is displayed.

:::info
The full list of roles and their permissions is available via the API (API tab): the console displays the roles assigned to an identity, space by space.
:::

</TabItem>

## API {#tabhead-api}


### Obtain the mapping between role names and their UUID (Universally Unique Identifier)

Roles are specific to each space. To manipulate them via the API, you need their UUID.

**List the roles of an organization**

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/roles

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/roles'
```

### View the permissions of a space role

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/spaces/{spaceId}/roles/{roleUuid}/permissions

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/roles/{roleUuid}/permissions'
```

### Response

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
```
