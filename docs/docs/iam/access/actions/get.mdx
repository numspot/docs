# View the access rights of an identity

This operation can be carried out at the organization level or at the space level.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.permission.get**

:::

1.  On the detail page of a user account, you can view the list of spaces assigned to a user.


2.  By clicking **X roles**, you can view the list of roles assigned to this user, on the space associated with them.


3.  By clicking **X permissions**, you can view the list of permissions assigned to this user, on the space associated with them.


## View the access rights of a service account

1.  On the detail page of a [service account](/docs/iam/concepts/identity/) you can view the list of spaces associated with the service account.


2.  By clicking the **X roles** link, you can view the list of roles assigned to this service account for the space associated with it.


3.  By clicking the **X permissions** link, you can view the list of permissions assigned to this service account for the space associated with it.

## Roles and permissions within an organization

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}

**Example with a curl:**

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}'
```

Response:

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
See the [page on API usage](/docs/iam/concepts/api/) for the implementation.
:::

## Roles and permissions within a space

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/spaces/{spaceId}/iampolicy/{subjectType}/{subjectId}

**Example with a curl:**

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/iampolicy/{subjectType}/{subjectId}'
```

Response:

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
See the [page on API usage](/docs/iam/concepts/api/) for the implementation.
