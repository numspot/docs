# Lister les comptes de service

Vous pouvez obtenir la liste des comptes de service au niveau de l'organisation ou d'un espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.serviceAccount.get**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Comptes de Service**.
2. Le tableau **Comptes de Service** affiche, pour chaque compte de service : la clé d'accès, le nom, la date d'expiration et les actions disponibles.

Le menu **Actions** d'un compte de service donne accès aux opérations suivantes :

- **Créer un Compte de Service à partir de ce profil** ;
- **Gérer les espaces** ;
- **Gérer les rôles** ;
- **Gérer les permissions** ;
- **Supprimer**.

Vous pouvez également sélectionner plusieurs comptes de service dans le tableau pour les supprimer en une seule opération.

## API {#tabhead-api}


### Lister les comptes de service dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/serviceAccounts

### Exemple de requête

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts'
```

### Exemple de réponse

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
      "name": "…",
      "id": "…",
      "tokenDuration": "…",
      "expirationDate": "…"
    }
  ]
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
