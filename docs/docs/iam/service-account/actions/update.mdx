# Update a service account

You can update a service account's name, token duration and expiration date.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.serviceAccount.update**

:::

1. From the left-hand side menu, click **IAM** → **Service Accounts**.
2. In the **Service Accounts** table, click the access key of the service account to update.
:::tip
You can search for a specific service account using the **Search** field.
:::

3. On the "Service Account details" page, click the **pencil** of the "Name" field.
4. Enter the new name, then confirm with the **tick** (the **cross** cancels the change).

From the console, only the service account's name can be updated. The token duration and the expiration date are updated via the API (API tab).

## API {#tabhead-api}


### Update a service account in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/PUT/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

### curl example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}' \
  --request PUT \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "tokenDuration": "PT24H",
  "expirationDate": "2025-12-31"
}'
```

### Response

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
All fields, updated or not, must be provided. The token duration uses the ISO 8601 format, between 1 second (PT1S) and 48 hours (PT48H), 24 hours (PT24H) by default.

See the [API usage page](/docs/iam/concepts/api/) for details.
:::

### Update a service account in a space

https://docs.numspot.com/openapi/#tag/identity-access-management/PUT/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

### curl example

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request PUT \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "tokenDuration": "PT24H",
  "expirationDate": "2025-12-31"
}'
```

### Response

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
All fields, updated or not, must be provided.

See the [API usage page](/docs/iam/concepts/api/) for details.
:::
