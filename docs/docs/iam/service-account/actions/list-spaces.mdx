# List the spaces assigned to a service account

View the spaces a service account has access to.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.serviceAccount.get**

:::

1. In the **Service Accounts** table, click the access key of the service account whose assigned spaces you want to view.
:::tip
You can search for a specific service account using the **Search** field.
:::

2. On the "Service Account details" page, the "Assigned spaces" section lists the spaces the service account can access, with the roles and permissions associated with each space.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}/spaces

### curl example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}/spaces'
```

### Response

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000"
    }
  ]
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
