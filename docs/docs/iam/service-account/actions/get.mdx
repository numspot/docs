# Get the details of a service account

All the details of a service account are returned, except the secret.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.serviceAccount.get**

:::

1.  Log in to the Numspot console
2.  From the left-hand side menu, click **IAM → Service accounts**


3.  You are redirected to the list of **Service accounts**


In the **Service accounts** table, click the identifier of the service account whose details you want to obtain.

:::info
You can search for a specific service account using the "Search" field.
:::

4.  The page containing the details of the service account is displayed.


5.  You can view the list of spaces assigned to the service account


6.  By clicking the **role** link, you can view the list of roles assigned to this service account on one of its assigned spaces


7.  By clicking the **permissions** link, you can view the list of permissions assigned to this service account on one of its assigned spaces

<TabItem value="api" label="API">

**Get the details of a service account in an organization**

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

**Example with curl**

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}'
```

Response

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
See the [page on using the API](/docs/iam/concepts/api/) for the implementation.
:::

**Get the roles and permissions of a service account in an organization**

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}

**Example with curl**

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}'
```

Response

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
See the [page on using the API](/docs/iam/concepts/api/) for the implementation.
:::
