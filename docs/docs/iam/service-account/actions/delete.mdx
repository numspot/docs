# Supprimer un compte de service

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.serviceAccount.delete**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Comptes de Service**.
2. Cliquez sur le menu **Actions** du compte de service concerné, puis sur **Supprimer**.
3. Une boîte de dialogue "Suppression d'un Compte de Service" apparaît. Dans le champ "Confirmation forte", tapez le nom du compte de service.
4. Cliquez sur le bouton **Supprimer** pour confirmer la suppression du compte de service.

Vous pouvez également supprimer le compte de service depuis sa page "Détails Compte de Service", via le bouton **Supprimer le Compte de Service** en haut à droite.

:::note
La suppression est asynchrone : un message confirme que la demande de suppression du compte de service a bien été prise en compte, puis le compte disparaît de la liste.
:::

## API {#tabhead-api}


### Supprimer un compte de service dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}' \
  --request DELETE
```

### Réponse

```json
{}
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Supprimer un compte de service dans un espace

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request DELETE
```

### Réponse

```json

```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
