# Get your organisation

An organisation groups your spaces and identities. This page shows how to retrieve the organisation assigned to the authenticated identity, with its identifier, name, description and timestamps.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permission:

- **iam.organisation.get**

:::

<Tabs>
<TabItem value="api" label="API">

## API {#tabhead-api}

### Get the organisation of the authenticated identity

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations

Returns the organisation the authenticated identity (user account or service account) is assigned to. An identity is assigned to a single organisation: the response is a one-element list.

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations'
```

### Response

```json
{
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000",
      "name": "ACME",
      "description": "ACME production organisation",
      "originalUserId": "123e4567-e89b-12d3-a456-426614174001",
      "createdOn": "2026-01-15T08:45:00+00:00",
      "updatedOn": "2026-05-02T14:12:00+00:00"
    }
  ]
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
