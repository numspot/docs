# Get a space

You can view the details of a space: its identifier, its name, its description and its status.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permission:

- **iam.space.get**

:::

1. In the **IAM** menu, click **Spaces**.

   You access the **Spaces** table, which lists all the spaces of your organisation.

2. Click the identifier of the space whose details you want to view. The space's details page displays its name, description, identifier and status.

## API {#tabhead-api}

### Get the details of a space

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/organisations/{organisationId}/spaces/{spaceId}

### Example

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces/{spaceId}'
```

### Response

```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "organisationId": "123e4567-e89b-12d3-a456-426614174001",
  "name": "Production",
  "description": "Production workloads",
  "status": "READY",
  "createdOn": "2026-01-15T08:45:00+00:00",
  "updatedOn": "2026-05-02T14:12:00+00:00"
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
