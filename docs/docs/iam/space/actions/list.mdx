# Lister les espaces de l'organisation

Visualisez l'ensemble des espaces de votre organisation.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.role.get**

:::

1. Dans le menu **IAM**, cliquez sur **Espaces**.

   Vous accédez au tableau des **Espaces** où vous pouvez visualiser l'ensemble des espaces de votre organisation.

2. En cliquant sur **Actions** pour un espace donné, vous pouvez modifier l'espace, y assigner des utilisateurs ou des comptes de service, ou le supprimer.

3. En cliquant sur l'identifiant d'un espace, vous accédez à une vision plus détaillée de l'espace, avec la liste des utilisateurs et des comptes de service qui lui sont assignés.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/GET/organisations/{organisationId}/spaces

### Exemple

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces'
```
