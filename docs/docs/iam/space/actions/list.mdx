# List the spaces of the organisation

View all the spaces of your organisation.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.role.get**

:::

1. In the **IAM** menu, click **Spaces**.

   You access the **Spaces** table where you can view all the spaces of your organisation.

2. Clicking **Actions** for a given space lets you edit the space, assign users or service accounts to it, or delete it.

3. Clicking a space's identifier opens a more detailed view of the space, with the list of users and service accounts assigned to it.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/GET/organisations/{organisationId}/spaces

### Example

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces'
```
