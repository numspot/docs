# Modifier un espace

Vous pouvez modifier les informations administratives d'un espace : son nom et sa description.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.role.update**

:::

Vous pouvez modifier un espace depuis la page **Espaces** (menu **Actions** → **Modifier l'espace**). Le bouton **Actions** permet également d'assigner des utilisateurs et des comptes de service à cet espace.

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Espaces**.
2. Ouvrez le menu **Actions** de l'espace à modifier, puis cliquez sur **Modifier l'espace**.
3. Modifiez le nom et/ou la description de l'espace, puis cliquez sur **Modifier l'espace**.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/PATCH/organisations/{organisationId}/spaces/{spaceId}

### Exemple

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces/{spaceId}' \
  --request PATCH \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "description": ""
}'
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
