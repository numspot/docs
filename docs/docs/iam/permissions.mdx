# Permissions and related APIs

For each platform permission, this page lists the APIs that use it: use the search field to filter the list by permission or by API, and follow an endpoint to its definition in the OpenAPI reference.

<PermissionsExplorer />

:::note
The platform follows the principle of least privilege: an action may require several permissions. Every action page of this documentation states, in its Permissions section, the permissions required for the corresponding action.
:::
