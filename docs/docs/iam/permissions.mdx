# Permissions and related APIs

For each platform permission, this page lists the APIs that use it, its UUID and the standard roles granting it.

The permissions are grouped by tenant level:

- **Organisation**: permissions exercised at the organisation level;
- **Espace**: permissions exercised within a space — a permission available at both levels appears under each group.

:::note
The platform follows the principle of least privilege: an action may require several permissions. Every action page of this documentation states, in its Permissions section, the permissions required for the corresponding action. Some permissions have no public endpoint: the corresponding action is performed from the Numspot console.
:::

Use the search field to filter the list by permission or by API, the tenant chips to keep one level only, and the standard role dropdown to display the permissions granted by a default role. Follow an endpoint to its definition in the OpenAPI reference.
