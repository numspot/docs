# Get user information

You can find all the basic information about a user, including the state of their account in the system.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.user.get**

:::

1. In the **Users** table, click the identifier of the user whose information you want to retrieve.
:::tip
You can search for a specific user using the **Search** field.
:::

2. The "User details" page is displayed, with the user's general information: first name, last name, email and account status.

3. You can also view the list of spaces assigned to the user, as well as the roles and permissions assigned to them for a given space.

4. Clicking **X roles** displays the list of roles assigned to the user on one of the spaces they are associated with.

5. Clicking **X permissions** displays the list of permissions assigned to the user on one of the spaces they are associated with.

## API {#tabhead-api}


### Get the details of a user in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/users/{userId}

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}'
```

### Response

```json
{
  "email": "john.smith@acme.org",
  "firstname": "…",
  "lastname": "…",
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "active": true,
  "createdOn": "2018-11-13T20:20:39+00:00",
  "updatedOn": "2018-11-13T20:20:39+00:00"
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::

### Get the details of a user in a space

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/spaces/{spaceId}/users/{userId}

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/users/{userId}'
```

### Response

### Get the list of spaces assigned to a user

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/users/{userId}/spaces

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}/spaces'
```

### Response

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000"
    }
  ]
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::

### Get the roles and permissions of a user account in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}'
```

### Response

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
