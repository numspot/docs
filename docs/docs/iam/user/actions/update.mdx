# Modifier un utilisateur

Vous pouvez modifier les informations de base de l'utilisateur, ainsi que le désactiver.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.user.update**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Utilisateurs**.
2. Cliquez sur l'identifiant de l'utilisateur à modifier.

   La page "Détails utilisateur" apparaît.
3. Dans la section "Informations générales", cliquez sur le **crayon** du champ à modifier : prénom, nom ou adresse e-mail.
4. Saisissez la nouvelle valeur puis validez avec la **coche** (la **croix** annule la modification).

Vous pouvez également **désactiver** l'utilisateur via le bouton "Statut du compte" (il ne pourra plus se connecter), ou lui envoyer un **Nouveau lien d'activation** pour réinitialiser son mot de passe et son authentification à deux facteurs.

## API {#tabhead-api}


### Modifier un utilisateur dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/PUT/iam/organisations/{organisationId}/users/{userId}

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}' \
  --request PUT \
  --header 'Content-Type: application/json' \
  --data '{
  "email": "john.smith@acme.org",
  "firstname": "",
  "lastname": "",
  "active": true
}'
```

### Réponse

```json
{
  "email": "john.smith@acme.org",
  "firstname": "…",
  "lastname": "…",
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "active": true,
  "createdOn": "2018-11-13T20:20:39+00:00",
  "updatedOn": "2018-11-13T20:20:39+00:00"
}
```

:::info
Tous les champs, modifiés ou non, doivent être renseignés.

Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
