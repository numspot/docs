# Lister les utilisateurs

La liste des utilisateurs s'obtient au niveau de l'organisation ou de l'espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.user.get**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Utilisateurs**.
2. Le tableau **Utilisateurs** affiche, pour chaque utilisateur de l'organisation : l'ID, le prénom, le nom, l'adresse e-mail, le statut d'activation et les actions disponibles.

Le menu **Actions** d'un utilisateur donne accès aux opérations suivantes :

- **Créer un utilisateur à partir de ce profil** ;
- **Gérer les espaces** ;
- **Gérer les rôles** ;
- **Gérer les permissions** ;
- **Supprimer**.

## API {#tabhead-api}


### Lister les utilisateurs d'une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/users

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users'
```
