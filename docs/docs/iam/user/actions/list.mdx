# List users

The list of users is available at organisation level or at space level.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.user.get**

:::

1. From the left-hand side menu, click **IAM** → **Users**.
2. The **Users** table displays, for each user in the organisation: the ID, the first name, the last name, the email address, the activation status and the available actions.

A user's **Actions** menu gives access to the following operations:

- **Create user from this profile**;
- **Manage spaces**;
- **Manage roles**;
- **Manage permissions**;
- **Delete**.

## API {#tabhead-api}


### List the users of an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/users

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users'
```
