# Lister les espaces assignés à un utilisateur

Consultez les espaces auxquels un utilisateur a accès.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.user.get**

:::

1. Dans le tableau des **utilisateurs**, cliquez sur l'identifiant de l'utilisateur dont vous souhaitez connaître les espaces.
:::tip
Vous avez la possibilité de rechercher un utilisateur en particulier en utilisant le champ **Rechercher**.
:::

2. Sur la page "Détails utilisateur", la section "Espaces assignés" liste les espaces auxquels l'utilisateur peut accéder, avec les rôles et permissions associés à chaque espace.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/users/{userId}/spaces

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}/spaces'
```

### Réponse

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000"
    }
  ]
}
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
