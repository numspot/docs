# Supprimer un utilisateur

La suppression d'un utilisateur est une opération d'administration à fort impact, non réversible.

:::warning
Cette action est **irréversible**.
:::

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **iam.user.delete**

:::

1. Dans le tableau listant les **utilisateurs**, ouvrez le menu **Actions** de l'utilisateur à supprimer, puis cliquez sur **Supprimer**. La boîte de dialogue "Supprimer l'utilisateur" apparaît.

2. Dans le champ "Confirmation forte", saisissez le prénom et le nom de l'utilisateur à supprimer.

3. Cliquez sur **Supprimer**.

Vous pouvez également supprimer un utilisateur depuis sa page "Détails utilisateur", via le bouton **Supprimer l'utilisateur** en haut à droite.

:::warning
La suppression d'un utilisateur de l'organisation supprime automatiquement ses clés API. Les politiques qui lui sont directement associées restent orphelines.
:::

## API {#tabhead-api}


### Supprimer un utilisateur dans une organisation

[Documentation de l'API de suppression d'un utilisateur](/openapi/#tag/identity-access-management/DELETE/iam/organisations/{organisationId}/users/{userId})

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}' \
  --request DELETE
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
