# Attach a virtual gateway

You can attach a [virtual gateway](/docs/connectivity/vpn/virtual-gateway/concepts/) to a [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/). You can then set up a **VPN** (Virtual Private Network) connection between this VPC and a [client gateway](/docs/connectivity/vpn/client-gateway/concepts/).

This action changes the attachment state of the virtual gateway from `detached` to `attached`, but the state of the virtual gateway remains `available`.

You can attach each virtual gateway to a single VPC at a time. You can attach a virtual gateway to a VPC before or after creating the VPN connection.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **connectivity.bridge.update**

:::

:::info
**Before you start:**
* Create a virtual gateway.
* Make sure the virtual gateway is in the `available` state.
* Create a VPC.
:::

<Tabs>
<TabItem value="console" label="Console" default>

1. Click in the **Virtual Gateways** dashboard to display the checkboxes.
2. Select the checkbox of the virtual gateway you want to attach to a VPC.
   The virtual gateway is selected and an actions menu appears.
3. Click **Attach to a VPC**.
   The "Attach to a VPC" dialog box appears.
4. In the "VPC" list, select the ID of the VPC to which you want to attach the virtual gateway.
5. Click **Attach**.
   The virtual gateway is attached to the specified VPC.

</TabItem>
<TabItem value="api" label="API">

The `POST /connectivity/spaces/{spaceId}/virtualGateways/{id}/link` command attaches a virtual gateway to a VPC.

:::warning
This action can only be performed if the virtual gateway is in the `available` state.
:::

[Request example: Attach a virtual gateway to a VPC](/openapi/#tag/connectivity/POST/connectivity/spaces/{spaceId}/virtualGateways/{id}/link)
