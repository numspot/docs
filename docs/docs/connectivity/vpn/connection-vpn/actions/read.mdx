# Get information about your VPN connections

You can get information about one or several of your VPN (Virtual Private Network) connections.

By default, this action describes all your VPN connections.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.vpnconnection.get**

:::

<Tabs>
<TabItem value="console" label="Console" default>

1. In the console, navigate to **Network** → **[VPC](/docs/network/vpc/concepts)** → **VPN Connections**.
2. The list of all your VPN connections is displayed with their main information:
   - ID
   - [virtual gateway](/docs/connectivity/vpn/virtual-gateway/concepts/)
   - [client gateway](/docs/connectivity/vpn/client-gateway/concepts/)
   - State

</TabItem>
<TabItem value="api" label="API">

The `GET /connectivity/spaces/{spaceId}/vpnConnections` command lists your VPN connections.

[Example request: List all your VPN Connections](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/vpnConnections)

The `GET /connectivity/spaces/{spaceId}/vpnConnections/{id}` command retrieves information about a VPN connection.

[Example request: Retrieve the information of a VPN Connection](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/vpnConnections/{id})

</TabItem>
<TabItem value="terraform" label="Terraform">

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/vpn_connection).

</TabItem>
