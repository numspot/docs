# Update a VPN connection

You can update the attributes of a VPN (Virtual Private Network) connection.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.vpnconnection.update**

:::

<Tabs>
<TabItem value="console" label="Console" default>

1. In the **VPN Connections** dashboard, click the ID of the VPN connection to update.
2. Update the required attributes.
3. Click **Save**.

The VPN connection is updated.

</TabItem>
<TabItem value="api" label="API">

The `PUT /connectivity/spaces/{spaceId}/vpnConnections/{id}` command updates the specified attributes of a VPN connection.

[Request example: Updating a VPN Connection](/openapi/#tag/connectivity/PUT/connectivity/spaces/{spaceId}/vpnConnections/{id})

</TabItem>

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/vpn_connection).
