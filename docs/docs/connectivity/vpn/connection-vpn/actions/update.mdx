# Modifier une connexion VPN

Vous pouvez modifier les attributs d'une connexion **VPN** (Virtual Private Network).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.vpnconnection.update**

:::

<Tabs>
<TabItem value="console" label="Console" default>

## Console {#tabhead-console}


1. Dans le dashboard **VPN Connections**, cliquez sur l'ID de la connexion VPN à modifier.
2. Modifiez les attributs souhaités.
3. Cliquez sur **Enregistrer**.

La connexion VPN est modifiée.

</TabItem>
<TabItem value="api" label="API">

## API {#tabhead-api}


La commande `PUT /connectivity/spaces/{spaceId}/vpnConnections/{id}` modifie les attributs spécifiés d'une connexion VPN.

[Exemple de requête : Modification d'une VPN Connection](/openapi/#tag/connectivity/PUT/connectivity/spaces/{spaceId}/vpnConnections/{id})

</TabItem>
