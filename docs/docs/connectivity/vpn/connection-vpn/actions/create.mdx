# Create a VPN connection

You can create a VPN (Virtual Private Network) connection between your corporate network and one of your [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud) in the Numspot Cloud.

This action creates a secure VPN tunnel between a [client gateway](/docs/connectivity/vpn/client-gateway/concepts/) and a [virtual gateway](/docs/connectivity/vpn/virtual-gateway/concepts/). The VPN connection remains in the `pending` state until traffic is generated from the client gateway.

Once the VPN connection is created, you must configure it.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.vpnconnection.create**

:::

:::info
Before you begin:
- create the required resources;
- make sure the virtual gateway is in the `available` state.
:::

The `POST /connectivity/spaces/{spaceId}/vpnConnections` command creates a VPN connection between a specified virtual gateway and a specified client gateway.
You can create only one VPN connection between a virtual gateway and a client gateway.
