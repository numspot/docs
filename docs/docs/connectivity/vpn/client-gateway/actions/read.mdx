# View the information of your client gateways

You can obtain information about one or more of your [client gateways](/docs/connectivity/vpn/client-gateway/concepts/).

By default, this action describes all your client gateways.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.bridge.get**

:::

<Tabs>
<TabItem value="console" label="Console" default>

1. In the console, navigate to **Network** → **[VPC](/docs/network/vpc/concepts)** → **Client Gateways**.
2. The list of all your client gateways is displayed with their main information:
   - ID
   - Public IP (Internet Protocol) address
   - ASN (Autonomous System Number)
   - State

</TabItem>
<TabItem value="api" label="API">

The `GET /connectivity/spaces/{spaceId}/clientGateways` command lists the client gateways.

[Example request: List all Client Gateways](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/clientGateways)

The `GET /connectivity/spaces/{spaceId}/clientGateways/{id}` command retrieves information about a client gateway.

[Example request: Retrieve the information of a Client Gateway](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/clientGateways/{id})

</TabItem>
<TabItem value="terraform" label="Terraform">

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/client_gateway).

</TabItem>
