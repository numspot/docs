# Créer une client gateway

Vous pouvez créer une [client gateway (passerelle client)](/docs/connectivity/vpn/client-gateway/concepts/) dans votre réseau d'entreprise.

Cette action identifie une ressource existante dans votre réseau d'entreprise à utiliser comme client gateway. Vous pouvez ensuite mettre en place une connexion **VPN** (Virtual Private Network) entre cette client gateway et une [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.bridge.create**

:::

:::info
**Avant de commencer** : Créez une ressource à utiliser comme client gateway.
:::

1. Dans le dashboard **Client Gateways**, cliquez sur **Créer une Client Gateway**.
   La boîte de dialogue "Création d'une Client Gateway" apparaît.

2. Dans le champ "BGP ASN", tapez le numéro de système autonome (ASN - Autonomous System Number) adéquat pour votre client gateway.

:::info
L'ASN doit être compris entre 1 et 4294967295. Si vous n'avez pas d'ASN, vous pouvez en choisir un entre 64512 et 65534, ou entre 4200000000 et 4294967294.
:::

3. Dans le champ "Public IP", tapez l'IP (Internet Protocol) publique statique de la ressource que vous voulez utiliser comme client gateway.

:::info
Les adresses IPv6 ne sont pas supportées. Vous devez utiliser une adresse IPv4.
:::

4. Cliquez sur **Créer une Client Gateway**.
   La client gateway est créée.

## API {#tabhead-api}


La commande `POST /connectivity/spaces/{spaceId}/clientGateways` crée une client gateway.
Cette action enregistre des informations pour identifier la client gateway que vous avez déployée dans votre réseau.
Pour établir un tunnel avec la client gateway, vous devez fournir le type de protocole de communication, l'adresse IP publique fixe de la passerelle, et un numéro de système autonome (ASN).

[Exemple de requête : Création d'une Client Gateway](/openapi/#tag/connectivity/POST/connectivity/spaces/{spaceId}/clientGateways)
