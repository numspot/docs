**Hybrid Bridges are deprecated.** The single Bridges API covers both use cases — VPC to VPC and VPC to managed services — and must be used for new deployments: see [About Bridges](/docs/connectivity/bridges/concepts/) and [Create a Bridge](/docs/connectivity/bridges/actions/create/). The endpoints and Terraform resources documented below keep working.

:::

# Delete a Hybrid Bridge

You can delete a bridge to end communication between your [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) and the managed services.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.bridge.delete**

:::
<Tabs>
  <TabItem value='api' label="API" default>

## API {#tabhead-api}

The `DELETE /connectivity/spaces/{spaceId}/bridges/{id}` command deletes the bridge.

[Example request: Deleting a Hybrid Bridge](/openapi/#tag/connectivity/DELETE/connectivity/spaces/{spaceId}/bridges/{id})
