# Get information about your Hybrid Bridges

You can get information about one or several bridges.

By default, this action describes all your bridges.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.bridge.get**

:::
<Tabs>
  <TabItem value='api' label="API" default>

## API {#tabhead-api}

The `GET /connectivity/spaces/{spaceId}/bridges` command lists all your bridges.

[Example request: List all Hybrid Bridges](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/bridges)

The `GET /connectivity/spaces/{spaceId}/bridges/{id}` command retrieves the information of a specific bridge.

[Example request: Retrieve the information of a Hybrid Bridge](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/bridges/{id})
