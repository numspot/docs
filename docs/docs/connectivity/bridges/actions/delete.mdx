# Delete a Bridge

You can delete a bridge to end the communication between the two connected resources.

Before deleting a bridge, remove the routes targeting it from the [route tables](/docs/network/route-table/concepts/) of your [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud), otherwise the traffic towards the deleted connection is blackholed.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permission:

- **connectivity.bridge.delete**

:::

<Tabs>
<TabItem value="api" label="API" default>

## API {#tabhead-api}

The `DELETE /connectivity/spaces/{spaceId}/bridges/{id}` command deletes the bridge.

[Example request: Deleting a Bridge](/openapi/#tag/connectivity/DELETE/connectivity/spaces/{spaceId}/bridges/{id})
