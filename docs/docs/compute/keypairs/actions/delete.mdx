# Delete a key pair

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.keypair.delete**

:::

You can delete a specified [key pair](/docs/compute/keypairs/concept/). This action deletes the public key kept by Numspot.

Deleting a key pair does not delete the private key saved on your computer, and does not delete the public key in the metadata of other [VM](/docs/compute/concept/) (Virtual Machine) created with the same key pair. You cannot create new VM using the deleted key pair. However, you can still connect to other VM already created with the same key pair, as long as you can provide its private key.

1. Log in to the Numspot console.

2. From the left-hand side menu, click **Compute → Key pairs**.

3. Tick the box of the key pair you want to delete or click the "Actions" drop-down menu on the same line.
  The key pair is selected or an actions menu appears.

4. Click **Delete**.
  A confirmation dialog box appears.

5. Confirm the deletion by typing the name of the key pair.

6. Click **Delete**.

  The key pair is deleted and a confirmation message appears at the bottom of the page.
