# View the console output of a VM

You can display the console output of a [VM (Virtual Machine)](/docs/compute/concept/) to diagnose kernel problems or system errors. The console displays the most recent 64 KiB of output. On Windows VM, the console is accessible only on the first start and provides no output after the first restart.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.vm.get**

:::

1. Access the VM

   1. From the left-hand side menu, click **Compute** → **VM** to access the list of VM.


   2. Click the ID of the VM to access the details page.


2. View the console

   1. In the General section, click "View the console".


   2. Tick "Automatic refresh" if necessary or click "Refresh".

  <TabItem value="api" label="API">
The `GET /compute/spaces/{spaceId}/vms/{id}/consoleOutputs` command lets you obtain the console output for a VM. This console provides the most recent 64 KiB of output.

:::warning
On Windows VM, the console is handled only on the first start. No output is returned after this first start.
:::

[Example request: Retrieve the console output of the VM](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/vms/{id}/consoleOutputs)
