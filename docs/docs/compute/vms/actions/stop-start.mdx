# Arrêter et démarrer une VM

Vous pouvez arrêter une [VM (Virtual Machine)](/docs/compute/concept/) en fonctionnement à tout moment, puis la démarrer à nouveau. Arrêter une VM vous permet, par exemple, d'assurer sa maintenance ou de traiter son volume système.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vm.update**

:::

    ### Arrêter une VM

    1. Depuis le menu latéral gauche, cliquez sur **Compute** → **VM** pour accéder à la liste des VM.

    2. Sélectionnez la VM que vous souhaitez arrêter.

       :::info
       La multi-sélection est disponible.
       :::

    3. Cliquez sur le bouton **Arrêter**.

    4. Lorsque vous êtes invité à confirmer l'opération, sélectionnez **Arrêter**.

       La VM sélectionnée est arrêtée.

    5. L'état de la VM sélectionnée passe à "stopping", puis à "stopped" une fois l'opération terminée.

    ### Démarrer une VM

    1. Depuis le menu latéral gauche, cliquez sur **Compute** → **VM** pour accéder à la liste des VM.

    2. Sélectionnez la VM que vous souhaitez démarrer.

       :::info
       La multi-sélection est disponible.
       :::

    3. Cliquez sur le bouton **Démarrer**.

    4. Lorsque vous êtes invité à confirmer l'opération, sélectionnez **Démarrer**.

       La VM sélectionnée est démarrée.

    5. L'état de la VM sélectionnée passe à "pending", puis à "running" une fois l'opération terminée.

## API {#tabhead-API}

    La commande `PUT /compute/spaces/{spaceId}/vms/{id}/stop` arrête une VM en cours d'exécution. Les données stockées dans la RAM (Random Access Memory) de la VM sont perdues.

    [Exemple de requête : Arrêter une VM](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D/stop)

    La commande `PUT /compute/spaces/{spaceId}/vms/{id}/start` démarre une VM.

    [Exemple de requête : Lancer une VM](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D/start)
  </TabItem>
