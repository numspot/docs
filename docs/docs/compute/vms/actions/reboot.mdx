# Restart a VM

You can restart a running [VM (Virtual Machine)](/docs/compute/concept/) if needed, which corresponds to restarting the operating system. During this operation, the VM restarts without following the stop and start process.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.vm.update**

:::
