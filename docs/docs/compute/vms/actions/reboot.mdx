# Redémarrer une VM

Vous pouvez redémarrer une [VM (Virtual Machine)](/docs/compute/concept/) en cours d'exécution si besoin, ce qui correspond à redémarrer le système d'exploitation. Lors de cette opération, la VM redémarre sans suivre le processus d'arrêt et de démarrage.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vm.update**

:::

    1. Depuis le menu latéral gauche, cliquez sur **Compute** → **VM** pour accéder à la liste des VM.

    2. Sélectionnez la VM que vous souhaitez redémarrer.

       :::info
       La multi-sélection est disponible.
       :::

    3. Cliquez sur le bouton **Redémarrer**.

    4. Lorsque vous êtes invité à confirmer l'opération, sélectionnez **Redémarrer**.

       La VM sélectionnée est redémarrée.

## API {#tabhead-API}

    La commande `PUT /compute/spaces/{spaceId}/vms/{id}/reboot` redémarre une VM. Cette opération envoie une demande de redémarrage à une VM spécifiée. Il s'agit d'une action asynchrone qui met en file d'attente cette demande de redémarrage.

    [Exemple de requête : Redémarrer la VM](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D/reboot)
