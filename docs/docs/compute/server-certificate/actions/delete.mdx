# Supprimer un server certificate

Vous pouvez supprimer un server certificate que vous n'utilisez plus.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.serverCertificate.delete**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

## Console {#tabhead-console}

:::info
La suppression d'un certificat serveur n'est pas disponible depuis la console Numspot.

Utilisez l'**API** ou **Terraform** (voir les onglets correspondants).
:::

  </TabItem>
  <TabItem value="api" label="API">

## API {#tabhead-api}

La commande `DELETE /compute/spaces/{spaceId}/serverCertificates/{id}` supprime un server certificate spécifié.

[Exemple de requête : Suppression d'un server certificate](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/serverCertificates/{id})
