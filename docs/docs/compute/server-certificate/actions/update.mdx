# Update a server certificate

You can update the name and/or the path of an existing server certificate.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.serverCertificate.update**

:::

<Tabs>
  <TabItem value="console" label="Console" default>

## Console {#tabhead-console}

:::info
Updating a server certificate is not available from the Numspot console.

Use the **API** or **Terraform** (see the corresponding tabs).
:::

  </TabItem>
  <TabItem value="api" label="API">
The `PUT /compute/spaces/{spaceId}/serverCertificates/{id}` command updates the name and/or the path of a specified server certificate.

[Example request: Updating a server certificate](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/serverCertificates/{id})
  </TabItem>
  <TabItem value="terraform" label="Terraform">

## Terraform {#tabhead-terraform}

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/server_certificate).
