# Attach or detach a GPU

You can attach a [GPU](/docs/compute/gpu/concept/) (Graphics Processing Unit) to a [VM](/docs/compute/concept/) (Virtual Machine), or detach it at any time. To attach a GPU, you must first allocate it to your account. For more information, see [Allocate or release a GPU](/docs/compute/gpu/actions/allocating-releasing/).

## Permissions

:::info
These actions require the following IAM (Identity and Access Management) permissions:

- **compute.gpu.update**

:::

:::warning
You can only attach GPU to VM with the highest performance flag (1). For more information, see [About GPU](/docs/compute/gpu/concept/) and [VM types](/docs/compute/vms/types/).
:::

## Attach a GPU
<Tabs>
   <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Compute** → **GPU**.

         ![GPU: Image](/img/console/general/sidebar/sidebar-compute-gpu.png)

2. In the GPU dashboard, choose from the list the GPU you want to attach to a VM.
3. Choose the **Attach to a VM** action.

         ![GPU: Image](/img/console/compute/gpus/dropdown-gpu.png)

   An "Attachment to a VM" panel appears.
4. In the "Choose a VM" list, select the VM to which you want to attach the GPU.
5. Click **Attach to the VM**.

         ![GPU: Image](/img/console/compute/gpus/button-associate-gpu.png)

6. A confirmation message appears at the bottom of the page indicating that the GPU is successfully attached to the VM.

:::warning
To finalize the attachment of the GPU, you must perform a stop and then a start of the VM.
A simple restart is not sufficient, because the attachment of the GPU takes place when the VM passes through the `stopped` state.

For the difference between stop/start and restart, see [VM lifecycle](/docs/compute/vms/lifecycle/).
:::

  </TabItem>

  <TabItem value="api" label="API">
The `PUT /compute/spaces/{spaceId}/flexibleGpus/{id}/vms/link` command attaches one of your allocated flexible GPU (fGPU) to one of your VM.
The fGPU is in an attaching state until the VM is stopped, after which it becomes attached.

:::note info
You can only attach fGPUs to VM with the highest performance flag: "highest" (1).
:::

[Example request: Attaching an fGPU to a VM](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/flexibleGpus/{id}/vms/link)
  </TabItem>

  <TabItem value="terraform" label="Terraform">
The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/flexible_gpu).
  </TabItem>

</Tabs>

## Detach a GPU

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.gpu.update**

:::

<Tabs>
  <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Compute** → **GPU**.

         ![GPU: Image](/img/console/general/sidebar/sidebar-compute-gpu.png)

2. Select the GPU you want to detach and choose the **Detach from the VM** action.
   The "Detach from the VM" dialog box appears.

            ![GPU: Image](/img/console/compute/gpus/dropdown-gpu-2.png)

3. Click **Detach from the VM**.

4. A confirmation message appears at the bottom of the page indicating that the GPU is successfully detached from the VM.

:::warning
To finalize the detachment of the GPU, you must perform a stop and then a start of the VM.
A simple restart is not sufficient, because the detachment of the GPU takes place when the VM passes through the `stopped` state.

For the difference between stop/start and restart, see [VM lifecycle](/docs/compute/vms/lifecycle/).
:::

  </TabItem>

  <TabItem value="api" label="API">
The `PUT /compute/spaces/{spaceId}/flexibleGpus/{id}/vms/unlink` command detaches a flexible GPU (fGPU) from a VM.
The fGPU is in a detaching state until the VM is stopped, after which it becomes allocated again. It is then available again to be attached to another VM.

[Example request: Detaching an fGPU from a VM](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/flexibleGpus/{id}/vms/unlink)
  </TabItem>

  <TabItem value="terraform" label="Terraform">
The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/flexible_gpu).
  </TabItem>

</Tabs>
