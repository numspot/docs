# Supprimer un ou plusieurs tags

Vous pouvez supprimer un ou plusieurs tags sur vos ressources.

## Permissions

:::info
La suppression de tags est une opération de mise à jour de la ressource concernée. Cette action nécessite la permission **IAM** (Identity and Access Management) de mise à jour de chaque ressource ciblée. Par exemple :

- **compute.vm.update** pour une [VM (virtual machine)](/docs/compute/concept/) ;
- **compute.blockStorage.update** pour un [volume (block storage)](/docs/storage/block-storage/concepts/) ;
- **compute.loadBalancer.update** pour un [load balancer](/docs/network/load-balancer/concepts/) ;
- **compute.vpc.update** pour un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/).

Cette liste est donnée à titre d'exemple et n'est pas exhaustive : pour chaque ressource, reportez-vous à sa page d'action.

:::

1. Depuis le menu latéral gauche, accédez à la liste de la ressource dont vous souhaitez supprimer un tag ;
2. Sur la ligne de la ressource, ouvrez le menu **Actions**, puis cliquez sur **Gérer les tags** ;
3. Dans le panneau **Gérer les tags**, cliquez sur la **croix** du tag à supprimer ;
4. Cliquez sur **Valider** pour enregistrer.

:::info
Le parcours est identique pour toutes les ressources qui supportent les tags (VM, volume, load balancer, VPC…). L'exemple ci-dessus est pris sur un load balancer.
:::

## API {#tabhead-API}


La commande `DELETE /compute/spaces/{spaceId}/bulk/tags` supprime un ou plusieurs tags de vos ressources.

[Exemple de requête : Supprimer un tag ↗](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/bulk/tags)
