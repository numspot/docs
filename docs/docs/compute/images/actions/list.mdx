# List images

You can obtain information about the images you can use to launch [VM (Virtual Machine)](/docs/compute/concept/) either through the Numspot console or through the API (Application Programming Interface). This information can help you choose the image best suited to your needs to create your VM.

The list of images returns the official images and the private images of the space. You can filter the list by image type using the `imageType` parameter:

- `official`: returns only the official Numspot images (open source Linux distributions)
- `private`: returns only the private images of the space

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.image.get**

:::

[Example request: List all your images](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/images)

## Obtain information about an image with the API

The `GET /compute/spaces/{spaceId}/images/{id}` command retrieves the information of an image.

[Example request: Retrieve the information of an image](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/images/%7Bid%7D)
