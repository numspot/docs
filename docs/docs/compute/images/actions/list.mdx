# Lister les images

Vous pouvez obtenir des informations sur les Images que vous pouvez utiliser pour lancer des [VM (Virtual Machine)](/docs/compute/concept/) soit par la console Numspot, soit par l'API (Application Programming Interface). Ces informations peuvent vous aider à choisir l'Image la plus adaptée à vos besoins pour créer vos VM.

La liste des images retourne les images officielles et les images privées de l'espace. Vous pouvez filtrer la liste par type d'image à l'aide du paramètre `imageType` :

- `official` : retourne uniquement les images officielles Numspot (distributions Linux open source)
- `private` : retourne uniquement les images privées de l'espace

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.image.get**

:::

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/images` permet de lister vos Images que vous pouvez utiliser pour créer des VM.

[Exemple de requête : Lister toutes vos Images](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/images)

### Obtenir des informations sur une Image avec API

La commande `GET /compute/spaces/{spaceId}/images/{id}` permet de récupérer les informations d'une Image.

[Exemple de requête : Récupérer les informations d'une Image](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/images/%7Bid%7D)
