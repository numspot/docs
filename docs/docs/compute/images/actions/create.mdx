# Create an image

You can create a private image from a [VM (Virtual Machine)](/docs/compute/concept/). The created image contains all the data of the VM, including the operating system, the applications and the user data.

This action also creates a snapshot of the VM system volume, as well as a snapshot of each [block storage](/docs/storage/block-storage/concepts/) volume attached to the VM. These snapshots are used to create the image and can be used to create new VM from this image.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.image.create**

:::
