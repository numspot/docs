# Créer une image

Vous pouvez créer une Image privée à partir d'une [VM (Virtual Machine)](/docs/compute/concept/). L'image créée contient toutes les données de la VM, y compris le système d'exploitation, les applications et les données utilisateur.

Cette action crée également un snapshot (instantané) du volume système de la VM, ainsi qu'un snapshot de chaque volume de [block storage (stockage bloc)](/docs/storage/block-storage/concepts/) attaché à la VM. Ces snapshots sont utilisés pour créer l'image et peuvent être utilisés pour créer de nouvelles VM à partir de cette image.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.image.create**

:::
