# Référence des images officielles

Cette page présente la liste des images officielles supportées pour chaque région.

Les images officielles intègrent Cloud-Init. Pour en savoir plus, voir la [documentation officielle de Cloud-Init ↗](https://cloudinit.readthedocs.io/en/latest/).

Numspot garantit que le contenu des images officielles est à jour. Cependant, une fois qu'une [VM (Virtual Machine)](/docs/compute/concept/) est lancée depuis une de ces images, il vous incombe de mettre à jour vos environnements.
