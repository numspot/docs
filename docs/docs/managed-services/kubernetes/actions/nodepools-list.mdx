# List the node pools of a Kubernetes cluster

Retrieve the list of node pools of a [Kubernetes cluster](/docs/managed-services/kubernetes/concepts/).

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **kubernetes.cluster.get**

:::
<Tabs>

<TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Managed Services** → **Kubernetes** to access the list of Kubernetes clusters.

   ![Managed Services menu](/img/console/managed-services/en-menu-managed-services.png)

2. Click the name of a cluster to access its details page.

3. The **Node pools** section displays the list of the cluster's node pools with their information:
   - Node pool name
   - Status
   - Availability Zone
   - Node type
   - System volume
   - Number of nodes

The status of a node pool can take the following values:

| Status | Description |
|--------|-------------|
| In progress | The node pool is operating normally |
| Pending | The node pool is being created or updated |
| Failed | An error has occurred |

</TabItem>

<TabItem value="api" label="API">
    Use the `GET /kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools` route to list the node pools of a Kubernetes cluster.

    **Example response**

    ```json
    {
      "items": [
        {
          "id": "nodepool-001-e29b-41d4",
          "name": "worker-nodepool-1",
          "availabilityZone": "eu-west-2a",
          "nodeProfile": "medium",
          "replicas": 3,
          "rootDisk": {
            "size": 50,
            "iops": 3000,
            "type": "enterprise"
          },
          "status": {
            "state": "RUNNING",
            "message": "NodePool is healthy"
          }
        }
      ]
    }
    ```

    [See the full specification](/openapi/#tag/kubernetes/GET/kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools)
</TabItem>
