# Delete a cluster Kubernetes

Delete a [cluster Kubernetes](/docs/managed-services/kubernetes/concepts/) within your space, regardless of its status.

:::info
**Prerequisites:** Make sure that the cluster is not in use before deleting it.
:::

:::warning
This action is irreversible. Once the cluster is deleted, all its associated resources and configurations will be permanently lost.
:::

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **kubernetes.cluster.delete**

:::

1. From the left-hand side menu, click **Managed Services** → **Kubernetes** to access the list of Kubernetes clusters.

2. In the list, locate the cluster to delete, click the **Actions** button on its row, then click **Delete**.

3. In the “Cluster deletion” window, enter the exact name of the cluster in the “Name of cluster” field, then click **Delete permanently**.

The cluster moves to the “Deleting” status in the list.

<TabItem value="api" label="API">
The `DELETE /kubernetes/spaces/{spaceId}/clusters/{clusterId}` request lets you delete a Kubernetes cluster.
The cluster moves to the “deleting” status during the deletion.

**Example response**

```text
HTTP/1.1 204 No Content
```

[See the full specification](/openapi/#tag/kubernetes/DELETE/kubernetes/spaces/{spaceId}/clusters/{clusterId})
