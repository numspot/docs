# Delete a node pool from a Kubernetes cluster

Delete a node pool from a [cluster Kubernetes](/docs/managed-services/kubernetes/concepts/) within your space.

:::warning
This action is irreversible. Once the node pool is deleted, its nodes and the associated data are permanently lost.
:::

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **kubernetes.cluster.update**

:::
<Tabs>
<TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Managed Services** → **Kubernetes** to access the list of Kubernetes clusters.

   ![Managed Services menu](/img/console/managed-services/en-menu-managed-services.png)

2. Click the ID of the cluster from which you want to delete a node pool to access its details page.

   ![List of Kubernetes clusters](/img/console/managed-services/kubernetes/en-kubernetes-cluster-list.png)

3. In the **Node pools** section, click the **Delete** button of the relevant node pool.

4. In the **Deleting a node pool** window, enter the name of the node pool in the confirmation field, then click **Delete the node pool**.

Once the deletion is confirmed, the node pool and its nodes are deleted: the node pool disappears from the **Node pools** section of the cluster.

</TabItem>

<TabItem value="api" label="API">
    Use the `DELETE /kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools/{nodePoolId}` route to delete a node pool from a managed Kubernetes cluster.

    **Example response**

```text
HTTP/1.1 204 No Content
```

    [See the full specification](/openapi/#tag/kubernetes/DELETE/kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools/{nodePoolId})
</TabItem>
