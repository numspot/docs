# Réinitialiser le mot de passe administrateur

Vous pouvez réinitialiser le mot de passe administrateur de votre Container Registry au sein de votre espace. Le mot de passe actuel est révoqué et un nouveau mot de passe est généré.

Une fois la réinitialisation terminée, récupérez le nouveau mot de passe avec la requête `GET /registry/spaces/{spaceId}/registries/{registryId}/password` (voir [Mot de passe administrateur du Container Registry](/docs/managed-services/registry/actions/password)).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **registry.password.reset**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    La requête `PUT /registry/spaces/{spaceId}/registries/{registryId}/password/reset` permet de réinitialiser le mot de passe administrateur d'un Container Registry.

### Paramètres

| Paramètre  | Type   | Requis | Description                    |
| ---------- | ------ | ------ | ------------------------------ |
| spaceId    | string | Oui    | Identifiant de l'espace Numspot. |
| registryId | string | Oui    | Identifiant du registry Harbor.  |

### Exemple de réponse

La requête renvoie un code `202 Accepted` avec un corps vide.

    ```json
    {}
    ```

    [Voir la spécification complète](/openapi/#tag/registry/PUT/registry/spaces/{spaceId}/registries/{registryId}/password/reset)
