# Reset the administrator password

You can reset the administrator password of your Container Registry within your space. The current password is revoked and a new password is generated.

Once the reset is complete, retrieve the new password with the `GET /registry/spaces/{spaceId}/registries/{registryId}/password` request (see [Container Registry administrator password](/docs/managed-services/registry/actions/password)).

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **registry.password.reset**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    The request `PUT /registry/spaces/{spaceId}/registries/{registryId}/password/reset` resets the administrator password of a Container Registry.

### Parameters

| Parameter  | Type   | Required | Description              |
| ---------- | ------ | -------- | ------------------------ |
| spaceId    | string | Yes      | The Numspot space ID.    |
| registryId | string | Yes      | The Harbor registry ID.  |

### Example response

The request returns a `202 Accepted` code with an empty body.

    ```json
    {}
    ```
