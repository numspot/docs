# Accéder à la console DLP

## Introduction

Le service [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) dispose de sa propre console web, indépendante de la console Numspot. Cette console est accessible via une URL dédiée, fournie lors du déploiement du service.

## Obtenir l'URL de la console

L'URL de la console DLP est définie par le paramètre `TLS_HOSTNAME` configuré lors du déploiement du service. Pour obtenir cette URL :

1. Connectez-vous à la console Numspot ;
2. Accédez aux détails de l'instance DLP déployée ;
3. Relevez l'URL d'accès affichée dans les informations de l'instance.

1. Ouvrez l'URL de la console DLP dans votre navigateur ;
2. Saisissez vos identifiants sur la page de connexion ;
3. Lors de la première connexion avec le compte admin, changez le mot de passe — la modification est obligatoire (8 caractères minimum).

:::warning
Après 5 tentatives de connexion échouées, un verrouillage de 5 minutes est appliqué par nom d'utilisateur.
:::

## Navigation dans la console

La console DLP comporte les sections suivantes dans le menu latéral :

- **Dashboard** : statistiques d'évaluation en temps réel ;
- **Publish** : publication et rollback des [ruleset](/docs/managed-services/dlp/concepts) (ensemble de règles) ;
- **Policies** : gestion des policies ;
- **Rules** : gestion des règles ;
- **Detectors** : gestion des détecteurs prédéfinis et personnalisés ;
- **Users** : gestion des utilisateurs ;
- **API Tokens** : création et gestion des [tokens API](/docs/managed-services/dlp/guides/api-authentication) (authentification Bearer) ;
- **Decision Logs** : consultation des journaux de décision ;
- **Monitored Rules** : consultation des événements monitorés ;
- **Audit Logs** : consultation de la piste d'audit ;
- **Documentation** : documentation intégrée du service.

## Déconnexion

Cliquez sur votre nom d'utilisateur en haut à droite de la console, puis sélectionnez **Sign out**. La session est détruite et vous êtes redirigé vers la page de connexion.

:::info
La durée de session est de 8 heures. Au-delà, vous devez vous reconnecter.
:::
