# Consulter le tableau de bord DLP

Consultez le tableau de bord [DLP](/docs/managed-services/dlp/concepts) pour visualiser les statistiques d'évaluation en temps réel : volume de requêtes, répartition des décisions, règles les plus déclenchées et répartition par plateforme.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **viewer**

:::

1. Connectez-vous à la console [DLP](/docs/managed-services/dlp/concepts). Le tableau de bord s'affiche par défaut.

### Statistiques d'évaluation

- **Sélecteur de période** : choisissez la plage temporelle — 1h, 24h, 7d ou 30d ;
- **Graphique en courbes** : évolution des évaluations dans le temps, ventilée par type de décision (`pass`, `block`, `modify`, `monitor`) ;
- **Graphique en barres** : règles les plus déclenchées sur la période sélectionnée ;
- **Graphique en secteurs** : répartition des évaluations par plateforme consommatrice.

### Décisions récentes

Le tableau des décisions récentes affiche les dernières évaluations bloquées ou modifiées, avec :

- l'identifiant de la requête ;
- la plateforme consommatrice ;
- la décision rendue ;
- les règles déclenchées ;
- l'horodatage.

</TabItem>
<TabItem value="api" label="API">

La requête `GET /api/v1/dashboard/stats` permet de récupérer les statistiques du tableau de bord.

### Paramètres de requête

| Paramètre | Description |
|-----------|-------------|
| `range` | Période : `1h`, `24h`, `7d` ou `30d` |

### Exemple de réponse

```json
{
  "evaluations": [
    {
      "timestamp": "2026-08-27T14:00:00Z",
      "pass": 8420,
      "block": 156,
      "modify": 23,
      "monitor": 8
    }
  ],
  "top_rules": [
    {
      "rule_id": "rule-550e8400",
      "rule_name": "block-aws-keys",
      "count": 156
    }
  ],
  "per_platform": [
    {
      "platform_instance": "mistral-prod-eu",
      "total": 8607
    }
  ]
}
```
