# Delete a DLP rule

Permanently delete a [DLP rule](/docs/managed-services/dlp/concepts). This action is irreversible. If the rule is included in a published policy, you must first update the policy to remove it.

## Permissions

:::info
This action requires the following [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) role:

- **rule_editor**

:::

:::warning
Deletion is permanent. Rules already published in a ruleset are not affected — only draft rules are deleted.
:::

2. Click the delete icon (trash) on the row of the rule to delete.
3. Confirm the deletion in the dialog box.

<TabItem value="api" label="API">

The `DELETE /api/v1/rules/{id}` request deletes a [DLP rule](/docs/managed-services/dlp/concepts).

### Response example

```text
HTTP/1.1 204 No Content
```
