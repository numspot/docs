# Consulter les journaux de décision DLP

Consultez les journaux de décision pour suivre les évaluations effectuées par le service [DLP](/docs/managed-services/dlp/concepts). Chaque évaluation produit un journal contenant la décision rendue, les [règles DLP](/docs/managed-services/dlp/concepts) déclenchées et les champs modifiés.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **viewer**

:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Decision Logs** dans le menu latéral.

### Filtrer les journaux

Utilisez les filtres disponibles pour affiner la recherche :

- **Platform instance** : filtrer par instance de plateforme ;
- **Decision** : filtrer par type de décision — `pass`, `block` ou `modify` ;
- **Time range** : filtrer par période.

### Détails d'un journal

Cliquez sur un journal pour afficher ses détails :

- l'identifiant de la requête ;
- la plateforme consommatrice ;
- la décision rendue ;
- les règles déclenchées ;
- les champs modifiés ;
- le code de statut HTTP ;
- la latence de traitement.

</TabItem>
<TabItem value="api" label="API">

La requête `GET /api/v1/logs/decisions` permet de rechercher les journaux de décision.

### Paramètres de requête

| Paramètre | Description |
|-----------|-------------|
| `platform_instance` | Filtrer par instance de plateforme |
| `decision` | Filtrer par décision : `pass`, `block` ou `modify` |
| `time_start` | Date de début de la période (ISO 8601) |
| `time_end` | Date de fin de la période (ISO 8601) |
