# Delete a DLP user

Delete a user from the [DLP](/docs/managed-services/dlp/concepts) service. The deleted user immediately loses access to the DLP console.

## Permissions

:::info
This action requires the following [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) role:

- **admin**

:::

:::warning
The internal numspot account cannot be deleted. The last admin account cannot be deleted — make sure at least one admin remains after deletion.
:::

1. In the [DLP](/docs/managed-services/dlp/concepts) console, click **Users** in the sidebar.
2. Click the delete icon (trash) on the row of the user to delete.
3. Confirm the deletion in the dialog box.

### Restrictions

- The internal **numspot** account cannot be deleted;
- The last **admin** account cannot be deleted. If you need to delete the last admin, assign the admin role to another user first.

</TabItem>
<TabItem value="api" label="API">

The `DELETE /api/v1/users/{id}` request deletes a user.

### Response example

```text
HTTP/1.1 204 No Content
```

### Restrictions

- Deleting the internal numspot account returns a `403 Forbidden` error;
- Deleting the last admin returns a `409 Conflict` error.
