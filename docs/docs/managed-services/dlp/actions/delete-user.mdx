# Supprimer un utilisateur DLP

Supprimez un utilisateur du service [DLP](/docs/managed-services/dlp/concepts). L'utilisateur supprimé perd immédiatement l'accès à la console DLP.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **admin**

:::

:::warning
Le compte interne `numspot` ne peut pas être supprimé. Le dernier compte admin ne peut pas être supprimé — assurez-vous qu'il reste au moins un admin après la suppression.
:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Users** dans le menu latéral.
2. Cliquez sur l'icône de suppression (corbeille) sur la ligne de l'utilisateur à supprimer.
3. Confirmez la suppression dans la boîte de dialogue.

### Restrictions

- Le compte interne **numspot** ne peut pas être supprimé ;
- Le dernier compte **admin** ne peut pas être supprimé. Si vous devez supprimer le dernier admin, attribuez d'abord le rôle admin à un autre utilisateur.

</TabItem>
<TabItem value="api" label="API">

La requête `DELETE /api/v1/users/{id}` permet de supprimer un utilisateur.

### Exemple de réponse

```text
HTTP/1.1 204 No Content
```

### Restrictions

- La suppression du compte interne `numspot` renvoie une erreur `403 Forbidden` ;
- La suppression du dernier admin renvoie une erreur `409 Conflict`.
