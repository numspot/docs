# Delete a DLP policy

Permanently delete a [DLP policy](/docs/managed-services/dlp/concepts). This action is irreversible. Only draft policies can be deleted.

## Permissions

:::info
This action requires the following [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) role:

- **rule_editor**

:::

:::warning
Deletion is permanent. Policies already published in a ruleset are not affected — only draft policies are deleted.
:::

<TabItem value="api" label="API">

The `DELETE /api/v1/policies/{id}` request deletes a [DLP policy](/docs/managed-services/dlp/concepts).

### Response example

```text
HTTP/1.1 204 No Content
```
