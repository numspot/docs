# Reset a DLP user password

Reset the password of a [DLP](/docs/managed-services/dlp/concepts) service user. The user will be required to change their password on the next login.

## Permissions

:::info
This action requires the following [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) role:

- **admin**

:::

1. In the [DLP](/docs/managed-services/dlp/concepts) console, click **Users** in the sidebar.
2. Click the **Reset password** button on the row of the user.
3. Enter the new password (minimum 8 characters) in the dialog box.
4. Click **Confirm** to validate the reset.

The user will be required to change their password on the next login.

</TabItem>
<TabItem value="api" label="API">

The `POST /api/v1/users/{id}/password-reset` request resets a user's password.

### Request example

```json
{
  "password": "NewPassword456!"
}
```

### Response example

```json
{
  "id": "user-123456",
  "username": "jdupont",
  "must_change_password": true,
  "updated_at": "2026-08-27T12:00:00Z"
}
```

The `must_change_password` field is set to `true` to force a password change on the next login.
