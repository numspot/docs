# Réinitialiser le mot de passe d'un utilisateur DLP

Réinitialisez le mot de passe d'un utilisateur du service [DLP](/docs/managed-services/dlp/concepts). L'utilisateur devra changer son mot de passe à la prochaine connexion.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **admin**

:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Users** dans le menu latéral.
2. Cliquez sur le bouton **Reset password** sur la ligne de l'utilisateur concerné.
3. Saisissez le nouveau mot de passe (8 caractères minimum) dans la boîte de dialogue.
4. Cliquez sur **Confirm** pour valider la réinitialisation.

L'utilisateur devra changer son mot de passe à la prochaine connexion.

</TabItem>
<TabItem value="api" label="API">

La requête `POST /api/v1/users/{id}/password-reset` permet de réinitialiser le mot de passe d'un utilisateur.

### Exemple de requête

```json
{
  "password": "NouveauMotDePasse456!"
}
```

### Exemple de réponse

```json
{
  "id": "user-123456",
  "username": "jdupont",
  "must_change_password": true,
  "updated_at": "2026-08-27T12:00:00Z"
}
```

Le champ `must_change_password` est positionné à `true` pour forcer le changement de mot de passe à la prochaine connexion.
