# Versions and lifecycle

Numspot operates the [DLP](/docs/managed-services/dlp/concepts/) (Data Loss Prevention) service with stable versions receiving active security patch monitoring, in compliance with the security requirements applied to the service.

## Supported version

The following version is supported:

- **DLP v0.16**

This scope covers the stable and actively maintained version, with continuous monitoring of security bulletins.

## Security patch monitoring

The DLP service includes:

- patch updates applied regularly to fix bugs and security vulnerabilities;
- active monitoring of critical and high vulnerabilities;
- hardened container images.

Patch updates are applied automatically by Numspot and require no action from the customer.

:::info
For information about applied versions or recent patches, contact Numspot support.
:::

## Version lifecycle

### Support policy

| Version | Support status | Estimated Numspot end of support |
|---------|----------------|----------------------------------|
| **v0.16** | Active | Not planned |

### End of support notification

Numspot notifies its customers several months before the end of support for a version. This notification allows customers to plan migration to a newer version.

## Updates

Updates to the DLP service are applied continuously by Numspot. Published [rulesets](/docs/managed-services/dlp/concepts/) and logging data are preserved during updates.

:::warning
Updates may modify the available platform schemas. Check the compatibility of your rules after each update notified by Numspot.
:::
