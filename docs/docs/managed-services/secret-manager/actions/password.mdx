# Get the admin token of a Secret Manager instance

You can retrieve the admin token of your [Secret Manager instance](/docs/managed-services/secret-manager/concepts/) within your space. This token is required to administer the instance from the Vault interface.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **secrets.instance.get**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    The request `GET /secrets/spaces/{spaceId}/instances/{instanceId}/password` retrieves the admin token of a Secret Manager instance.

### Parameters

| Parameter  | Type   | Required | Description                   |
| ---------- | ------ | -------- | ----------------------------- |
| spaceId    | string | Yes      | The Numspot space ID.         |
| instanceId | string | Yes      | The Secret Manager instance ID. |

### Example response

    ```json
    {
      "token": "hvs.CAESIJ7m8w9GxK2LpQr5tNvY1zA4bC6dE8fG0hI2jK4lM6nO8p"
    }
    ```

    [View the full specification](/openapi/#tag/secrets/GET/secrets/spaces/{spaceId}/instances/{instanceId}/password)
