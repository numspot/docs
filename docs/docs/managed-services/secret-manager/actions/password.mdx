# Obtenir le token admin d'une instance Secret Manager

Vous pouvez récupérer le token admin de votre [instance Secret Manager](/docs/managed-services/secret-manager/concepts/) au sein de votre espace. Ce token est requis pour administrer l'instance depuis l'interface Vault.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **secrets.instance.get**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    La requête `GET /secrets/spaces/{spaceId}/instances/{instanceId}/password` permet de récupérer le token admin d'une instance Secret Manager.

### Paramètres

| Paramètre  | Type   | Requis | Description                             |
| ---------- | ------ | ------ | --------------------------------------- |
| spaceId    | string | Oui    | Identifiant de l'espace Numspot.        |
| instanceId | string | Oui    | Identifiant de l'instance Secret Manager. |

### Exemple de réponse

    ```json
    {
      "token": "hvs.CAESIJ7m8w9GxK2LpQr5tNvY1zA4bC6dE8fG0hI2jK4lM6nO8p"
    }
    ```

    [Voir la spécification complète](/openapi/#tag/secrets/GET/secrets/spaces/{spaceId}/instances/{instanceId}/password)
