# Versions et cycle de vie

Numspot opère ses [clusters PostgreSQL](/docs/managed-services/postgresql/concepts/) avec des versions stables bénéficiant d'un suivi actif des correctifs de sécurité, en conformité avec les exigences de sécurité appliquées au service.

## Versions supportées

Les versions majeures suivantes sont supportées :

- **PostgreSQL 16**
- **PostgreSQL 17**
- **PostgreSQL 18**

Ce périmètre couvre les versions stables et activement maintenues par la communauté PostgreSQL, avec un suivi continu des bulletins de sécurité.

:::note
Lors de la création d'un cluster, la version la plus récente est sélectionnée par défaut. Pour plus d'informations, consultez [Créer un cluster PostgreSQL](/docs/managed-services/postgresql/actions/create/).
:::

## Suivi des patches de sécurité

Les images utilisées pour les clusters PostgreSQL sont basées sur des images TimescaleDB HA et intègrent :

- Des mises à jour mineures (patch) appliquées régulièrement pour corriger les bugs et les failles de sécurité.
- Un suivi actif des vulnérabilités critiques et hautes.

Les mises à jour mineures sont appliquées automatiquement par Numspot et ne nécessitent aucune action de la part du client. Elles ne concernent que les versions patch (par exemple, `17.2` vers `17.5`), sans modification de la compatibilité des données.

:::info
Pour obtenir des informations sur les versions appliquées ou les correctifs récents, contactez le support Numspot.
:::

## Cycle de vie des versions (lifecycle)

### Politique de support

| Version | Statut du support | Date de fin de support communautaire | Fin de support Numspot estimée |
|---------|-------------------|--------------------------------------|--------------------------------|
| **16** | Active | novembre 2028 | novembre 2028 |
| **17** | Active | novembre 2029 | novembre 2029 |
| **18** | Active | novembre 2030 | novembre 2030 |

Le statut de support est aligné sur les dates annoncées par le projet PostgreSQL. Numspot suit la politique PostgreSQL concernant le support des versions majeures.

### Notification de fin de support

Numspot notifie ses clients **plusieurs mois avant la fin de support** d'une version majeure. Cette notification permet aux clients de planifier la migration vers une version plus récente.

## Mises à jour majeures

Les mises à jour majeures (par exemple, de PostgreSQL 17 vers PostgreSQL 18) nécessitent la création d'un nouveau cluster. Numspot recommande de tester la compatibilité de vos applications avant de procéder à une mise à jour majeure.

:::warning
Numspot ne peut pas garantir la compatibilité ascendante entre les versions majeures. Il est de la responsabilité du client de vérifier que ses applications sont compatibles avec la nouvelle version avant toute migration.
:::
