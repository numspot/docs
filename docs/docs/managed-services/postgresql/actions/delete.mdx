# Delete a PostgreSQL cluster

You can delete a [PostgreSQL cluster](/docs/managed-services/postgresql/concepts/) within your space, whatever its status.

:::warning
Make sure the cluster is not in use before deleting it.
:::

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **postgresql.cluster.delete**

:::
<Tabs>
<TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Managed Services** → **PostgreSQL** → **Clusters** to access the list of PostgreSQL clusters.

   ![Managed Services menu](/img/console/managed-services/postgresql/en-menu-postgresql.png)

2. In the list, locate the cluster to delete, click the **Actions** button on its row, then click **Delete**.

   You can also open the cluster details page and click the **Delete** button at the top right.

3. In the "Delete the cluster" window, enter the exact name of the cluster in the "Strong confirmation" field, then click **Delete**.

   The cluster switches to the "Deleting" status in the list.

</TabItem>

<TabItem value="api" label="API">
    The `DELETE /postgresql/spaces/{spaceId}/clusters/{clusterId}` request deletes a PostgreSQL cluster.
    The cluster switches to the `DELETING` status during the deletion.

    ### Example response

    ```text
    HTTP/1.1 204 No Content
    ```

    [See the full specification](/openapi/#tag/postgresql/DELETE/postgresql/spaces/{spaceId}/clusters/{clusterId})
</TabItem>
