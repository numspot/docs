# List PostgreSQL clusters

You can list all the [PostgreSQL clusters](/docs/managed-services/postgresql/concepts/) within your space.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **postgresql.cluster.get**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    The request `GET /postgresql/spaces/{spaceId}/clusters` lists the PostgreSQL clusters of a space.

### Parameters

| Parameter | Type   | Required | Description              |
| --------- | ------ | -------- | ------------------------ |
| spaceId   | string | Yes      | The Numspot space ID.    |

### Example response

    ```json
    {
      "items": [
        {
          "id": "123e4567-e89b-42d3-a456-426614174000",
          "name": "my-cluster-postgresql",
          "databaseName": "appdb",
          "user": "admin",
          "majorVersion": "17",
          "fullVersion": "17.2",
          "status": {
            "state": "RUNNING",
            "message": "Cluster is healthy"
          },
          "nodeConfiguration": {
            "vcpuCount": 2,
            "memorySizeGiB": 8

            "type": "GP2",

    ```
