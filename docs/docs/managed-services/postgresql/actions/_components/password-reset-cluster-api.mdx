The `PUT /postgresql/spaces/{spaceId}/clusters/{clusterId}/password/reset` request generates a new password for the primary user of a [PostgreSQL cluster](/docs/managed-services/postgresql/concepts/).
The request is answered with a `202` response carrying the new auto-generated password; it becomes active once the cluster status is no longer `RESETTING_PASSWORD`.

### Example response

```json
{
  "password": "S3cure-P4ssw0rd-g3n3r4t3d"
}
```
