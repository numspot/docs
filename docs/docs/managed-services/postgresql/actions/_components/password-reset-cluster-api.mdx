The `PUT /postgresql/spaces/{spaceId}/clusters/{clusterId}/password/reset` request generates a new password for the primary user of a [PostgreSQL cluster](/docs/managed-services/postgresql/concepts/).
Once the request has been executed, the new password can be retrieved after a few seconds by calling the `GET /postgresql/spaces/{spaceId}/clusters/{clusterId}/password` route.

### Example response

```json
{
  "message": "Password reset in progress"
}
```
