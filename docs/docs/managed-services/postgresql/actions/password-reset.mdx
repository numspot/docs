# Reset the primary user password of a PostgreSQL cluster

You can generate a new password for the primary user (the user you specified when creating the cluster) of one of your [PostgreSQL clusters](/docs/managed-services/postgresql/concepts/) within your space.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **postgresql.cluster.resetPassword**

:::
