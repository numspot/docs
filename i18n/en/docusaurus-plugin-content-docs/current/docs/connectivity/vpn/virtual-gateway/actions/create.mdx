# Create a virtual gateway

You can create a [virtual gateway](/docs/connectivity/vpn/virtual-gateway/concepts/) to attach to a [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud). You can then set up a VPN (Virtual Private Network) connection between this VPC and a [client gateway](/docs/connectivity/vpn/client-gateway/concepts/).

You can create the virtual gateway before or after creating the VPC.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **connectivity.bridge.create**

:::

1. In the **Virtual Gateways** dashboard, click **Create a Virtual Gateway**.
   The "Create a Virtual Gateway" dialog box appears.
2. In the "Name" field, type a name for the virtual gateway.
3. Click **Create**.
   The virtual gateway is created.

<TabItem value="api" label="API">

The `POST /connectivity/spaces/{spaceId}/virtualGateways` command creates a virtual gateway.
A virtual gateway is the access point on the VPC side of a VPN connection.

[Example request: Creating a virtual gateway](/openapi/#tag/connectivity/POST/connectivity/spaces/{spaceId}/virtualGateways)
