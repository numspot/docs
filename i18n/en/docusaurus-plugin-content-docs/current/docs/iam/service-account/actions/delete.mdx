# Delete a service account

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.serviceAccount.delete**

:::

1. From the left-hand side menu, click **IAM** → **Service Accounts**.
2. Open the **Actions** menu of the relevant service account, then click **Delete**.
3. The "Deleting Service Account" dialog appears. In the "Strong confirmation" field, enter the name of the service account.
4. Click the **Delete** button to confirm the deletion of the service account.

You can also delete the service account from its "Service Account details" page, using the **Delete Service Account** button at the top right.

:::note
The deletion is asynchronous: a message confirms that the deletion request has been taken into account, then the service account disappears from the list.
:::

## API {#tabhead-api}


### Delete a service account in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

### curl example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}' \
  --request DELETE
```

### Response

```json
{}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::

### Delete a service account in a space

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

### curl example

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request DELETE
```

### Response

```json
{}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
