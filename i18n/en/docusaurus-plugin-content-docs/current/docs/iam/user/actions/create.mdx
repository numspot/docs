# Create a user

Create a user within your Numspot organization. The user then accesses the console and the API to manage the resources of the spaces assigned to them.

When creating the user, you choose whether to assign roles and permissions immediately, or to create the account without access rights. You can also create a user from the profile of an existing user: the new user then inherits the same spaces, roles and permissions.

For the API, you must first create a service account.

Once the user is created, [generate an activation link](/docs/iam/user/actions/generate/) so that they can set their password and configure two-factor authentication.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.user.create**

:::

1. From the left-hand side menu, click **IAM** → **Users**.
2. Click the **Create a user** button.
3. Enter the user's first name, last name and email address, then click **Create and assign roles and permissions**, or **Create the user without roles or permissions**:
   - **Create the user without roles or permissions** immediately creates the account and redirects you to the "User details" page; you can assign access rights later;
   - **Create and assign roles and permissions** opens the access rights wizard, made up of three steps: "Spaces", "Roles" and "Permissions".
4. "Spaces" step: tick the spaces to associate with the user, then click **Assign spaces and continue**. You can also click **Skip step**.
5. "Roles" step: select the "All spaces" tab or the relevant space, tick the roles to assign, then click **Save and continue**. You can also click **Do not assign roles** or **Skip step**.
6. "Permissions" step: select the "All spaces" tab or the relevant space, tick the permissions to assign, then click **Save and quit**. You can also click **Do not assign permissions** or **Skip step**.
7. A confirmation message is displayed and you are redirected to the "User details" page.

You can create a user from the profile of an existing user:

1. From the "User details" page, click **Create user from this profile**.
2. Enter the new user's first name, last name and email address.
3. The new user inherits the same spaces, roles and permissions as the initial user.

## API {#tabhead-api}


### Create a user in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/POST/iam/organisations/{organisationId}/users

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users' \
  --request POST \
  --header 'Content-Type: application/json' \
  --data '{
  "email": "john.smith@acme.org",
  "firstname": "",
  "lastname": ""
}'
```

### Response

```json
{
  "email": "john.smith@acme.org",
  "firstname": "…",
  "lastname": "…",
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "active": true,
  "createdOn": "2018-11-13T20:20:39+00:00"
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::

### Assign roles and permissions to a user in an organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/PATCH/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}

### Example

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}' \
  --request PATCH \
  --header 'Content-Type: application/json' \
  --data '{
  "add": {
    "roles": [
      ""
    ],
    "permissions": [
      ""
    ]
  },
  "delete": {
    "roles": [
      ""
    ],
    "permissions": [
      ""
    ]
  }
}'
```
