# Update a space

You can update a space's administrative information: its name and its description.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.role.update**

:::

You can update a space from the **Spaces** page (**Actions** menu → **Edit space**). The **Actions** button also lets you assign users and service accounts to the space.

1. From the left-hand side menu, click **IAM** → **Spaces**.
2. Open the **Actions** menu of the space to update, then click **Edit space**.
3. Update the space's name and/or description, then click **Edit space**.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/PATCH/organisations/{organisationId}/spaces/{spaceId}

### Example

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces/{spaceId}' \
  --request PATCH \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "description": ""
}'
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
:::
