# Create a space within an organisation

An organisation can create as many spaces as it needs. A space compartmentalises resources and identities. A user or a service account can belong to several spaces of the organisation and have different permissions for each space. Example: an administrator on one space can be a read or write user on some resources in others.

A space has the following properties:

- a name;
- a description.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **iam.role.create**

:::

1. In the **Spaces** menu, click the **Create a space** button.

   A new window appears.

2. In the "Space name" and "Space description" fields, enter the name and description of the new space.
3. Click the **Create space** button. Back on the spaces list, a message confirms that the new space has been created.
:::warning
A space can take several seconds to be created. Therefore, it may not appear immediately in the list of spaces.

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/POST/organisations/{organisationId}/spaces

### Example

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces' \
  --request POST \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "description": ""
}'
```

### Response

```json
{
  "name": "…",
  "description": "…",
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "organisationId": "123e4567-e89b-12d3-a456-426614174000",
  "status": "QUEUED",
  "createdOn": "2025-12-16T15:38:31.485Z",
  "updatedOn": "2025-12-16T15:38:31.485Z"
}
```

:::info
See the [API usage page](/docs/iam/concepts/api/) for details.
