# Attach a volume

You can attach a `volume` to a [VM](/docs/compute/concept/) (Virtual Machine) within the same Subregion to add storage capacity to it. You can attach several `volumes` to a VM (up to 40), for example to separate different types of data.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.blockStorage.update**

:::

<Tabs>
<TabItem value="Console" default>

1. Log in to the Numspot console.
2. From the left-hand side menu, click **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**. The list of `volumes` appears.
3. Select the `volume` you want to link.
   :::info
   You can also select a VM in the "VM" dashboard and click **Link a volume**.
   :::
4. Under the `volume` actions menu, click **Associate a VM**.
   The **Association with a VM** dialog box appears.
5. In the "VM" list, select the VM to which you want to link the `volume`.
6. In the "Devices" list, select the name of the device to which you want to assign the `volume`.
7. Click **Associate with the VM**.
   The `volume` is linked to the selected VM.
   :::warning
   Once the `volume` is attached, you must mount it at the operating system level to make it usable.
   :::

</TabItem>
<TabItem value="API">

The `PUT /compute/spaces/{spaceId}/volumes/{id}/vms/link` command attaches a block storage `volume` to a VM. The `volume` and the VM must be located in the same subregion. The VM can be running or stopped. The `volume` is attached to the specified device of the VM.

[Example request: Attach a Volume to a VM ↗](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/volumes/{id}/vms/link)

</TabItem>
