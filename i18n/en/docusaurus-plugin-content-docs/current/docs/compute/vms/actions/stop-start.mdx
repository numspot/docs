# Stop and start a VM

You can stop a running [VM (Virtual Machine)](/docs/compute/concept/) at any time, then start it again. Stopping a VM lets you, for example, carry out its maintenance or process its system volume.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.vm.update**

:::

    ### Stop a VM

    1. From the left-hand side menu, click **Compute** → **VM** to access the list of VM.


    2. Select the VM you want to stop.


       :::info
       Multi-selection is available.
       :::

    3. Click the **Stop** button.


    4. When prompted to confirm the operation, select **Stop**.


       The selected VM is stopped.

    5. The state of the selected VM moves to "stopping", then to "stopped" once the operation is complete.

    ### Start a VM

    1. From the left-hand side menu, click **Compute** → **VM** to access the list of VM.


    2. Select the VM you want to start.


       :::info
       Multi-selection is available.
       :::

    3. Click the **Start** button.


    4. When prompted to confirm the operation, select **Start**.


       The selected VM is started.

    5. The state of the selected VM moves to "pending", then to "running" once the operation is complete.

  <TabItem value="API" label="API">
    The `PUT /compute/spaces/{spaceId}/vms/{id}/stop` command stops a running VM. The data stored in the RAM (Random Access Memory) of the VM is lost.

    [Example request: Stop a VM](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D/stop)

    The `PUT /compute/spaces/{spaceId}/vms/{id}/start` command starts a VM.

    [Example request: Launch a VM](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D/start)
  </TabItem>
