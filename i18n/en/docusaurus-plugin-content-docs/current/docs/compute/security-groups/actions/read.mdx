# Get information about your security groups

You can get information about one or more [security groups](/docs/compute/security-groups/concepts/concept-sg/) and the rules they contain.

Information about your security groups is also available from the [VM](/docs/compute/concept/) (Virtual Machine) themselves.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.securityGroup.get**

:::
