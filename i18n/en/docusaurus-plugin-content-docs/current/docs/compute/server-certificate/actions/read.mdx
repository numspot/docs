# Get information about your server certificates

You can view the detailed information of your server certificates.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.serverCertificate.get**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

## Console {#tabhead-console}

:::info
Viewing server certificates is not available from the Numspot console.

Use the **API** or **Terraform** (see the corresponding tabs).
:::

  </TabItem>
  <TabItem value="api" label="API">
### Get information about your server certificates with the Numspot API

The `GET /compute/spaces/{spaceId}/serverCertificates` command lists your server certificates.

[Example request: List all your server certificates](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/serverCertificates)
  </TabItem>
  <TabItem value="terraform" label="Terraform">

## Terraform {#tabhead-terraform}

The Terraform documentation is available on the [Numspot registry ↗](https://registry.terraform.io/providers/numspot/numspot/latest/docs/resources/server_certificate).
