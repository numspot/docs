# Obtain information about your key pairs

You can obtain information about your created and imported [key pairs](/docs/compute/keypairs/concept/).

Information about the public part of a key pair is also available, only from the [VM](/docs/compute/concept/) (Virtual Machine) associated with the key pair.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.keypair.get**

:::

  <TabItem value="api" label="API">
The `GET /compute/spaces/{spaceId}/keypairs` command lets you list your key pairs.

[Example request: Listing all your key pairs](/openapi/#tag/compute/get/compute/spaces/{spaceId}/keypairs)

The `GET /compute/spaces/{spaceId}/keypairs/{id}` command lets you retrieve the information of a key pair.

[Example request: Retrieving the information of a key pair](/openapi/#tag/compute/get/compute/spaces/{spaceId}/keypairs/{id})
