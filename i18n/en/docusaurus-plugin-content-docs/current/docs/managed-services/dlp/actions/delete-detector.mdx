# Delete a custom DLP detector

Permanently delete a custom [DLP detector](/docs/managed-services/dlp/concepts). This action is irreversible. If the detector is referenced in existing rules, you must first update those rules.

## Permissions

:::info
This action requires the following [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) role:

- **detector_editor**

:::

:::warning
Deletion is permanent. If active rules reference this detector via `@custom:<id>`, they will fail during evaluation. Check dependencies before deleting a detector.
:::

1. In the [DLP](/docs/managed-services/dlp/concepts) console, click **Detectors** in the sidebar.
2. Click the **Custom** tab to display custom detectors.
3. Click the delete icon (trash) on the row of the detector to delete.
4. Confirm the deletion in the dialog box.

</TabItem>
<TabItem value="api" label="API">

The `DELETE /api/v1/detectors/custom/{id}` request deletes a custom [DLP detector](/docs/managed-services/dlp/concepts).

### Response example

```text
HTTP/1.1 204 No Content
```
