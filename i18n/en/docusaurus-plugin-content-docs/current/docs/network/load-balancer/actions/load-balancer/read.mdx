# Obtain information about your load balancers

You can view the information about one or more [load balancers](/docs/network/load-balancer/concepts/) in your space.

## Permissions

:::info
This action requires the following **IAM** (Identity and Access Management) permissions:

- **compute.loadBalancer.get**

:::

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. The list displays the information of each load balancer: name, ID, type, status, associated [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud), etc.
3. To display the details of a specific load balancer, click its name.

  </TabItem>
  <TabItem value="api" label="API">

The `GET /compute/spaces/{spaceId}/loadBalancers` command lists your load balancers.

[Example request: List all your load balancers](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/loadBalancers)

The `GET /compute/spaces/{spaceId}/loadBalancers/{id}` command retrieves information about a load balancer.

[Example request: Retrieve the information of a load balancer](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/loadBalancers/{id})

  </TabItem>
