# Register a VM with a load balancer

You can attach one or more [VM](/docs/compute/concept/) (Virtual Machine) to a specified [load balancer](/docs/network/load-balancer/concepts/). You must specify at least the BackendIps or BackendVMIds parameter. The VM can be located in different subnets and different Subregions from the load balancer, as long as the VM and the load balancers are either all in the public Cloud or all in the same [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud). Registering a VM with the load balancer can take some time. Once registered, the VM receives traffic and requests from that load balancer and is then called a backend VM.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.loadBalancer.update**

:::
<Tabs>
  <TabItem value="console" label="Console" default>

1. From the left-hand side menu, click **Network** → **Load Balancers** to access the list of load balancers.
2. Click the name of the load balancer for which you want to register a VM.
3. In the "Backend VM" tab, click **Register a VM**.
4. Select the VM to register from the drop-down list.

:::tip
Multi-selection is available.
:::

5. Click **Register**.
   The VM is registered with the load balancer.

  </TabItem>
  <TabItem value="api" label="API">

The `PUT /compute/spaces/{spaceId}/loadBalancers/{id}/backendMachines/link` command attaches a VM to a load balancer.
