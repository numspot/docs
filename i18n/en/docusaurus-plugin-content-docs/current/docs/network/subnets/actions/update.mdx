# Edit an attribute of a subnet

You can edit one attribute of a subnet: the `mapPublicIpOnLaunch` attribute.

This attribute determines whether a public IP (Internet Protocol) is automatically assigned to the network interfaces created in the subnet, including the network interfaces created when you launch a [VM](/docs/compute/concept/) (Virtual Machine) in a subnet. It is disabled by default.

To learn about the behaviour of the public IP assigned this way, see [About public IP](/docs/network/public-ip/concepts/).

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.subnet.update**

:::

 1. Log in to the Numspot console.
 2. From the left-hand side menu, click **Network** → **[VPC](/docs/network/vpc/concepts/)** → **VPC**.
 3. The list of VPC appears. Click the ID of the relevant VPC.
 4. The "VPC details" page appears.
 5. Below the VPC details, the "Subnets" section appears, containing the list of subnets associated with the VPC.
 6. On the VPC detailed page, identify the subnet from the "Subnets" section. In this section, you can:  
     \- manage the `tags`  
     \- add and edit the associated [Route Table](/docs/network/route-table/concepts/)

 :::info
 By clicking the **Edit** button, you can enable or disable the `mapPublicIpOnLaunch` attribute of the subnet, which automatically assigns a public IP to the network interfaces created in it, including when you launch a VM in the subnet.
