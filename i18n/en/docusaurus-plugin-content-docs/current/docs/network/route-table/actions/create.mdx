# Create a route table

You can create a [route table](/docs/network/route-table/concepts/) that you can associate with one or more subnets to control how their traffic is routed. Once your route table is created, you can add routes to it to customize the routing of the subnets it is associated with.

Each route table contains the `local` route, which routes traffic targeting an IP from the CIDR block of the [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud) locally. This route can be neither modified nor deleted.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.routeTable.create**

:::

1. Log in to the Numspot console.   
2. From the left-hand side menu, click **Network** → **VPC** → **VPC**. 
3.  Click the **Create a Route Table** button at the top right of the screen to open the pop-up.
4.  The pop-up opens and asks you to enter a route table name and to select the ID of the VPC (drop-down list containing all the IDs of the VPC you have access to) for which you are creating this route.
5.  Click **Create**.
