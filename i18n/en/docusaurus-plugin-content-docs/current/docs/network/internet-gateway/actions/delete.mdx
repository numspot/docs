# Delete an internet gateway

You can delete an [internet gateway](/docs/network/internet-gateway/concepts/) that you no longer need.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.internetGateway.delete**

:::

## Prerequisites

:::info
**Before you begin:** Detach the internet gateway from the [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud).
:::

You can delete a single internet gateway or delete several in a single action.

## Delete an internet gateway

1. Log in to the Numspot console.

2. In the left-hand side menu, click **Network** → **VPC** → **Internet Gateways**.


3. Identify the internet gateway you want to delete, then from the list of actions, click **Delete**.


    A new "Internet Gateway deletion" dialog box appears.


4. To continue, strong confirmation is required. Enter the name of the resource to delete in the corresponding field.

5. Click **Delete**. The internet gateway is deleted.

    A confirmation message "The Internet Gateway has been successfully deleted" appears.


## Delete several internet gateways

1. Log in to the Numspot console.

2. From the left-hand side menu, click **Network** → **VPC** → **Internet Gateways**.


3. Select the internet gateways you want to delete, then click **Delete**.


    A new "Internet Gateways deletion" dialog box appears.


4. To continue, strong confirmation is required. Enter the term **Delete** in the corresponding field.

5. Click **Delete**. The internet gateways are deleted.

    A confirmation message "The Internet Gateways have been successfully deleted" appears.
