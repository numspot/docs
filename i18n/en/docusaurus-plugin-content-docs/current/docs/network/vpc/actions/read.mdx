# Get information about your VPC

You can get information about one or more of your [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud), such as their CIDR (Classless Inter-Domain Routing) block or their allocation option.
Information about your VPC is also available from the [VM](/docs/compute/concept/) (Virtual Machine) themselves.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.vpc.get**

:::

[Example request: List all VPC ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/vpcs)

The `GET /compute/spaces/{spaceId}/vpcs/{id}` command lets you retrieve the information of a VPC.
