# Delete a VPC

You can delete an empty [VPC](/docs/network/vpc/concepts/) (Virtual Private Cloud) that you no longer need.

## Permissions

:::info
This action requires the following IAM (Identity and Access Management) permissions:

- **compute.vpc.delete**

:::

 :::info
 Before you begin, make sure to delete or detach all resources linked to the VPC, such as:
 * [VM](/docs/compute/concept/) (Virtual Machine)
 * subnets
 * public IP
 :::

 1. Log in to the Numspot console.

 2. From the left-hand side menu, click **Network** → **VPC** → **VPC**.

 3. The list of VPC appears.

 4. Identify the VPC to delete, then click **Actions**. An options dialog box appears.

 5. Click **Delete the VPC**. The VPC is deleted.
    :::warning
    If the VPC still has dependencies with other objects, the deletion will not be possible. Before continuing, make sure to delete or detach all dependencies, then delete the VPC.
    :::
