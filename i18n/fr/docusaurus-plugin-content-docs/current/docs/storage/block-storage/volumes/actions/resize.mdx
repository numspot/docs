# Augmenter la taille d'un volume

Vous pouvez augmenter la capacité de stockage d'un `volume` existant sans perdre les données stockées sur celui-ci.

Vous pouvez modifier la taille de tout type de `volume`, qu'il s'agisse d'un `volume` système sur lequel le système d'exploitation de la [VM (Virtual Machine)](/docs/compute/concept/) est installé, ou d'un `volume` secondaire de la VM.

:::info
La modification fonctionne que le `volume` soit attaché à une VM démarrée (modification **à chaud**) ou non (modification **à froid**). Elle est asynchrone : l'API renvoie la valeur précédente et un `taskId`, et la nouvelle taille est appliquée en quelques secondes à quelques minutes. Vous pouvez vérifier la taille actuelle du `volume` à tout moment depuis le dashboard **Volumes** ou avec la méthode `ReadVolumes`. Vous ne pouvez qu'augmenter la taille d'un `volume` : il n'est pas possible de la réduire.
:::

:::warning
Avant de modifier un `volume`, nous vous recommandons de créer un [snapshot](/docs/storage/block-storage/snapshots/actions/create/) de celui-ci, au cas où un problème surviendrait pendant le processus.
:::

## Changer le type d'un volume

Vous pouvez également changer le **type** d'un `volume` (Magnetic, Performance ou Enterprise) à tout moment, que le `volume` soit attaché à une VM démarrée ou non :

1. Depuis le menu latéral gauche, cliquez sur **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Sélectionnez le `volume` et cliquez sur le bouton de modification (**Modifier** / **Change tier** selon la langue de votre console).
3. Dans le champ "Type", sélectionnez le nouveau type.
4. Si vous sélectionnez **Enterprise**, vous devez également renseigner le nombre d'**IOPS** (de `100` à `13,000`, avec un ratio de performance maximum de 300 IOPS par Go).
5. Cliquez sur **Modifier**.

Le `volume` est alors modifié avec les caractéristiques de performance et la facturation du nouveau type. Pour en savoir plus, voir le [catalogue](/docs/catalog/concepts/).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.blockStorage.update**

:::

## Linux {#tabhead-linux}

### Augmenter la taille d'un volume

1. Depuis le menu latéral gauche, cliquez sur **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Sélectionnez le `volume`.
3. Cliquez sur **Modifier**.
4. Dans le champ "Taille", entrez la nouvelle taille du `volume` (supérieure à la taille actuelle).
5. Cliquez sur **Modifier**.

    La modification est asynchrone : la nouvelle taille est appliquée en quelques secondes à quelques minutes, que le `volume` soit attaché à une VM démarrée ou non.

### Étendre le système de fichiers dans la VM

La modification côté plateforme n'étend pas le système de fichiers du `volume`. À l'intérieur de la VM :

1. (optionnel) Pour afficher les périphériques blocs et leurs tailles, exécutez la commande suivante :
    ```bash
    $ lsblk
    ```
2. Si le `volume` utilise une table de partitions, étendez la partition (exemple pour la première partition du périphérique) :
    ```bash
    $ sudo growpart /dev/DEVICE_NAME 1
    ```
3. Redimensionnez le système de fichiers :
    - Pour redimensionner un système de fichiers ext4, exécutez la commande suivante :
    ```bash
    $ sudo resize2fs /dev/DEVICE_NAME
    ```
    - Pour redimensionner un système de fichiers XFS, exécutez la commande suivante :
    ```bash
    $ sudo xfs_growfs /MOUNT_POINT
    ```
4. (optionnel) Exécutez la commande `df -hT` pour visualiser les tailles de vos systèmes de fichiers.

Le système de fichiers du `volume` est configuré.

:::info
Pour les VM créées à partir d'une Image, le paquet cloud-init ajuste automatiquement le système de fichiers du `volume` système au prochain démarrage après que la taille de ce dernier a été modifiée. Pour en savoir plus, voir la documentation officielle cloud-init (en anglais).
:::

## Windows {#tabhead-windows}

### Augmenter la taille d'un volume

1. Depuis le menu latéral gauche, cliquez sur **Storage** → **[Block Storage](/docs/storage/block-storage/concepts/)** → **Volumes**.
2. Sélectionnez le `volume`.
3. Cliquez sur **Modifier**.
4. Dans le champ "Taille", entrez la nouvelle taille du `volume` (supérieure à la taille actuelle).
5. Cliquez sur **Modifier**.

    La modification est asynchrone : la nouvelle taille est appliquée en quelques secondes à quelques minutes, que le `volume` soit attaché à une VM démarrée ou non.

### Étendre le système de fichiers dans la VM

1. Connectez-vous à votre VM.
2. Cliquez sur le menu **Démarrer**, tapez "diskmgmt.msc" et cliquez sur le programme qui apparaît.
3. Faites un clic droit sur le `volume` et sélectionnez **Étendre le volume**.

    L'**Assistant Extension** du volume apparaît.

4. Conservez les informations par défaut et cliquez sur **Suivant**.
5. Cliquez sur **Terminer** pour valider.

    Le `volume` est configuré et son système de fichiers apparaît dans la liste "Gestion des disques".
