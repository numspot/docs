# Versions et cycle de vie

Numspot opère ses [instances Secret Manager](/docs/managed-services/secret-manager/concepts/) avec des versions stables d'OpenBao bénéficiant d'un suivi actif des correctifs de sécurité, en conformité avec les exigences de sécurité appliquées au service.

## Versions supportées

Les versions mineures suivantes sont supportées :

- **OpenBao 2.5**

Ce périmètre couvre les versions stables et activement maintenues par le projet OpenBao, avec un suivi continu des bulletins de sécurité.

:::note
Lors de la création d'une instance Secret Manager, la version la plus récente est sélectionnée par défaut. Pour plus d'informations, consultez [Créer une instance Secret Manager](/docs/managed-services/secret-manager/actions/create/).
:::

## Suivi des patches de sécurité

Les images utilisées pour les instances Secret Manager intègrent :

- Des mises à jour de correctifs (patch) appliquées régulièrement pour corriger les bugs et les failles de sécurité.
- Un suivi actif des vulnérabilités critiques et hautes.

Les mises à jour de correctifs sont appliquées automatiquement par Numspot et ne nécessitent aucune action de la part du client. Elles ne concernent que les versions patch (par exemple, `2.5.3` vers `2.5.4`), sans modification de la compatibilité des données.

:::info
Pour obtenir des informations sur les versions appliquées ou les correctifs récents, contactez le support Numspot.
:::

## Cycle de vie des versions (lifecycle)

### Politique de support

| Version | Statut du support | Fin de support Numspot estimée |
|---------|-------------------|--------------------------------|
| **2.5** | Active | À déterminer |

Le projet OpenBao ne maintient que la dernière version mineure à tout moment. Le statut de support est aligné sur les annonces du projet OpenBao. Numspot suit la politique OpenBao concernant le support des versions mineures.

### Notification de fin de support

Numspot notifie ses clients **plusieurs mois avant la fin de support** d'une version mineure. Cette notification permet aux clients de planifier la mise à jour vers une version plus récente.

## Mises à jour mineures

Les mises à jour mineures (par exemple, d'OpenBao 2.5 vers OpenBao 2.6) entraînent une mise à jour de l'instance Secret Manager. Numspot recommande de tester la compatibilité de vos workflows avant de procéder à une mise à jour mineure.

:::warning
La mise à jour de version peut entraîner une indisponibilité temporaire de l'instance Secret Manager. Il est de la responsabilité du client de vérifier que ses workflows sont compatibles avec la nouvelle version avant toute migration.
:::
