# Supprimer une règle DLP

Supprimez définitivement une [règle DLP](/docs/managed-services/dlp/concepts). Cette action est irréversible. Si la règle est incluse dans une policy publiée, vous devez d'abord modifier la policy pour la retirer.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **rule_editor**

:::

:::warning
La suppression est définitive. Les règles déjà publiées dans un ruleset ne sont pas affectées — seules les règles en brouillon sont supprimées.
:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Rules** dans le menu latéral.
2. Cliquez sur l'icône de suppression (corbeille) sur la ligne de la règle à supprimer.
3. Confirmez la suppression dans la boîte de dialogue.

<TabItem value="api" label="API">

La requête `DELETE /api/v1/rules/{id}` permet de supprimer une [règle DLP](/docs/managed-services/dlp/concepts).

### Exemple de réponse

```text
HTTP/1.1 204 No Content
```
