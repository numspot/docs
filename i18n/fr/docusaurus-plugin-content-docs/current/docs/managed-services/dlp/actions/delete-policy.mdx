# Supprimer une policy DLP

Supprimez définitivement une [policy DLP](/docs/managed-services/dlp/concepts). Cette action est irréversible. Seules les policies en brouillon peuvent être supprimées.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **rule_editor**

:::

:::warning
La suppression est définitive. Les policies déjà publiées dans un ruleset ne sont pas affectées — seules les policies en brouillon sont supprimées.
:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Policies** dans le menu latéral.
2. Cliquez sur l'icône de suppression (corbeille) sur la ligne de la policy à supprimer.
3. Confirmez la suppression dans la boîte de dialogue.

<TabItem value="api" label="API">

La requête `DELETE /api/v1/policies/{id}` permet de supprimer une [policy DLP](/docs/managed-services/dlp/concepts).

### Exemple de réponse

```text
HTTP/1.1 204 No Content
```
