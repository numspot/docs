# Consulter la piste d'audit DLP

Consultez la piste d'audit pour suivre toutes les actions d'administration effectuées sur le service [DLP](/docs/managed-services/dlp/concepts). Chaque action — création, modification, suppression de [règles DLP](/docs/managed-services/dlp/concepts), [policies DLP](/docs/managed-services/dlp/concepts), [détecteurs DLP](/docs/managed-services/dlp/concepts), publication de [ruleset](/docs/managed-services/dlp/concepts) et gestion des utilisateurs — est enregistrée avec l'utilisateur, l'horodatage et les détails de l'action.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **viewer**

:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Audit Logs** dans le menu latéral.

### Filtrer les événements

Utilisez les filtres disponibles pour affiner la recherche :

- **Action** : filtrer par type d'action — `rule_create`, `rule_update`, `rule_delete`, `ruleset_publish`, `ruleset_rollback`, `detector_create`, `detector_update`, `detector_delete`, `policy_create`, `policy_update`, `policy_delete`, `user_create`, `user_update`, `user_delete`, `user_password_reset` ;
- **Time range** : filtrer par période.

### Détails d'un événement

Chaque événement affiche :

- l'utilisateur ayant effectué l'action ;
- le type d'action ;
- la cible de l'action (règle, détecteur, policy, utilisateur, ruleset) ;
- le nom de la cible ;
- les détails de l'action ;
- l'horodatage.

</TabItem>
<TabItem value="api" label="API">

La requête `GET /api/v1/audit` permet de consulter la piste d'audit.

### Paramètres de requête

| Paramètre | Description |
|-----------|-------------|
| `action` | Filtrer par type d'action |
| `time_start` | Date de début de la période (ISO 8601) |
| `time_end` | Date de fin de la période (ISO 8601) |
