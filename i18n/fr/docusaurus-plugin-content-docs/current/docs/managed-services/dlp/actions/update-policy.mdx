# Modifier une policy DLP

Modifiez une [policy DLP](/docs/managed-services/dlp/concepts) existante pour ajuster ses règles, leur ordre ou l'action par défaut. La modification crée une nouvelle version de la policy en tant que brouillon. Pour l'activer, publiez-la dans un [ruleset](/docs/managed-services/dlp/concepts) (ensemble de règles).

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **rule_editor**

:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Policies** dans le menu latéral.
2. Cliquez sur le nom de la policy à modifier dans la liste.

### Éléments modifiables

Vous pouvez modifier les éléments suivants :

| Élément | Description |
|---------|-------------|
| Règles | Ajouter ou retirer des règles de la policy |
| Ordre des règles | Réordonner les règles par glisser-déposer — l'ordre détermine la séquence d'évaluation |
| Action par défaut | Modifier l'action par défaut (`pass` ou `block`) |

### Enregistrement

Cliquez sur **Save as Draft** pour enregistrer les modifications en tant que brouillon. La policy apparaît dans la liste avec le statut "Draft". Pour activer la policy modifiée, publiez-la dans un [ruleset](/docs/managed-services/dlp/concepts).

<TabItem value="api" label="API">

La requête `PUT /api/v1/policies/{id}` permet de modifier une [policy DLP](/docs/managed-services/dlp/concepts) existante. Le corps de la requête est identique à celui de la création.

### Exemple de requête

```json
{
  "name": "mistral-prod-policy",
  "description": "Policy de production pour Mistral (mise à jour)",
  "platform_type": "mistral-platform",
  "rule_ids": [
    "rule-550e8400",
    "rule-a1b2c3d4",
    "rule-e5f6g7h8"
  ],
  "default_action": "pass"
}
```

### Exemple de réponse

```json
{
  "id": "policy-9f8e7d6c",
  "name": "mistral-prod-policy",
  "description": "Policy de production pour Mistral (mise à jour)",
  "platform_type": "mistral-platform",
  "rule_ids": [
    "rule-550e8400",
    "rule-a1b2c3d4",
    "rule-e5f6g7h8"
  ],
  "default_action": "pass",
  "draft": true,
  "version": 2,
  "created_at": "2026-08-27T10:00:00Z",
  "updated_at": "2026-08-27T11:30:00Z"
}
```
