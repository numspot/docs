# Supprimer un détecteur personnalisé DLP

Supprimez définitivement un [détecteur DLP](/docs/managed-services/dlp/concepts) personnalisé. Cette action est irréversible. Si le détecteur est référencé dans des règles existantes, vous devez d'abord modifier ces règles.

## Permissions

:::info
Cette action nécessite le rôle [DLP](/docs/managed-services/dlp/concepts) (Data Loss Prevention) suivant :

- **detector_editor**

:::

:::warning
La suppression est définitive. Si des règles actives référencent ce détecteur via `@custom:<id>`, elles échoueront lors de l'évaluation. Vérifiez les dépendances avant de supprimer un détecteur.
:::

1. Dans la console [DLP](/docs/managed-services/dlp/concepts), cliquez sur **Detectors** dans le menu latéral.
2. Cliquez sur l'onglet **Custom** pour afficher les détecteurs personnalisés.
3. Cliquez sur l'icône de suppression (corbeille) sur la ligne du détecteur à supprimer.
4. Confirmez la suppression dans la boîte de dialogue.

<TabItem value="api" label="API">

La requête `DELETE /api/v1/detectors/custom/{id}` permet de supprimer un [détecteur DLP](/docs/managed-services/dlp/concepts) personnalisé.

### Exemple de réponse

```text
HTTP/1.1 204 No Content
```
