# Lister les groupes de nœuds d'un cluster Kubernetes

Obtenez la liste des groupes de nœuds (node pools) d'un [cluster Kubernetes](/docs/managed-services/kubernetes/concepts/).

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **kubernetes.cluster.get**

:::
<Tabs>

<TabItem value="console" label="Console" default>

## Console {#tabhead-console}


1. Depuis le menu latéral gauche, cliquez sur **Services managés** → **Kubernetes** pour accéder à la liste des clusters Kubernetes.

   ![Menu Services managés](/img/console/managed-services/fr-menu-managed-services.png)

2. Cliquez sur le nom d'un cluster pour accéder à sa page de détails.

3. La section **Node pools** affiche la liste des groupes de nœuds du cluster avec leurs informations :
   - Nom du groupe de nœuds
   - Statut
   - Zone de disponibilité
   - Type de nodes
   - Volume système
   - Nombre de nodes

   ![Liste des node pools](/img/console/managed-services/kubernetes/fr-kubernetes-nodepools-list.png)

Le statut d'un groupe de nœuds peut prendre les valeurs suivantes :

| Statut | Description |
|--------|-------------|
| En cours | Le groupe de nœuds fonctionne normalement |
| En attente | Le groupe de nœuds est en cours de création ou de mise à jour |
| Échec | Une erreur est survenue |

</TabItem>

<TabItem value="api" label="API">

## API {#tabhead-api}

    Utilisez la route `GET /kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools` pour lister les groupes de nœuds d'un cluster Kubernetes.

### Exemple de réponse

    ```json
    {
      "items": [
        {
          "id": "nodepool-001-e29b-41d4",
          "name": "worker-nodepool-1",
          "availabilityZone": "eu-west-2a",
          "nodeProfile": "medium",
          "replicas": 3,
          "rootDisk": {
            "size": 50,
            "iops": 3000,
            "type": "enterprise"
          },
          "status": {
            "state": "RUNNING",
            "message": "NodePool is healthy"
          }
        }
      ]
    }
    ```

    [Voir la spécification complète](/openapi/#tag/kubernetes/GET/kubernetes/spaces/{spaceId}/clusters/{clusterId}/nodePools)
</TabItem>
