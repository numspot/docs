# Supprimer un cluster Kubernetes

Supprimez un [cluster Kubernetes](/docs/managed-services/kubernetes/concepts/) au sein de votre espace, quel que soit son statut.

:::info
**Prérequis :** Vérifiez que le cluster n'est pas en cours d'utilisation avant de le supprimer.
:::

:::warning
Cette action est irréversible. Une fois le cluster supprimé, toutes ses ressources et configurations associées seront définitivement perdues.
:::

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **kubernetes.cluster.delete**

:::

1. Depuis le menu latéral gauche, cliquez sur **Services managés** → **Kubernetes** pour accéder à la liste des clusters Kubernetes.

2. Dans la liste, repérez le cluster à supprimer, cliquez sur le bouton **Actions** situé sur sa ligne, puis sur **Supprimer**.

3. Dans la fenêtre « Suppression d'un cluster », saisissez le nom exact du cluster dans le champ « Nom du cluster », puis cliquez sur **Supprimer définitivement**.

Le cluster passe à l'état « Suppression en cours » dans la liste.

## API {#tabhead-api}

La requête `DELETE /kubernetes/spaces/{spaceId}/clusters/{clusterId}` permet de supprimer un cluster Kubernetes. 
Le cluster passe dans l'état « deleting » le temps de la suppression.

### Exemple de réponse

```text
HTTP/1.1 204 No Content
```

[Voir la spécification complète](/openapi/#tag/kubernetes/DELETE/kubernetes/spaces/{spaceId}/clusters/{clusterId})
