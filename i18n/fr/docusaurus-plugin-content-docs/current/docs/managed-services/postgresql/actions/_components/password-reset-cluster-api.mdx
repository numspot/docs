La requête `PUT /postgresql/spaces/{spaceId}/clusters/{clusterId}/password/reset` permet de générer un nouveau mot de passe pour l'utilisateur principal d'un [cluster PostgreSQL](/docs/managed-services/postgresql/concepts/).
Le nouveau mot de passe est retourné directement dans la réponse. Il devient actif une fois que le statut du cluster n'est plus `RESETTING_PASSWORD`.

### Exemple de réponse

```json
{
  "password": "Kj8#mP2$vL5@nQ9x"
}
```
