# Supprimer un cluster PostgreSQL

Vous pouvez supprimer un [cluster PostgreSQL](/docs/managed-services/postgresql/concepts/) au sein de votre espace, quel que soit son statut.

:::warning
Vérifiez que le cluster n'est pas en cours d'utilisation avant de le supprimer.
:::

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **postgresql.cluster.delete**

:::

1. Depuis le menu latéral gauche, cliquez sur **Services Managés** → **PostgreSQL** → **Clusters** pour accéder à la liste des clusters PostgreSQL.

2. Dans la liste, repérez le cluster à supprimer, cliquez sur le bouton **Actions** situé sur sa ligne, puis sur **Supprimer**.

   Vous pouvez aussi ouvrir la page de détails du cluster et cliquer sur le bouton **Supprimer** situé en haut à droite.

3. Dans la fenêtre "Supprimer le cluster", saisissez le nom exact du cluster dans le champ de "Confirmation forte", puis cliquez sur **Supprimer**.

   Le cluster passe à l'état "Suppression en cours" dans la liste.

## API {#tabhead-api}

    La requête `DELETE /postgresql/spaces/{spaceId}/clusters/{clusterId}` permet de supprimer un cluster PostgreSQL.
    Le cluster passe dans l'état `DELETING` le temps de la suppression.

    ### Exemple de réponse

    ```text
    HTTP/1.1 204 No Content
    ```

    [Voir la spécification complète](/openapi/#tag/postgresql/DELETE/postgresql/spaces/{spaceId}/clusters/{clusterId})
