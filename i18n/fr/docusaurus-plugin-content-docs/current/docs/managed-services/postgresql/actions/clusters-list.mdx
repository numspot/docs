# Lister les clusters PostgreSQL

Vous pouvez lister l'ensemble des [clusters PostgreSQL](/docs/managed-services/postgresql/concepts/) au sein de votre espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **postgresql.cluster.get**

:::
<Tabs>

<TabItem value="api" label="API" default>

## API {#tabhead-api}

    La requête `GET /postgresql/spaces/{spaceId}/clusters` permet de lister les clusters PostgreSQL d'un espace.

### Paramètres

| Paramètre | Type   | Requis | Description                      |
| --------- | ------ | ------ | -------------------------------- |
| spaceId   | string | Oui    | Identifiant de l'espace Numspot. |

### Exemple de réponse

    ```json
    {
      "items": [
        {
          "id": "123e4567-e89b-42d3-a456-426614174000",
          "name": "mon-cluster-postgresql",

          "majorVersion": "17",
          "fullVersion": "17.2",
          "status": {
            "state": "RUNNING",

          "nodeConfiguration": {
    ```
