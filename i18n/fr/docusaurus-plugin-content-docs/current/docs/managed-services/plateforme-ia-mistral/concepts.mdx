# Concepts

## Introduction

Le **service managé Plateforme IA Mistral** permet aux entreprises d'accéder à une
plateforme d'intelligence artificielle générative (modèles de langage Mistral)
hébergée dans un environnement cloud souverain, sans avoir à gérer l'infrastructure
[GPU](/docs/compute/gpu/concept) ni le déploiement des modèles sous-jacents.

**Cas d'utilisation** :

- Assistants conversationnels et agents internes.
- Génération, résumé et classification de texte.
- Recherche augmentée (RAG) et exploitation de données documentaires.

## Comment obtenir la Plateforme IA Mistral

Contrairement aux autres services managés (PostgreSQL, Kubernetes, Container
Registry) que vous activez en autonomie depuis la Console, le service managé
Plateforme IA Mistral est mis à disposition **sur demande, via notre service
commercial**.

:::info Pour souscrire à la Plateforme IA Mistral
Contactez notre **service commercial** pour étudier votre besoin et déclencher la
mise à disposition de votre instance :

- E-mail : [sales-eu@numspot.com](mailto:sales-eu@numspot.com)
- Ou sollicitez votre **Technical Account Manager (TAM)**.

Précisez l'**URL souhaitée** pour votre instance ainsi que le ou les **modèles
Mistral** souhaités. Vos identifiants d'accès vous seront ensuite transmis de
manière sécurisée.
:::
