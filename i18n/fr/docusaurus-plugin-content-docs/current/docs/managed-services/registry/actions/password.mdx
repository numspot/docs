# Mot de passe administrateur du Container Registry

Vous pouvez récupérer le mot de passe administrateur de votre Container Registry au sein de votre espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **registry.instance.get**

:::
<Tabs>

{/* </TabItem> */}
<TabItem value="api" label="API" default>

## API {#tabhead-api}

    La requête `GET /registry/spaces/{spaceId}/registries/{registryId}/password` permet de récupérer le mot de passe administrateur d'un Container Registry.

    ### Exemple de réponse

    ```json
    {
      "password": "Rg7#kT9$pM3@wX5yZ8"
    }
    ```

    [Voir la spécification complète](/openapi/#tag/registry/GET/registry/spaces/{spaceId}/registries/{registryId}/password)

</TabItem>
</Tabs>

:::note
Le Container Registry est préconfiguré avec un unique compte administrateur, dont le nom d'utilisateur est figé et ne peut pas être modifié : il s'agit toujours de `admin`. Seul le mot de passe est généré. Connectez-vous à Harbor avec le nom d'utilisateur `admin` et le mot de passe renvoyé par cette action.
:::
