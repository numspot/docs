# Versions disponibles de Harbor

Vous avez la possibilité d'obtenir la liste des versions mineures disponibles de Harbor pour créer votre Registry.

Lors de la création, vous aurez besoin de spécifier la version \<majeure\>.\<mineure\> de Harbor que vous souhaitez utiliser.
Numspot se charge de gérer les versions des correctifs afin de toujours vous offrir une version la plus à jour.

## Permissions

Aucune permission **IAM** (Identity and Access Management) n'est requise pour effectuer cette action.

## API {#tabhead-api}

        La requête `GET /registry/versions` permet d'obtenir la liste des versions mineures de Harbor proposées par Numspot.

        ### Exemple de réponse

        ```json
        {
          "items": ["2.13", "2.14"]
        }
        ```

        [Voir la spécification complète](/openapi/#tag/registry/GET/registry/versions)
