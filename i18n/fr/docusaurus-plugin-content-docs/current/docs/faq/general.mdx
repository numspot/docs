# FAQ - Général

Nous avons rassemblé ici les réponses aux questions les plus fréquemment posées par nos utilisateurs.

## 1. Qu'est-ce que Numspot ?
Numspot propose une offre de cloud indépendant, souverain et robuste. Prônant la transparence et la réversibilité, ses services sont majoritairement basés sur des technologies Open Source et des solutions européennes. Plus d'infos sur le site internet [numspot.com](https://numspot.com).

## 2. Comment puis-je contacter le support technique ? 
Vous pouvez contacter le support technique via :

- **E-mail** : support-client@numspot.com (pour la création de compte, les déclarations d'incidents et les requêtes).
- **Interface de ticketing Web** : [support.numspot.com](https://support.numspot.com) (sous condition de création préalable d'un compte).
- **Numéro de téléphone** : +33 1 59 03 50 06

## 3. Quand puis-je solliciter le support ?
Les canaux de sollicitation du support Numspot sont disponibles **24/7** (Interface de ticketing Web et e-mail).  
Les tickets de support sont traités uniquement durant les jours ouvrés entre **9h et 18h**.
