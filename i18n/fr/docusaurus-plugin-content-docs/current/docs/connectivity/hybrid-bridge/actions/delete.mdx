# Supprimer un Hybrid Bridge

Vous pouvez supprimer un bridge pour mettre fin à la communication entre votre [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) et les services managés.

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **connectivity.bridge.delete**

:::
<Tabs>
  <TabItem value='api' label="API" default>

## API {#tabhead-api}

La commande `DELETE /connectivity/spaces/{spaceId}/bridges/{id}` supprime le bridge.

[Exemple de requête : Suppression d'un Hybrid Bridge](/openapi/#tag/connectivity/DELETE/connectivity/spaces/{spaceId}/bridges/{id})
