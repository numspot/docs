# Obtenir des informations sur vos Hybrid Bridges

Vous pouvez obtenir des informations sur un ou plusieurs bridges.

Par défaut, cette action décrit tous vos bridges.

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **connectivity.bridge.get**

:::
<Tabs>
  <TabItem value='api' label="API" default>

## API {#tabhead-api}

La commande `GET /connectivity/spaces/{spaceId}/bridges` permet de lister tous vos bridges.

[Exemple de requête : Lister tous les Hybrid Bridges](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/bridges)

La commande `GET /connectivity/spaces/{spaceId}/bridges/{id}` permet de récupérer les informations d'un bridge spécifique.

[Exemple de requête : Récupérer les informations d'un Hybrid Bridge](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/bridges/{id})
