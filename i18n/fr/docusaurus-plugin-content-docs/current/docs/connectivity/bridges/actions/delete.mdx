# Supprimer un bridge

Vous pouvez supprimer un bridge pour mettre fin à la communication entre les deux ressources connectées.

Avant de supprimer un bridge, retirez de vos [route tables (tables de routage)](/docs/network/route-table/concepts/) les routes qui le ciblent, sinon le trafic vers la connexion supprimée reste en trou noir.

## Permissions

:::info
Cette action nécessite la permission **IAM** (Identity and Access Management) suivante :

- **connectivity.bridge.delete**

:::

<Tabs>
<TabItem value="api" label="API" default>

## API {#tabhead-api}

La commande `DELETE /connectivity/spaces/{spaceId}/bridges/{id}` supprime le bridge.

[Exemple de requête : Suppression d'un Bridge](/openapi/#tag/connectivity/DELETE/connectivity/spaces/{spaceId}/bridges/{id})
