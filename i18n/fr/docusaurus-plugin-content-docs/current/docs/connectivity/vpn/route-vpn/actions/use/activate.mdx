# Activer la propagation des routes

Vous pouvez activer la propagation des routes vers une [route table (table de routage)](/docs/network/route-table/concepts/) pour qu'elle contienne les routes associées à une connexion **VPN** (Virtual Private Network).

Cette action actualise automatiquement la route table avec les routes de la connexion VPN, et les dirige vers la [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/). Sinon, vous devez ajouter manuellement chaque route à la route table. La propagation des routes est facultative, et fonctionne avec le routage statique ou dynamique. Vous pouvez utiliser une route table par défaut ou personnalisée.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.vpnconnection.update**

:::

## Console {#tabhead-console}


:::warning
### Avant de commencer
* Créez un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/).
* Créez une virtual gateway.
* Liez la virtual gateway au VPC.
* (optionnel) Créez une route table personnalisée pour le subnet (sous-réseau) du VPC.
:::

1. Cliquez dans le dashboard **Route Tables** pour faire apparaître des cases à cocher.
2. Sélectionnez la route table vers laquelle vous voulez activer la propagation des routes.
   La route table est sélectionnée et un menu d'actions apparaît.
3. Cliquez sur **Activer la propagation des routes**.
   La boîte de dialogue "Activer la propagation par Virtual Gateway" s'affiche.
4. Dans la liste "Virtual Gateway", sélectionnez la virtual gateway dont vous voulez propager les routes.
5. Cliquez sur **Activer**.
   La propagation des routes est activée.

## API {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/routeTables/{id}/routePropagation` configure la propagation des routes vers une table de routage spécifiée d'un VPC par une virtual gateway.

[Exemple de requête : Activation de la propagation des routes](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/routeTables/{id}/routePropagation)
