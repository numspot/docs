# Créer une connexion VPN

Vous pouvez créer une connexion **VPN** (Virtual Private Network) entre votre réseau d'entreprise et un de vos [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) dans le Cloud Numspot.

Cette action crée un tunnel VPN sécurisé entre une [client gateway (passerelle client)](/docs/connectivity/vpn/client-gateway/concepts/) et une [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/). La connexion VPN reste dans l'état `pending` jusqu'à ce que du trafic soit généré à partir de la client gateway.

Une fois la connexion VPN créée, vous devez la configurer.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.vpnconnection.create**

:::

:::info
Avant de commencer :
- Créez les ressources nécessaires
- Assurez-vous que la virtual gateway est dans l'état `available`
:::

## API {#tabhead-api}


La commande `POST /connectivity/spaces/{spaceId}/vpnConnections` crée une connexion VPN entre une virtual gateway spécifiée et une client gateway spécifiée.
Vous pouvez créer une seule connexion VPN entre une virtual gateway et une client gateway.

[Exemple de requête : Création d'une VPN Connection](/openapi/#tag/connectivity/POST/connectivity/spaces/{spaceId}/vpnConnections)
