# Obtenir des informations sur vos connexions VPN

Vous pouvez obtenir des informations sur une ou plusieurs de vos connexions **VPN** (Virtual Private Network).

Par défaut, cette action décrit toutes vos connexions VPN.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.vpnconnection.get**

:::

<Tabs>
<TabItem value="console" label="Console" default>

## Console {#tabhead-console}


1. Dans la console, naviguez vers **Réseau** → **VPC** → **VPN Connections**.
2. La liste de toutes vos connexions VPN s'affiche avec leurs informations principales :
   - ID
   - [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/)
   - [client gateway (passerelle client)](/docs/connectivity/vpn/client-gateway/concepts/)
   - État

</TabItem>
<TabItem value="api" label="API">

## API {#tabhead-api}


La commande `GET /connectivity/spaces/{spaceId}/vpnConnections` permet de lister vos connexions VPN.

[Exemple de requête : Lister toutes vos VPN Connections](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/vpnConnections)

La commande `GET /connectivity/spaces/{spaceId}/vpnConnections/{id}` permet de récupérer des informations concernant une connexion VPN.

[Exemple de requête : Récupérer les informations d'une VPN Connection](/openapi/#tag/connectivity/GET/connectivity/spaces/{spaceId}/vpnConnections/{id})

</TabItem>
