# Créer une virtual gateway

Vous pouvez créer une [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/) à attacher à un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/). Vous pouvez ensuite mettre en place une connexion **VPN** (Virtual Private Network) entre ce VPC et une [client gateway (passerelle client)](/docs/connectivity/vpn/client-gateway/concepts/).

Vous pouvez créer la virtual gateway avant ou après avoir créé le VPC.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **connectivity.bridge.create**

:::

## API {#tabhead-api}


La commande `POST /connectivity/spaces/{spaceId}/virtualGateways` crée une virtual gateway.
Une virtual gateway est le point d'accès du côté du VPC d'une connexion VPN.

[Exemple de requête : Création d'une virtual gateway](/openapi/#tag/connectivity/POST/connectivity/spaces/{spaceId}/virtualGateways)
