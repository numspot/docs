# Support technique

Le support technique de Numspot est disponible pour vous accompagner au quotidien et répondre à vos questions via les canaux suivants :

- Interface de ticketing Web : https://support.numspot.com ;
- E-mail : support-client@numspot.com ;
- Numéro de téléphone : +33 1 59 03 50 06.

## État des services

Pour consulter l'état des services Numspot en temps réel et suivre les incidents en cours, consultez la page de statut : https://status.numspot.com/posts/dashboard.

## Heures de service

Les tickets de support sont traités les jours ouvrés, de 9 h à 18 h.

Le service téléphonique est accessible les jours ouvrés, de 9 h à 18 h, sous réserve de la disponibilité des conseillers.

## Demandes de support

:::info
Pour soumettre une demande de support et ouvrir un ticket via le web, vous devez d'abord envoyer une demande de création de compte support à l'adresse suivante : support-client@numspot.com, en incluant les informations de la personne concernée (nom, prénom, adresse e-mail).
:::

1. Une fois votre compte créé, vous recevrez un e-mail vous invitant à vous rendre sur le lien suivant : https://support.numspot.com. Sur la page de connexion, cliquez sur le lien "Mot de passe oublié".

![login](/img/support/create_support_account.png)

2. Saisissez l'adresse e-mail que vous nous avez communiquée et cliquez sur le bouton **Envoyer**. Vous recevrez ensuite un e-mail contenant un lien de réinitialisation.

![login2](/img/support/create_support_account01.png)

3. Cliquez sur le lien. Vous serez redirigé vers la page de réinitialisation où vous pourrez saisir un nouveau mot de passe. Saisissez et confirmez votre nouveau mot de passe, puis cliquez sur le bouton **Sauvegarder le nouveau mot de passe**.

![login3](/img/support/create_support_account02.png)

4. Après avoir modifié votre mot de passe, cliquez sur le lien "retour vers l'écran de connexion".

![login4](/img/support/create_support_account03.png)

5. Une fois connecté, vous pourrez ouvrir un nouveau ticket en fournissant les informations suivantes :

- Type de la demande ;
- Catégorie ;
- Titre ;
- Description ;
- `Space ID` ;
- Produits ;
- Zone.

6. Vous pourrez suivre l'avancement de votre demande depuis la page "Tickets" de votre compte.
