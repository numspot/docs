# Supprimer un security group

Vous pouvez supprimer un [security group (groupe de sécurité)](/docs/compute/security-groups/concepts/concept-sg/) que vous avez créé si celui-ci n'est plus utilisé par aucune [VM (Virtual Machine)](/docs/compute/concept/) ou dans aucune règle de security group, et s'il ne contient aucune règle.

Vous ne pouvez pas supprimer les security groups par défaut.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.securityGroup.delete**

:::

## Console {#tabhead-console}

   :::info
   **Avant de commencer :** assurez-vous que le security group que vous souhaitez supprimer : 
   * n'est associé à aucune VM ;
   * n'est référencé comme security group source ou destination dans aucune règle de security group ;
   * ne contient aucune règle.

   :::

   1. Connectez-vous sur la console Numspot. 
   2. Depuis le menu latéral gauche, cliquez sur **Compute** → **Security Groups**.

   3. Pour supprimer un security group, 2 options sont possibles :
      * sélectionnez le security group que vous voulez supprimer puis cliquez sur le bouton "Supprimer" en surbrillance. Une boîte de dialogue de confirmation apparaît.
      * sur le menu déroulant d'actions du security group, cliquez sur **Supprimer**. Une boîte de dialogue de confirmation apparaît. 

   4. Cliquez sur le bouton **Supprimer**.

   5. Un message de confirmation s'affiche en bas indiquant que le security group est supprimé et la boîte de dialogue se ferme.

La commande `DELETE /compute/spaces/{spaceId}/securityGroups/{id}` supprime un security group spécifié. Vous ne pouvez pas supprimer un security group associé à une VM ou référencé dans une règle d'un autre security group.

[Exemple de requête : Suppression d'un Security Group](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/securityGroups/{id})
