# Retirer des règles d'un security group

Vous pouvez retirer des règles pour les flux entrants ou sortants à tout moment, même les règles initiales contenues dans les [security groups (groupes de sécurité)](/docs/compute/security-groups/concepts/concept-sg/) par défaut ou que vous créez. Une fois la règle retirée, vos modifications sont automatiquement appliquées et les flux correspondants ne sont plus autorisés.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.securityGroup.update**

:::

   2. Depuis le menu latéral gauche, cliquez sur **Compute** → **Security Groups**.

   3. Cliquez sur l'ID du security group auquel vous voulez retirer une règle.

## API {#tabhead-api}

La commande `DELETE /compute/spaces/{spaceId}/securityGroups/{id}/rules` supprime une ou plusieurs règles entrantes ou sortantes d'un security group. Pour que la règle soit supprimée, les valeurs spécifiées dans la demande de suppression doivent correspondre exactement à celles de la règle existante.

Dans le cas des protocoles TCP (Transmission Control Protocol) et UDP (User Datagram Protocol), il est nécessaire d'indiquer le port de destination ou la plage de ports. Dans le cas du protocole ICMP (Internet Control Message Protocol), vous devez spécifier les numéros de type et de code ICMP.

Les règles, ou autorisations IP (Internet Protocol), se composent du protocole, de la plage IP ou du security group source.

Pour supprimer l'accès sortant à un security group de destination, il est recommandé d'utiliser un ensemble d'autorisations IP. Il est également recommandé de spécifier le protocole dans cet ensemble d'autorisations IP.

[Exemple de requête : Suppression d'une règle d'un Security Group](/openapi/#tag/compute/DELETE/compute/spaces/{spaceId}/securityGroups/{id}/rules)
