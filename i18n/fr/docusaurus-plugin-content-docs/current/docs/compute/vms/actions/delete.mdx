# Supprimer une VM

Vous pouvez supprimer une [VM (Virtual Machine)](/docs/compute/concept/) dont vous n'avez plus besoin. Supprimer une VM libère les ressources matérielles correspondantes. La VM ne peut donc pas être récupérée. Vous pouvez également spécifier que la VM est supprimée lorsque vous l'arrêtez avec la commande du système d'exploitation en activant l'attribut InstanceInitiatedShutDownBehavior.

:::warning
L'action "Supprimer" est irréversible. Si vous confirmez cette action, la VM sera définitivement supprimée, ce qui entraînera les conséquences suivantes :
- Les ressources rattachées à la VM seront libérées ;
- Les données stockées dans la mémoire seront effacées ;
- En cas d'IP publique rattachée, elle sera libérée mais restera allouée au compte ;
- Le comportement des volumes de [stockage bloc (block storage)](/docs/storage/block-storage/concepts/) dépend du block device mapping.
:::

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **compute.vm.delete**

:::

## API {#tabhead-api}

    La commande `DELETE /compute/spaces/{spaceId}/vms/{id}` permet de mettre fin à une VM spécifiée.

    Cette opération est idempotente, ce qui signifie que tous les appels réussissent même si vous terminez une VM plus d'une fois.

    En d'autres termes, si vous effectuez plusieurs demandes de terminaison pour une même VM, seule la première demande sera prise en compte. Les demandes suivantes n'auront aucun effet, car la VM aura déjà été terminée.

    [Exemple de requête : Suppression d'une VM](/openapi/#tag/compute/DELETE/compute/spaces/%7BspaceId%7D/vms/%7Bid%7D)
  </TabItem>
