# Consulter la sortie de la console d'une VM

Vous pouvez afficher la sortie de la console d'une [VM (Virtual Machine)](/docs/compute/concept/) pour diagnostiquer des problèmes de kernel ou des erreurs système. La console affiche les 64 Kio les plus récents de la sortie. Sur les VM Windows, la console est accessible uniquement lors du premier démarrage et ne fournit aucune sortie après le premier redémarrage.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vm.get**

:::

1. Accédez à la VM

   1. Depuis le menu latéral gauche, cliquez sur **Compute** → **VM** pour accéder à la liste des VM.

   2. Cliquez sur l'ID de la VM pour accéder à la page de détails.

2. Consultez la console

   1. Dans la section Général, cliquez sur "Voir la console".

   2. Cochez "Rafraîchissement automatique" si nécessaire ou sur "Rafraîchir".

## API {#tabhead-api}

La commande `GET /compute/spaces/{spaceId}/vms/{id}/consoleOutputs` permet d'obtenir la sortie de la console pour une VM. Cette console fournit la sortie la plus récente de 64 Kio.

:::warning
Sur les VM Windows, la console n'est gérée qu'au premier démarrage. Aucune sortie ne sera renvoyée après ce premier démarrage.
:::

[Exemple de requête : Récupérer la sortie console de la VM](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/vms/{id}/consoleOutputs)
