# Modifier un attribut d'une VM

Les actions possibles sur une [VM (Virtual Machine)](/docs/compute/concept/) Numspot dépendent de son état actuel :
- Pour modifier l'attribut Type de VM (`Type`, `UserData`, `Performance` et `NestedVirtualization`), vous devez arrêter la VM ;
- Les autres attributs peuvent être modifiés lorsque la VM est en exécution ou à l'arrêt.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vm.update**

:::

Depuis la console, la modification des attributs d'une VM se fait sur une page unique **Modification d'une VM**.

1. Depuis le menu latéral gauche, cliquez sur **Compute** → **VM** ;
2. Sur la ligne de la VM concernée, ouvrez le menu **Actions**, puis cliquez sur **Modifier la VM**.

   La page **Modification d'une VM** apparaît. Le récapitulatif de droite (image, type, réseau, security group, key pair) est en lecture seule ;
3. Ajustez les attributs modifiables :
   - **Nom de la VM** ;
   - **Comportement à l'arrêt** : "Stop" (la VM s'arrête), "Redémarrage" (la VM redémarre automatiquement) ou "Supprimer" (la VM est supprimée) ;
   - **Protection contre la suppression** : lorsqu'elle est cochée, la VM ne peut pas être supprimée ;
4. Cliquez sur **Modifier la VM** pour appliquer les modifications.

:::info
La modification des **security groups** associés et du **type (gabarit)** d'une VM n'est pas disponible depuis la console Numspot. Utilisez l'**API** ou **Terraform** (voir les onglets correspondants).
:::

## API {#tabhead-API}

    La commande `PUT /compute/spaces/{spaceId}/vms/{id}` modifie les attributs d'une VM.

    Vous devez arrêter la VM avant de modifier les attributs suivants :
    - `nestedVirtualization` ;
    - `performance` ;
    - `userData` ;
    - `type`.

    [Exemple de requête : Modification d'une VM](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/vms/{id})
