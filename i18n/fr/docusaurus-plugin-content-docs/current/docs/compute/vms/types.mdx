# Types de VM

Les types de [VM (Virtual Machine)](/docs/compute/concept/) déterminent les caractéristiques matérielles de vos VM.

Lorsque vous créez une VM, vous devez spécifier un type de VM. Celui-ci reste cependant modifiable par la suite.

## Caractéristiques

Un type de VM détermine les caractéristiques matérielles de votre VM, parmi lesquelles figurent :

* Caractéristiques de calcul : Génération de CPU (Central Processing Unit), nombre de vCPU (virtual Central Processing Unit), quantité de mémoire et indicateur de performance.
* Caractéristiques réseau : Nombre maximum de NIC (Network Interface Card) que vous pouvez attacher et nombre maximum d'IP (Internet Protocol) privées que vous pouvez attribuer par NIC.

La génération de CPU correspond à une famille de CPU Intel :

{/* v5 : Intel Skylake */}
* v6 : Intel Ice Lake
{/* v7 : Intel Sapphire Rapids */}
Pour en savoir plus sur ces familles de CPU, voir la [documentation Intel officielle](https://ark.intel.com/content/www/fr/fr/ark.html).

L'indicateur de performance est une valeur qui détermine la performance globale des vCPU :

* 1 (La plus élevée) : Capacité de calcul maximum sur tous les vCPU de la VM. Cette valeur est idéale pour les applications de calcul intensif demandant des performances stables durant le cycle de vie de la VM.
* 2 (Élevée) : Haute capacité de calcul sur tous les vCPU de la VM. Cette valeur s'applique à la plupart des cas et offre des performances variables dans le temps.
* 3 (Modérée) : Performance à variation significative sur tous les vCPU de la VM. Cette valeur ne garantit pas des performances constantes, mais est idéale pour les machines à faible demande CPU.

## Types de VM disponibles

Numspot propose une large gamme de types de VM optimisés pour différents cas d'utilisation.

Ces types d'instances correspondent à différentes combinaisons en termes de capacités de processeur (CPU), de mémoire et de mise en réseau. Vous pouvez ainsi choisir un ensemble de ressources parfaitement adapté à vos applications. 

Chaque type de VM inclut une ou plusieurs tailles de VM, ce qui vous permet de mettre à l'échelle vos ressources en fonction des exigences de la charge de travail cible. Cette flexibilité vous permet de sélectionner le type de VM le plus approprié pour répondre aux besoins de vos applications, et de l'adapter en fonction de l'évolution de ces besoins.

si vous avez des besoins spécifiques qui ne sont pas couverts par les gabarits préconfigurés, vous pouvez créer une VM personnalisée.

### Usage économique (Economic) 
Offrant un rapport coût-performance optimal, elles conviennent aux charges de travail modérées en ressources processeur et mémoire. <br/>
Elles sont parfaites pour les serveurs web peu ou moyennement sollicités, les environnements de développement et de test, ou encore les applications à la demande inconstante. <br/>
Elles s'avèrent également idéales pour les tâches peu gourmandes, comme les serveurs web statiques, les sites web à faible trafic et les microservices.

### Usage mémoire (Memory)

Elles se révèlent idéales pour les bases de données en mémoire, les systèmes de cache, les opérations de traitement de données en temps réel, les bases de données relationnelles et les applications d'analyse de données volumineuses. <br/>
Ces VM offrent généralement un nombre élevé de gigaoctets de RAM par cœur de processeur, les rendant parfaitement adaptées aux charges de travail gourmandes en mémoire, comme les caches in-memory et les applications analytiques.

### Usage inférence (Inference)  
Les VM d'inférence sont optimisées pour les charges de travail d'inférence, en offrant des performances élevées pour l'exécution de modèles d'intelligence artificielle en production.
Elles exploitent des processeurs haute performance — CPU ou [GPU (Graphics Processing Unit)](/docs/compute/gpu/concept/) selon les besoins — afin de garantir une latence minimale et un débit élevé lors du traitement de grandes volumétries de requêtes.
Ces VM sont particulièrement adaptées aux cas d'usage tels que la prédiction en temps réel, l'analyse de données embarquée, le traitement d'images ou de langage naturel, ainsi que le déploiement de modèles d'apprentissage automatique optimisés pour l'inférence à grande échelle.
