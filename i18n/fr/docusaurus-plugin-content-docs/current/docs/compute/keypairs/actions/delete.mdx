# Supprimer une key pair

## Permissions

:::info
Cette action nécessite les permissions IAM (Identity and Access Management) suivantes :

- **compute.keypair.delete**

:::

Vous pouvez supprimer une [key pair (paire de clés)](/docs/compute/keypairs/concept/) spécifiée. Cette action supprime la clé publique conservée par Numspot.

Supprimer une key pair ne supprime pas la clé privée sauvegardée sur votre ordinateur, et ne supprime pas la clé publique dans les metadata d'autres [VM (virtual machine)](/docs/compute/concept/) créées avec la même key pair. Vous ne pouvez pas créer de nouvelles VM à l'aide de la key pair supprimée. Cependant, vous pouvez continuer à vous connecter à d'autres VM déjà créées avec la même key pair, tant que vous pouvez en fournir la clé privée.

1. Connectez-vous sur la console Numspot.

2. Depuis le menu latéral gauche, cliquez sur **Compute → Key pairs**.

3. Cochez la case de la key pair que vous voulez supprimer ou cliquez sur le menu déroulant "Actions" sur la même ligne.
  La key pair est sélectionnée ou un menu d'actions apparaît.

4. Cliquez sur **Supprimer**.
  Une boîte de dialogue de confirmation apparaît.

5. Confirmez la suppression en tapant le nom de la key pair.

6. Cliquez sur **Supprimer**.

  La key pair est supprimée et un message de confirmation s'affiche en bas de la page.

## API {#tabhead-api}

La commande `DELETE /compute/spaces/{spaceId}/keypairs/{id}` supprime la key pair spécifiée. Cette action supprime la clé publique stockée par Numspot, ce qui entraîne la suppression de la key pair.

[Exemple de requête : Suppression d'une key pair](/openapi/#tag/compute/delete/compute/spaces/{spaceId}/keypairs/{id})
