# Créer ou modifier un ou plusieurs tags

Pour créer ou modifier un tag, vous devez définir une clé et une valeur. La clé est le nom du tag et la valeur est la valeur du tag. Par exemple, vous pouvez créer un tag avec la clé "environnement" et la valeur "production".

À la création d'une ressource, la Console Numspot permet de définir son tag **Name** (le nom de la ressource). Une fois la ressource créée, vous pouvez ajouter des tags supplémentaires via la Console Numspot ou l'API Numspot.

## Permissions

:::info
L'ajout ou la modification de tags est une opération de mise à jour de la ressource concernée. Cette action nécessite la permission **IAM** (Identity and Access Management) de mise à jour de chaque ressource ciblée. Par exemple :

- **compute.vm.update** pour une [VM (virtual machine)](/docs/compute/concept/) ;
- **compute.blockStorage.update** pour un [volume (block storage)](/docs/storage/block-storage/concepts/) ;
- **compute.loadBalancer.update** pour un [load balancer](/docs/network/load-balancer/concepts/) ;
- **compute.vpc.update** pour un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/).

Cette liste est donnée à titre d'exemple et n'est pas exhaustive : pour chaque ressource, reportez-vous à sa page d'action.

:::

1. Depuis le menu latéral gauche, accédez à la liste de la ressource à laquelle vous souhaitez ajouter un tag ;
2. Sur la ligne de la ressource, ouvrez le menu **Actions**, puis cliquez sur **Gérer les tags** ;
3. Dans le panneau **Gérer les tags**, cliquez sur **Créer un tag** ;
4. Renseignez la **clé** et la **valeur** du tag, puis cliquez sur **Ajouter le tag** ;
5. Cliquez sur **Valider** pour enregistrer.

:::info
Le parcours est identique pour toutes les ressources qui supportent les tags (VM, volume, load balancer, VPC…). L'exemple ci-dessus est pris sur un load balancer.

## API {#tabhead-API}


La commande `PATCH /compute/spaces/{spaceId}/bulk/tags` crée un ou plusieurs tag sur vos ressources.

:::info
La console Numspot ne permet pas de modifier un tag existant : les tags s'affichent en pastilles non éditables. Pour changer une valeur, supprimez le tag puis recréez-le avec la même clé. L'**API** et **Terraform** permettent en revanche une modification directe (voir les onglets correspondants).
:::

1. Depuis le menu latéral gauche, accédez à la liste de la ressource dont vous souhaitez modifier un tag ;
2. Sur la ligne de la ressource, ouvrez le menu **Actions**, puis cliquez sur **Gérer les tags** ;
3. Cliquez sur la **croix** du tag à modifier pour le supprimer ;
4. Cliquez sur **Créer un tag**, saisissez la même **clé** et la nouvelle **valeur**, puis cliquez sur **Ajouter le tag** ;
5. Cliquez sur **Valider** pour enregistrer.

:::info
Le parcours est identique pour toutes les ressources qui supportent les tags (VM, volume, load balancer, VPC…). L'exemple ci-dessus est pris sur un load balancer.
:::
