# À propos des comptes de service

<ActionsSummary />

Un compte de service (service account) est un compte non-humain utilisé pour automatiser des tâches ou réaliser des opérations à la place d'un utilisateur. Il s'authentifie auprès de l'API (Application Programming Interface) Numspot pour gérer les ressources des espaces auxquels il est rattaché, dans la limite des permissions IAM (Identity and Access Management) qui lui sont accordées.

## Informations générales

Un compte de service est caractérisé par :

- un nom, choisi à la création ;
- une clé d'accès, générée par Numspot ;
- un code secret, généré par Numspot lors de la création et utilisé pour l'authentification ;
- une date d'expiration optionnelle ;
- un ou plusieurs espaces auxquels il a accès ;
- des rôles IAM qui déterminent ses permissions.

## Authentification

À la création d'un compte de service, Numspot retourne sa clé d'accès **et** son code secret. Le code secret n'est jamais réaffiché par la suite — il faut le conserver dans un emplacement sécurisé dès la création.

La clé d'accès et le code secret sont utilisés conjointement pour authentifier le compte auprès de l'API.

## Clés d'accès (AK/SK)

En complément du code secret généré à la création, un compte de service peut détenir jusqu'à deux paires de clés d'accès durables (AK/SK — Access Key/Secret Key). Elles authentifient un accès programmatique au stockage objet avec une signature compatible avec les outils AWS, sans échanger de token à chaque session.

- La clé d'accès identifie le secret ; la clé secrète n'est affichée qu'une seule fois, lors de la création.
- Chaque paire possède une durée de vie paramétrable, d'une heure à un an (un an par défaut), et un statut (ACTIVE, INACTIVE ou EXPIRED).
- La clé d'accès identifie la paire de clés ;
- La suppression d'une paire révoque immédiatement les sessions ouvertes avec celle-ci.

Pour créer, lister, consulter ou supprimer ces paires, voir les actions sur les clés d'accès : [créer](/docs/iam/service-account/actions/create-aksk), [lister](/docs/iam/service-account/actions/list-aksk), [consulter](/docs/iam/service-account/actions/get-aksk) et [supprimer](/docs/iam/service-account/actions/delete-aksk). Pour une paire de clés temporaire obtenue à partir d'un token, voir le [démarrage rapide Object Storage](/docs/storage/object-storage/quickstart/).

## Espaces et permissions

Un compte de service peut être rattaché à plusieurs espaces. Ses permissions sont définies par les rôles IAM qui lui sont attribués. Vous pouvez consulter à tout moment la liste des espaces assignés à un compte de service.
