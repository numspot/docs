# Modifier un compte de service

Vous pouvez modifier le nom, la durée de vie du jeton d'accès (token) et la date d'expiration d'un compte de service.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.serviceAccount.update**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Comptes de Service**.
2. Dans le tableau **Comptes de Service**, cliquez sur la clé d'accès du compte de service à modifier.
:::tip
Vous avez la possibilité de rechercher un compte de service en particulier en utilisant le champ **Rechercher**.
:::

3. Sur la page "Détails Compte de Service", cliquez sur le **crayon** du champ "Nom du Compte de Service".
4. Saisissez le nouveau nom puis validez avec la **coche** (la **croix** annule la modification).

Depuis la console, seul le nom du compte de service est modifiable. La durée de vie du token et la date d'expiration se modifient via l'API (onglet API).

## API {#tabhead-api}


### Modifier un compte de service dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/PUT/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}' \
  --request PUT \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "tokenDuration": "PT24H",
  "expirationDate": "2025-12-31"
}'
```

### Réponse

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
Tous les champs, modifiés ou non, doivent être renseignés. La durée de vie du token est au format ISO 8601, entre 1 seconde (PT1S) et 48 heures (PT48H), 24 heures (PT24H) par défaut.

Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Modifier un compte de service dans un espace

https://docs.numspot.com/openapi/#tag/identity-access-management/PUT/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request PUT \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "",
  "tokenDuration": "PT24H",
  "expirationDate": "2025-12-31"
}'
```

### Réponse

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
Tous les champs, modifiés ou non, doivent être renseignés.

Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
