# Obtenir les détails d'un compte de service

Tous les détails d'un compte de service sont retournés, sauf le code secret.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.serviceAccount.get**

:::

1. Dans le tableau **Comptes de Service**, cliquez sur la clé d'accès du compte de service dont vous souhaitez obtenir les informations.
:::tip
Vous avez la possibilité de rechercher un compte de service en particulier en utilisant le champ **Rechercher**.
:::

2. La page "Détails Compte de Service" s'affiche : nom du compte de service, durée de vie du token et date d'expiration.

3. Vous pouvez voir la liste des espaces assignés au compte de service, avec les rôles et permissions associés à chaque espace.

4. En cliquant sur **X rôles**, vous pouvez voir la liste des rôles attribués à ce compte de service sur un de ses espaces assignés.

5. En cliquant sur **X permissions**, vous pouvez voir la liste des permissions attribuées à ce compte de service sur un de ses espaces assignés.

## API {#tabhead-api}


### Obtenir les détails d'un compte de service dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}'
```

### Réponse

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Obtenir les informations d'un compte de service dans un espace

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}'
```

### Réponse

```json
{
  "name": "…",
  "id": "…",
  "tokenDuration": "…",
  "expirationDate": "…"
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Lister les espaces assignés à un compte de service

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}/spaces

### Exemple avec curl

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/serviceAccounts/{serviceAccountId}/spaces'
```

### Réponse

```json
{
  "nextPageToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9",
  "totalSize": 150,
  "items": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000"
    }
  ]
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
