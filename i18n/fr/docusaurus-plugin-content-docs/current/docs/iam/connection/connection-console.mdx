# Connexion à la console Numspot

### 1. Prérequis

Pour vous connecter, assurez-vous de disposer des éléments suivants :

- **Un compte Numspot actif.**
- **Votre application TOTP (Time-based One-Time Password) précédemment paramétrée.**
- **Un navigateur web moderne** **et à jour** (Chrome, Firefox, Edge, Safari).
- **L'URL de la console correspondant à la région de votre infrastructure Cloud.**
    - Pour la région standard : https://auth.eu-west-2.numspot.com/login
    - Pour la région SNC : https://auth.cloudgouv-eu-west-1.numspot.com/login

### 2. Identifiant et mot de passe

Veuillez renseigner votre identifiant et votre mot de passe.

![FR_login-password](/img/console/iam/login/FR_login-password.png)


### 3. Validation du TOTP

Reportez le code à 6 chiffres qui s'affiche dans votre application d'authentification (TOTP).

![FR_TOTP_login](/img/console/iam/login/FR_TOTP_login.png)


### 4. Redirection vers la console

Vous serez alors redirigé vers la page d'accueil de la console Numspot.

![FR_dashboard.png](/img/console/general/FR_dashboard.png)
