# Permissions et API associées

Pour chaque permission de la plateforme, cette page liste les API qui l'utilisent : utilisez la recherche pour filtrer la liste par permission ou par API, et cliquez sur un endpoint pour consulter sa définition dans la référence OpenAPI.

<PermissionsExplorer />

:::note
La plateforme applique le moindre privilège : une action peut nécessiter plusieurs permissions. Chaque page d'action de cette documentation précise, dans sa section Permissions, les permissions requises pour l'action correspondante.
:::
