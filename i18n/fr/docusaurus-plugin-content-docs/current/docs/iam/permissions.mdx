# Permissions et API associées

Pour chaque permission de la plateforme, cette page liste les API qui l'utilisent, son UUID et les rôles standard qui l'accordent.

Les permissions sont regroupées par niveau de tenant :

- **Organisation** : permissions exercées au niveau de l'organisation ;
- **Espace** : permissions exercées au sein d'un espace — une permission disponible aux deux niveaux apparaît dans chaque groupe.

:::note
La plateforme applique le moindre privilège : une action peut nécessiter plusieurs permissions. Chaque page d'action de cette documentation précise, dans sa section Permissions, les permissions requises pour l'action correspondante. Certaines permissions n'ont pas d'endpoint public : l'action correspondante est réalisée depuis la console Numspot.
:::

Utilisez la recherche pour filtrer la liste par permission ou par API, les pastilles de tenant pour ne conserver qu'un seul niveau, et le menu déroulant des rôles standard pour afficher les permissions accordées par un rôle par défaut. Cliquez sur un endpoint pour consulter sa définition dans la référence OpenAPI.
