# Générer un lien d'activation

Lors de la première connexion ou dans le cadre d'une réinitialisation des informations d'authentification, un nouveau lien d'activation est généré. Ce lien est envoyé par e-mail à l'adresse déclarée lors de la création de l'utilisateur.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.user.recover**

:::

1. Dans le tableau des **utilisateurs**, cliquez sur l'identifiant de l'utilisateur.

   :::tip
   Vous avez la possibilité de rechercher un utilisateur en particulier en utilisant le champ **Rechercher**.
   :::

2. Sur la page "Détails utilisateur", cliquez sur **Nouveau lien d'activation**.

3. Confirmez l'envoi en cliquant sur **Envoyer l'email**. L'utilisateur reçoit un email contenant un nouveau lien permettant de réinitialiser son mot de passe et son authentification à deux facteurs.
:::warning
Si l'utilisateur est connecté, sa session actuelle reste active. Cependant, il ne pourra plus se reconnecter avec son ancien mot de passe.
:::

## API {#tabhead-api}


La génération d'un lien d'activation peut se faire via l'API, mais les étapes suivantes sont à réaliser par l'utilisateur dans son navigateur.

https://docs.numspot.com/openapi/#tag/identity-access-management/POST/iam/organisations/{organisationId}/users/{userId}/recover

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users/{userId}/recover' \
  --request POST
```

### Réponse

```json
{
  "link": "https://example.com",
  "code": "…",
  "expiration": "2018-11-13T20:20:39+00:00"
}
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
