# Créer un utilisateur

Créez un utilisateur au sein de votre organisation Numspot. L'utilisateur accède ensuite à la console et à l'API pour gérer les ressources des espaces qui lui sont assignés.

Lors de la création, vous choisissez d'attribuer immédiatement des rôles et des permissions à l'utilisateur, ou de créer son compte sans droits. Vous pouvez également créer un utilisateur à partir du profil d'un utilisateur existant : le nouvel utilisateur hérite alors des mêmes espaces, rôles et permissions.

Pour l'API, il faut préalablement créer un compte de service.

Après la création, [générez un lien d'activation](/docs/iam/user/actions/generate/) afin que l'utilisateur définisse son mot de passe et configure son authentification à deux facteurs.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.user.create**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Utilisateurs**.
2. Cliquez sur le bouton **Créer un utilisateur**.
3. Renseignez le prénom, le nom et l'adresse e-mail de l'utilisateur, puis cliquez sur **Créer et attribuer des rôles et permissions**, ou sur **Créer l'utilisateur sans rôles et permissions** :
   - **Créer l'utilisateur sans rôles et permissions** crée immédiatement le compte et vous redirige vers la page "Détails utilisateur" ; vous pourrez attribuer des droits ultérieurement ;
   - **Créer et attribuer des rôles et permissions** ouvre l'assistant de gestion des droits, composé de trois étapes : "Espaces", "Rôles" et "Permissions".
4. Étape "Espaces" : cochez les espaces à associer à l'utilisateur, puis cliquez sur **Assigner les espaces et continuer**. Vous pouvez aussi cliquer sur **Passer l'étape**.
5. Étape "Rôles" : sélectionnez l'onglet "Organisation" ou l'espace concerné, cochez les rôles à attribuer, puis cliquez sur **Enregistrer et continuer**. Vous pouvez aussi cliquer sur **Ne pas attribuer de rôles** ou sur **Passer l'étape**.
6. Étape "Permissions" : sélectionnez l'onglet "Organisation" ou l'espace concerné, cochez les permissions à attribuer, puis cliquez sur **Enregistrer et quitter**. Vous pouvez aussi cliquer sur **Ne pas attribuer de permissions** ou sur **Passer l'étape**.
7. Un message de confirmation s'affiche et vous êtes redirigé vers la page "Détails utilisateur".

Vous pouvez créer un utilisateur à partir du profil d'un utilisateur existant :

1. Depuis la page "Détails utilisateur", cliquez sur **Créer un utilisateur à partir de ce profil**.
2. Renseignez le prénom, le nom et l'adresse e-mail du nouvel utilisateur.
3. Le nouvel utilisateur hérite des mêmes espaces, rôles et permissions que l'utilisateur initial.

## API {#tabhead-api}


### Créer un utilisateur dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/POST/iam/organisations/{organisationId}/users

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/users' \
  --request POST \
  --header 'Content-Type: application/json' \
  --data '{
  "email": "john.smith@acme.org",
  "firstname": "",
  "lastname": ""
}'
```

### Réponse

```json
{
  "email": "john.smith@acme.org",
  "firstname": "…",
  "lastname": "…",
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "active": true,
  "createdOn": "2018-11-13T20:20:39+00:00"
}
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Exemple

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}' \
  --request PATCH \
  --header 'Content-Type: application/json' \
  --data '{
  "add": {
    "roles": [
      ""
    ],
    "permissions": [
      ""
    ]
  },
  "delete": {
    "roles": [
      ""
    ],
    "permissions": [
      ""
    ]
  }
}'
```
