# Consulter les accès d'une identité

Cette opération peut s'effectuer au niveau de l'organisation ou d'un espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.permission.get**

:::

1.  Dans la page de détail d'un compte utilisateur, vous pouvez voir la liste des espaces assignés à un utilisateur.


2.  En cliquant sur **X rôles**, vous pourrez voir la liste des rôles attribués à cet utilisateur, sur l'espace qui lui est associé.


3.  En cliquant sur **X permissions**, vous pourrez voir la liste des permissions attribuées à cet utilisateur, sur l'espace qui lui est associé.


### Consulter les accès d'un compte de service

1.  Dans la page de détail d'un [compte de service](/docs/iam/concepts/identity/) vous pouvez voir la liste des espaces associés au compte de service.


2.  En cliquant sur le lien **X rôles**, vous pourrez voir la liste des rôles attribués à ce compte de service pour l'espace qui lui est associé.


3.  En cliquant sur le lien **X permissions**, vous pourrez voir la liste des permissions attribuées à ce compte de service pour l'espace qui lui est associé.

## API {#tabhead-api}


### Rôles et permissions dans une organisation

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}

### Exemple avec un curl

```bash
curl 'https://api.{region}.numspot.com/iam/organisations/{organisationId}/iampolicy/{subjectType}/{subjectId}'
```

Réponse :

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

### Rôles et permissions dans un espace

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/iam/spaces/{spaceId}/iampolicy/{subjectType}/{subjectId}

### Exemple avec un curl

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/iampolicy/{subjectType}/{subjectId}'
```

Réponse :

```json
{
  "roles": [
    "123e4567-e89b-12d3-a456-426614174000"
  ],
  "permissions": [
    "123e4567-e89b-12d3-a456-426614174000"
  ]
}
```

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
