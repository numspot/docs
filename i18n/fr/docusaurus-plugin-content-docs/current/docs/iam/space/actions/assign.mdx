# Assigner une identité à un espace

Assignez des utilisateurs ou des comptes de service à un espace pour leur donner accès aux ressources de cet espace.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.role.create**

:::

1. Depuis le menu latéral gauche, cliquez sur **IAM** → **Utilisateurs** (ou **Comptes de Service**) ;
2. Cliquez sur l'identifiant de l'identité concernée pour ouvrir sa page de détail ;
3. Dans la section **Espaces assignés**, cliquez sur **Assigner des espaces**.

   L'assistant **Assignation des espaces** apparaît. Il se déroule en trois étapes : **Espaces**, **Rôles**, **Permissions** ;
4. Cochez le ou les espaces à assigner (la multi-sélection est disponible), puis poursuivez l'assistant pour attribuer les rôles et les permissions correspondants.

## API {#tabhead-api}


Pour assigner un compte utilisateur à un espace avec l'API, il faut connaître l'UUID (Universally Unique Identifier) de l'espace. Une variante dans l'URL permet d'intervenir sur un utilisateur ou sur un compte de service.

À l'issue de cette opération, le compte sera assigné à l'espace mais sans rôle et permission.

https://docs.numspot.com/openapi/#tag/identity-access-management/POST/iam/spaces/{spaceId}/users/{userId}

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/users/{userId}' \
  --request POST
```

La requête ne retourne aucune réponse.

:::info
Consulter la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::

Pour supprimer (enlever l'assignation) un compte utilisateur d'un espace avec l'API :

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/spaces/{spaceId}/users/{userId}

À l'issue de cette opération, le compte utilisateur ne sera plus assigné à l'espace mais sera toujours présent dans l'organisation ou assigné à d'autres espaces.

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/users/{userId}' \
  --request DELETE
```

Pour assigner un compte de service à un espace avec l'API :

https://docs.numspot.com/openapi/#tag/identity-access-management/POST/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request POST
```

Pour supprimer (enlever l'assignation) un compte de service d'un espace avec l'API :

https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}

À l'issue de cette opération, le compte de service ne sera plus assigné à l'espace mais sera toujours présent dans l'organisation ou assigné à d'autres espaces.

```bash
curl 'https://api.{region}.numspot.com/iam/spaces/{spaceId}/serviceAccounts/{serviceAccountId}' \
  --request DELETE
```
