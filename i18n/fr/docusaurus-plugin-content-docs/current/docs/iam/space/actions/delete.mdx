# Supprimer un espace

Supprimez un espace dont vous n'avez plus besoin. Cette opération est irréversible.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **iam.role.delete**

:::

:::danger
La suppression d'un espace est irréversible. Cette action est à réaliser avec précaution. L'accès à l'espace ne sera plus possible après suppression.
:::

Pour supprimer un espace, assurez-vous que **toutes les ressources créées dans votre espace ont été supprimées**. L'existence de ressources empêche la suppression de l'espace. Elles doivent être préalablement supprimées par les utilisateurs pour s'assurer qu'elles ne seront plus facturées.

1. Dans le menu des **Espaces**, ouvrez le menu **Actions** de l'espace concerné, puis cliquez sur **Supprimer**.
2. Une boîte de dialogue **Suppression de l'espace** apparaît, vous invitant à faire une demande auprès du support. Contactez-nous à [support@numspot.com](mailto:support@numspot.com) ou via [support.numspot.com](https://support.numspot.com) en fournissant l'identifiant de votre organisation ainsi que l'identifiant de l'espace à supprimer.

:::info
Depuis la console, la suppression d'un espace n'est pas réalisée directement : elle fait l'objet d'une demande auprès du support Numspot.
:::

## API {#tabhead-api}


https://docs.numspot.com/openapi/#tag/identity-access-management/DELETE/organisations/{organisationId}/spaces/{spaceId}

### Exemple

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces/{spaceId}' \
  --request DELETE
```

:::info
Consultez la [page sur l'utilisation des API](/docs/iam/concepts/api/) pour la mise en œuvre.
:::
