# Consulter un espace

Vous pouvez consulter le détail d'un espace : son identifiant, son nom, sa description et son statut.

## Permissions

:::info
Cette action nécessite la permission **IAM** (Identity and Access Management) suivante :

- **iam.space.get**

:::

1. Dans le menu **IAM**, cliquez sur **Espaces**.

   Vous accédez au tableau **Espaces**, qui liste tous les espaces de votre organisation.

2. Cliquez sur l'identifiant de l'espace dont vous voulez consulter le détail. La page de détail affiche son nom, sa description, son identifiant et son statut.

## API {#tabhead-api}

### Consulter le détail d'un espace

https://docs.numspot.com/openapi/#tag/identity-access-management/GET/organisations/%7BorganisationId%7D/spaces/%7BspaceId%7D

### Exemple

```bash
curl 'https://api.{region}.numspot.com/organisations/{organisationId}/spaces/{spaceId}'
```

### Réponse

```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "organisationId": "123e4567-e89b-12d3-a456-426614174001",
  "name": "Production",
  "description": "Charges de travail de production",
  "status": "READY",
  "createdOn": "2026-01-15T08:45:00+00:00",
  "updatedOn": "2026-05-02T14:12:00+00:00"
}
```

:::info
Consultez la [page d'utilisation de l'API](/fr/docs/iam/concepts/api/) pour la mise en œuvre.
:::
