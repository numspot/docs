# Créer un subnet dans un VPC

Vous pouvez créer un ou plusieurs subnets (sous-réseaux) dans un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) pour pouvoir lancer des ressources dans celui-ci. Les subnets sont placés dans des sous-régions de la région de votre VPC.

Une fois votre subnet créé, il est recommandé de créer un [security group (groupe de sécurité)](/docs/compute/security-groups/concepts/concept-sg/) et une [route table (table de routage)](/docs/network/route-table/concepts/) qui lui sont dédiés.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.subnet.create**

:::

 :::info
 **Prérequis** : Créer un VPC.

 **Optionnel** : Pour désactiver la fonctionnalité permettant aux [VM (Virtual Machines)](/docs/compute/concept/) d'un même subnet de communiquer entre elles sans règles de security group requises, ajoutez un tag (étiquette) à votre VPC avec "osc.fcu.enable_lan_security_groups" pour clé.
 Ce tag doit être ajouté à votre VPC avant de créer des subnets dans celui-ci.
 La valeur de ce tag n'est pas prise en compte, vous pouvez donc spécifier n'importe quelle valeur pour ce tag.   
 ::: 

 1. Connectez-vous sur la console Numspot.

 2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **VPC**. 

 3. La liste des VPC apparaît. Cliquez sur l'ID du VPC concerné.

 4. La page "Détails VPC" apparaît.

 5. Cliquez sur le bouton **Créer un subnet**.

 6. La page "Création de subnet" apparaît.

 7. Dans le champ "Nom", saisissez un nom pour le subnet.
 :::info
 Cette action ajoute un tag Name de 255 caractères maximum. Vous pouvez utiliser tous les caractères, y compris les lettres accentuées.
 :::

 8. Dans le champ "Plage d'IP", entrez la plage d'adresses IP (Internet Protocol) pour votre subnet, en notation CIDR (Classless Inter-Domain Routing). La plage d'adresses IP doit être comprise dans le CIDR du VPC associé.
:::warning
Le bloc CIDR du subnet doit faire partie du bloc CIDR du VPC.
Si vous créez plusieurs subnets dans un VPC, leurs blocs CIDR ne doivent pas se chevaucher.
:::

 9. Dans la section "Availability Zone", sélectionnez la zone de disponibilité dans laquelle vous voulez créer le subnet.

 10. Cliquez ensuite sur le bouton **Créer**.

 11. Un message de confirmation s'affiche en bas indiquant que le subnet est bien créé et vous êtes redirigé vers la page détaillée du VPC associé.

La commande `POST /compute/spaces/{spaceId}/subnets` crée un subnet dans un réseau existant.
Pour créer un subnet dans un réseau, vous devez fournir l'ID du réseau et la plage d'adresses IP pour le subnet (sa plage réseau). Une fois le subnet créé, vous ne pouvez plus modifier sa plage d'adresses IP.

[Exemple de requête : Création d'un subnet](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/subnets)
