# Obtenir des informations sur vos Subnets

Vous pouvez obtenir des informations à propos d'un ou plusieurs de vos subnets (sous-réseaux), comme le [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) dans lequel ils sont, leur bloc CIDR (Classless Inter-Domain Routing) ou leur Sous-région.

Des informations sur vos subnets sont également disponibles depuis les [VM (Virtual Machines)](/docs/compute/concept/) elles-mêmes.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.subnet.get**

:::

 1. Connectez-vous sur la console Numspot.
 2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **VPC**.

     
 3. La liste des VPC apparaît. Cliquez sur l'ID du VPC concerné.
 4. La page "Détails VPC" apparaît.
 5. En dessous des détails du VPC apparaît la section "Subnets" dans laquelle se trouve la liste des subnets associés au VPC.

  <TabItem value="API">

La commande `GET /compute/spaces/{spaceId}/subnets` permet de lister les subnets.

[Exemple de requête : Lister tous les subnets](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/subnets)

La commande `GET /compute/spaces/{spaceId}/subnets/{id}` permet de récupérer les informations d'un subnet spécifié.

[Exemple de requête : Récupérer les informations d'un subnet](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/subnets/{id})
