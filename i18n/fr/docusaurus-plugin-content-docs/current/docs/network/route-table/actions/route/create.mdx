# Créer une route

Vous pouvez créer une route dans une [route table](/docs/network/route-table/concepts/) pour spécifier comment le trafic est routé pour les [VM (Virtual Machines)](/docs/compute/concept/) dans les subnets (sous-réseaux) auxquels elle est associée.

Vous pouvez créer des routes avec les targets suivants :

* Une [internet gateway (passerelle Internet)](/docs/network/internet-gateway/concepts/), pour permettre aux VM avec une IP (Internet Protocol) publique associée d'être directement connectées à Internet.
* Une [virtual gateway (passerelle virtuelle)](/docs/connectivity/vpn/virtual-gateway/concepts/), pour router le trafic vers une connexion [DirectLink](/docs/connectivity/direct-link/concepts/) ou VPN (Virtual Private Network).
* Une [NAT gateway (passerelle NAT)](/docs/network/nat/concepts/), pour permettre aux VM d'être indirectement connectées à Internet.
* Une VM.
* Une interface réseau d'une VM.
* Un [VPC](/docs/network/vpc/concepts/) peering (peering VPC), pour permettre aux VM d'envoyer du trafic vers un VPC pair.

:::warning
Lorsque vous créez un VPC access point, la route appropriée est automatiquement créée et ajoutée aux route tables que vous spécifiez.
:::

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.routeTable.update**

:::

 ## Créer une route sur la console Numspot 

 :::info
 **Avant de commencer :** Créez une route table. Pour en savoir plus, voir [Créer une Route table](../create.mdx).

 1.  Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Route Table**.
 2.  Identifiez la table de routage à laquelle vous souhaitez créer une nouvelle route.
 3.  Cliquez dans la ligne concernée sur le lien de la colonne **Routes**.
 4.  Une nouvelle boîte de dialogue s'affichera.
 5.  Cliquez sur le bouton **Ajouter une Route**.
 6.  Une fenêtre pour la création d'une route apparaît :
 7.  Dans le champ "Cible", choisissez la ressource.
 8.  Dans le champ "Plage d'IP de destination", tapez le CIDR (Classless Inter-Domain Routing).
      
      :::info
      Pour spécifier le CIDR 0.0.0.0/0, cliquez sur **ALL IPS**.
      :::
     
 9.  Cliquez sur le bouton **Ajouter la Route**.
     
     :::info
     Vous pouvez saisir autant de nouvelles routes que vous le souhaitez. Le volet latéral vous indique le récapitulatif des routes existantes et en cours de création.
     :::
     
 10. Cliquez sur le bouton **Valider**.  
     Les routes associées ont été créées.

   :::info
   Avant de commencer : créez une route table.
   :::

   La commande `POST /compute/spaces/{spaceId}/routeTables/{id}/routes` crée une route dans une Route Table spécifiée au sein d'un VPC spécifié. Vous devez spécifier l'un des éléments suivants comme cible :
   - VPC Peering
   - NAT VM
   - Internet Gateway
   - Virtual Gateway
   - NAT Gateway
   - Network Interface Card (NIC)

   L'algorithme de routage est basé sur la correspondance la plus spécifique.

   [Exemple de requête : Création d'une Route](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/routeTables/{id}/routes)
