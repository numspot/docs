# Supprimer une route table

Vous pouvez supprimer une [route table (table de routage)](/docs/network/route-table/concepts/) dont vous n'avez plus besoin et qui n'est associée à aucun subnet. Vous ne pouvez pas supprimer la route table qui est définie comme principale.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.routeTable.delete**

:::

   ## Supprimer une route table depuis la console
   
    Vous pouvez supprimer une route table de façon unitaire ou en supprimer plusieurs en une seule action.

### Supprimer une route table

1. Connectez-vous sur la console Numspot.
2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **[VPC](/docs/network/vpc/concepts/)** → **Route Table**.
3. Identifiez la route table que vous souhaitez supprimer, puis depuis la liste des actions, cliquez sur **Supprimer**.
    Une nouvelle boîte de dialogue "Suppression de la route table" apparaît.
4. Pour continuer, une confirmation forte est nécessaire. Saisissez le nom de la ressource à supprimer dans le champ correspondant.
5. Cliquez sur **Supprimer**.  
    La route table est supprimée et un message de confirmation "**La route table a bien été supprimée**" apparaît.

### Supprimer plusieurs route tables

1. Connectez-vous sur la console Numspot.
2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Route Table**.
3. Sélectionnez les route tables que vous souhaitez supprimer, puis cliquez sur **Supprimer**.
    Une nouvelle boîte de dialogue "Suppression de route tables" apparaît.
4. Pour continuer, une confirmation forte est nécessaire. Saisissez le terme **Supprimer** dans le champ correspondant.
5. Cliquez sur **Supprimer**.  
    Les route tables sont supprimées et un message de confirmation "**Les route tables ont bien été supprimées**" apparaît.
