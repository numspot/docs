# Créer une route table

Vous pouvez créer une [route table (table de routage)](/docs/network/route-table/concepts/) que vous pouvez associer à un ou plusieurs subnet (sous-réseau) pour contrôler la façon dont leur trafic est routé. Une fois votre route table créée, vous pouvez y créer des routes pour personnaliser le routage des subnet auxquels elle est associée.

Chaque route table contient la route `local` qui route le trafic ciblant une IP du bloc CIDR du [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) localement. Cette route ne peut être ni modifiée ni supprimée.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.routeTable.create**

:::

1. Connectez-vous sur la console Numspot.   
2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **VPC**. 
3.  Cliquez sur le bouton **Créer une Route Table** situé en haut à droite de l'écran pour ouvrir la pop-up.
4.  La pop-up s'ouvre et vous demande de rentrer un nom de route table, ainsi que de sélectionner l'ID du VPC (liste déroulante contenant tous les IDs des VPC dont vous avez l'accès) pour lequel vous créez cette route.
5.  Cliquez sur **Créer**.

## api {#tabhead-api}

   :::info
Avant de commencer : créez un VPC.
:::

La commande `POST /compute/spaces/{spaceId}/routeTables` crée une route table pour un VPC spécifié. Vous pouvez ensuite ajouter des routes et associer la route table à un subnet.

[Exemple de requête : Création d'une Route Table](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/routeTables)
