# Supprimer une route

Vous pouvez supprimer une route que vous avez créée dans une [route table (table de routage)](/docs/network/route-table/concepts/) afin de supprimer l'option de routage correspondante pour les [VM (Virtual Machines)](/docs/compute/concept/) placées dans les subnets (sous-réseaux) associés.

Vous ne pouvez pas supprimer la route `local`.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.routeTable.update**

:::

1.  Depuis le menu latéral gauche, cliquez sur **Réseau** → **[VPC](/docs/network/vpc/concepts/)** → **Route Table**.
2.  Identifiez la route table à laquelle vous souhaitez créer une nouvelle route.
3.  Cliquez dans la ligne concernée sur le lien de la colonne "Routes".
4.  Une nouvelle boîte de dialogue s'affichera.
5.  Cliquer sur **Supprimer**.
6.  Une boîte de dialogue de suppression apparaît.
7.  Pour continuer, une confirmation forte est nécessaire. Saisissez "Supprimer" dans le champ correspondant.
8.  Cliquez sur **Supprimer**.  
    La route est supprimée et un message de confirmation apparaîtra temporairement.
