# Obtenir des informations sur les tags (étiquettes) associés à vos load balancers

Vous pouvez consulter les tag (étiquettes) associés à vos [load balancer (équilibreurs de charge)](/docs/network/load-balancer/concepts/) pour identifier et organiser vos ressources.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.loadBalancer.get**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Load Balancers** pour accéder à la liste des load balancers.
2. Sur la ligne du load balancer, ouvrez le menu **Actions**, puis cliquez sur **Gérer les tags**.
3. Le panneau **Gérer les tags** affiche la liste des tag associés au load balancer.

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/loadBalancersTags` répertorie les tags associés à un load balancer spécifié.

[Exemple de requête : Lister les tags associés à un load balancer](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/loadBalancersTags)
