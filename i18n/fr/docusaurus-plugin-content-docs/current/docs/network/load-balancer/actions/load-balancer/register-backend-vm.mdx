# Enregistrer une VM auprès d'un load balancer

Vous pouvez attacher une ou plusieurs [VM (Virtual Machine)](/docs/compute/concept/) à un [load balancer (équilibreur de charge)](/docs/network/load-balancer/concepts/) spécifié. Vous devez spécifier au moins le paramètre BackendIps ou BackendVMIds. Les VM peuvent se trouver dans différents subnet (sous-réseaux) et différentes Subregions par rapport au load balancer, tant que les VM et les load balancers sont soit tous dans le Cloud public, soit tous dans le même [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/). L'enregistrement d'une VM avec le load balancer peut prendre un certain temps. Une fois enregistrée, la VM reçoit le trafic et les requêtes provenant de ce load balancer et est alors appelée une VM de backend (serveur dorsal).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.loadBalancer.update**

:::

## API {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/loadBalancers/{id}/backendMachines/link` attache une VM à un load balancer.

[Exemple de requête : Attacher une VM à un load balancer](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/loadBalancers/{id}/backendMachines/link)
