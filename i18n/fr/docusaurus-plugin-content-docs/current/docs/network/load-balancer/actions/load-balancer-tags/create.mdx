# Ajouter ou supprimer des tags (étiquettes) à un load balancer

Vous pouvez ajouter ou supprimer des tag (étiquettes) associés à un [load balancer (équilibreur de charge)](/docs/network/load-balancer/concepts/) pour organiser et identifier vos ressources.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.loadBalancer.update**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Load Balancers** pour accéder à la liste des load balancers.
2. Sur la ligne du load balancer, ouvrez le menu **Actions**, puis cliquez sur **Gérer les tags**.
3. Dans le panneau **Gérer les tags**, cliquez sur **Créer un tag** (ou sur la croix d'un tag existant pour le supprimer).
4. Renseignez la clé et la valeur du tag, cliquez sur **Ajouter le tag**, puis sur **Valider** pour enregistrer.

## API {#tabhead-api}


La commande `PATCH /compute/spaces/{spaceId}/bulk/loadBalancersTags` ajoute un ou plusieurs tag au load balancer spécifié. Si un tag avec la même clé existe déjà pour le load balancer, la valeur du tag est remplacée.

[Exemple de requête : Ajout de tag au load balancer ↗](/openapi/#tag/compute/PATCH/compute/spaces/{spaceId}/bulk/loadBalancersTags)
