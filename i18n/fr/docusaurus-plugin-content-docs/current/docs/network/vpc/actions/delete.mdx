# Supprimer un VPC

Vous pouvez supprimer un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) vide dont vous n'avez plus besoin. 

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vpc.delete**

:::

 :::info
 Avant de commencer, assurez-vous de supprimer ou détacher toutes les ressources liées au VPC, telles que : 
 * [VM (Virtual Machines)](/docs/compute/concept/)
 * subnets (sous-réseaux)
 * IP (Internet Protocol) publique (Public IP)
 ::: 

 1. Connectez-vous sur la console Numspot.  

 2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **VPC**. 

 3. La liste des VPC apparaît.

 4. Identifiez le VPC à supprimer puis cliquez sur **Actions**. Une boîte de dialogue d'options apparaîtra.

 5. Cliquez sur **Supprimer le VPC**. Le VPC est supprimé. 
    :::warning 
    Si le VPC a encore des dépendances avec d'autres objets, la suppression sera impossible. Avant de continuer, assurez-vous de supprimer ou détacher toutes les dépendances et supprimez ensuite le VPC.  
    :::

La commande `DELETE /compute/spaces/{spaceId}/vpcs/{id}` permet de supprimer un cloud privé virtuel (VPC).
