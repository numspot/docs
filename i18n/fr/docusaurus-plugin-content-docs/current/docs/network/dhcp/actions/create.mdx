# Créer un groupe d'options DHCP

Vous pouvez créer un groupe d'options [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/) à associer à un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/). Vous pouvez spécifier un ou plusieurs serveurs NTP (Network Time Protocol) et serveurs DNS (Domain Name System) à utiliser, avec un nom de domaine correspondant.

Numspot fournit automatiquement un groupe d'options DHCP par défaut. Cependant, vous pouvez créer autant de groupes personnalisés que vous le souhaitez.

Vous pouvez associer un groupe d'options DHCP à un VPC pour personnaliser la configuration DHCP utilisée avec les [VM (Virtual Machine)](/docs/compute/concept/) créées dans ce VPC.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.dhcpOptions.create**

:::

## Console {#tabhead-console}

La création d'un groupe d'options DHCP n'est pas disponible depuis la Console. Utilisez l'API ou Terraform.

<TabItem value="api" label="API">

## API {#tabhead-api}


La commande `POST /compute/spaces/{spaceId}/dhcpOptions` crée un ensemble d'options DHCP, que vous pouvez ensuite associer à un réseau en utilisant la méthode pour modifier un VPC.

[Exemple de requête : Création d'un ensemble d'options DHCP ↗](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/dhcpOptions)
