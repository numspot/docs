# Modifier le groupe d'options DHCP associé à un VPC

Vous pouvez associer un groupe d'options [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/) par défaut ou personnalisé à un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) pour appliquer les options qu'il contient aux [VM (Virtual Machine)](/docs/compute/concept/) créées dans ce VPC.

Cette action remplace le groupe d'options DHCP par un autre, car vous ne pouvez associer un VPC qu'à un seul groupe d'options DHCP à la fois.

Lorsque vous modifiez le groupe d'options DHCP associé à un VPC, les options qu'il contient sont automatiquement appliquées aux VM existantes, ainsi qu'aux VM lancées ultérieurement. Les VM existantes appliquent ces options quelques heures après la modification, selon la fréquence de renouvellement de leur bail DHCP. Vous n'avez pas besoin de redémarrer ces VM. Vous pouvez cependant forcer le renouvellement du bail DHCP avec la commande `dhclient` pour les VM Linux, ou la commande `ipconfig/renew` pour les VM Windows.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.vpc.update**

:::

## Console {#tabhead-console}

L'association d'un groupe d'options DHCP à un VPC n'est pas disponible depuis la Console. Utilisez l'API ou Terraform.

</TabItem>
<TabItem value="api" label="API">

## API {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/vpcs/{id}` associe un ensemble d'options DHCP à un réseau spécifié.

[Exemple de requête : Associer un ensemble d'options DHCP à un réseau ↗](/openapi/#tag/compute/PUT/compute/spaces/{spaceId}/vpcs/{id})
