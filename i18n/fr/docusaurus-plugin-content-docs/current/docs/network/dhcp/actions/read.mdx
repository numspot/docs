# Consulter les informations de vos options DHCP

Vous pouvez obtenir des informations sur un ou plusieurs de vos groupes d'options [DHCP (Dynamic Host Configuration Protocol)](/docs/network/dhcp/concepts/), comme leur ID et les options qu'ils contiennent.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.dhcpOptions.get**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **DHCP Options** pour accéder à la liste des groupes d'options DHCP.
2. La liste affiche les groupes d'options DHCP disponibles avec leurs informations :
   - le nom du groupe d'options ;
   - l'identifiant du groupe d'options ;
   - le [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) associé.
3. Cliquez sur un groupe d'options DHCP pour afficher ses détails.

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/dhcpOptions` permet de lister les options DHCP.

[Exemple de requête : Lister tous les ensembles d'options DHCP ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/dhcpOptions)

La commande `GET /compute/spaces/{spaceId}/dhcpOptions/{id}` permet de récupérer les informations d'une option DHCP.

[Exemple de requête : Récupérer les informations d'un ensemble d'options DHCP ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/dhcpOptions/{id})
