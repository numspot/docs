# Obtenir des informations sur vos nat gateways

Vous pouvez obtenir des informations à propos d'une ou plusieurs de vos [nat gateways (passerelles NAT)](/docs/network/nat/concepts/), comme son IP publique ou le [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) et subnet (sous-réseau) dans lesquels elles se trouvent.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.natGateway.get**

:::

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/natGateways` permet de lister les nat gateways.

[Exemple de requête : Lister tous les nat gateways ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/natGateways)

La commande `GET /compute/spaces/{spaceId}/natGateways/{id}` permet de récupérer des informations concernant une nat gateway.

[Exemple de requête : Récupérer les informations d'une nat gateway ↗](/openapi/#tag/compute/GET/compute/spaces/{spaceId}/natGateways/{id})
