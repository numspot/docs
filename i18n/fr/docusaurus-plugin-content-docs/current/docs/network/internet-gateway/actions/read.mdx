# Obtenir des informations sur vos internet gateways

Vous pouvez obtenir des informations à propos d'une ou plusieurs de vos [internet gateways (passerelles Internet)](/docs/network/internet-gateway/concepts/), comme son état d'attachement ou le [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) auquel elle est attachée.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.internetGateway.get**

:::

Vous pouvez consulter les informations de vos internet gateways depuis le dashboard **VPC**.

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Internet Gateways**.


2. La liste des internet gateways s'affiche avec leurs informations :
   - **Nom** : nom de l'internet gateway
   - **ID** : identifiant unique
   - **État** : attachée ou détachée
   - **VPC** : VPC auquel elle est attachée (le cas échéant)

3. Cliquez sur une internet gateway pour voir ses détails.

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/internetGateways` permet de lister les internet gateways.

[Exemple de requête : Lister toutes les internet gateways ↗](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/internetGateways)

La commande `GET /compute/spaces/{spaceId}/internetGateways/{id}` permet de récupérer des informations concernant une internet gateway.

[Exemple de requête : Récupérer les informations d'une internet gateway ↗](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/internetGateways/%7Bid%7D)
