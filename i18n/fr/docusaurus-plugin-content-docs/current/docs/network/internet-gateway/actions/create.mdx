# Créer une internet gateway

Vous pouvez créer une [internet gateway (passerelle Internet)](/docs/network/internet-gateway/concepts/) que vous pouvez ensuite attacher à un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) pour connecter des [VM (Virtual Machine)](/docs/compute/concept/) d'un ou plusieurs subnet (sous-réseaux) à Internet de manière directe.

Pour cela, vous devez également ajouter une route à la [route table (table de routage)](/docs/network/route-table/concepts/) de ces subnet dirigeant le trafic Internet vers l'internet gateway et mettre à jour vos [security group (groupes de sécurité)](/docs/compute/security-groups/concepts/concept-sg/). Pour en savoir plus, consultez le [Tutoriel : Mettre en place une connexion directe entre des VM d'un VPC et internet ↗](./administration/tutorial.mdx).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.internetGateway.create**

:::

1. Connectez-vous sur la console Numspot.
2. Depuis le menu latéral gauche, cliquez sur **Réseau** → **VPC** → **Internet Gateways**.


3. Cliquez sur le bouton **Créer une Internet Gateway**.


Une nouvelle fenêtre "Créer une Internet Gateway" apparaît.


4. Dans le champ "Nom", saisissez un nom pour l'internet gateway.

:::warning
Cette action ajoute un tag Name de 255 caractères maximum. Vous pouvez utiliser tous les caractères, y compris les lettres accentuées.
:::

5. Cliquez sur **Créer l'internet gateway**.

Un message de confirmation s'affiche en bas de page indiquant que l'internet gateway est bien créée.

## API {#tabhead-api}


La commande `POST /compute/spaces/{spaceId}/internetGateways` crée une internet gateway que vous pouvez utiliser avec un VPC.

Une internet gateway permet aux VM lancées dans un réseau de se connecter à Internet. Elle permet le routage du trafic Internet entrant et sortant ainsi que la gestion des IP publiques.

[Exemple de requête : Création d'une internet gateway ↗](/openapi/#tag/compute/POST/compute/spaces/{spaceId}/internetGateways)
