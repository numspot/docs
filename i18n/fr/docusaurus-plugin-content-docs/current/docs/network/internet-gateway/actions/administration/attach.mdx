# Attacher une internet gateway à un VPC

Vous pouvez attacher une [internet gateway](/docs/network/internet-gateway/concepts/) à un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/) afin de connecter des [VM (Virtual Machine)](/docs/compute/concept/) dans un ou plusieurs subnet (sous-réseau) à Internet de manière directe grâce à une route dans leur [route table (table de routage)](/docs/network/route-table/concepts/), des règles de [security group (groupe de sécurité)](/docs/compute/security-groups/concepts/concept-sg/) et des IP (Internet Protocol) publiques (IP publique).

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.internetGateway.update**

:::

1. Connectez-vous sur la console Numspot.

2. Dans le menu de gauche, cliquez sur **Réseau** → **VPC** → **Internet Gateways**.


3. Identifiez l'internet gateway que vous souhaitez associer à un VPC, puis depuis la liste des actions, cliquez sur **Lier à un VPC**.


    Une nouvelle boîte de dialogue **Lier à un VPC** apparaît.


4. Sélectionnez le VPC à associer dans la liste proposée.

5. Cliquez sur **Lier**. L'internet gateway est liée au VPC.

    Un message de confirmation "Le VPC a bien été lié à l'Internet Gateway" apparaît.

## API {#tabhead-api}


La commande `PUT /compute/spaces/{spaceId}/internetGateways/{id}/vpcs/link` attache une internet gateway à un VPC.

Pour activer la connexion entre Internet et un VPC, vous devez attacher une internet gateway à ce VPC.

[Exemple de requête : Attacher une internet gateway à un VPC ↗](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/internetGateways/%7Bid%7D/vpcs/link)

La commande qui attache une internet gateway à un VPC retourne un code HTTP 204 NO CONTENT, indiquant que l'opération a été effectuée et qu'aucun contenu n'est renvoyé dans la réponse.
