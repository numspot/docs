# Associer une IP publique à une VM ou à une interface réseau

Vous pouvez associer une IP publique à une [VM (Virtual Machine)](/docs/compute/concept/) ou à une interface réseau dans un [VPC (Virtual Private Cloud)](/docs/network/vpc/concepts/).

L'IP publique sera liée à une NIC (Network Interface Card) de la VM (la NIC par défaut si aucune n'est précisée lors de la demande de liaison).

Vous pouvez également associer une IP publique à une [nat gateway (passerelle NAT)](/docs/network/nat/concepts/). Cependant, cette action n'est possible que lors de la création de la nat gateway.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.publicIp.update**

:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Public IP** ;
2. Sur la ligne de l'IP publique à associer, ouvrez le menu **Actions** ;
3. Cliquez sur **Associer à la VM** (ou **Associer à une NIC** pour l'associer à une carte d'interface réseau).

   Le panneau **Association à une VM** apparaît ;
4. Sélectionnez la VM à laquelle associer l'IP publique, puis cliquez sur **Associer à la VM**.

   L'IP publique est associée à la VM.

## API {#tabhead-api}


:::info
**Avant de commencer** : Pour associer une IP publique à une VM ou à une carte d'interface réseau (NIC) dans un VPC, assurez-vous que le VPC dispose d'une [internet gateway (passerelle Internet)](/docs/network/internet-gateway/concepts/) attachée.
:::

La commande `PUT /compute/spaces/{spaceId}/publicIps/{id}/link` associe une IP publique à une VM ou à une carte d'interface réseau (NIC) dans un VPC. Vous ne pouvez associer une IP publique qu'à une seule VM ou NIC à la fois. Pour associer une IP publique à un VPC, assurez-vous que le VPC a une internet gateway attachée. Par défaut, l'IP publique est dissociée de la VM à chaque arrêt et redémarrage de celle-ci.

:::warning
Vous pouvez associer une IP publique à un service de traduction d'adresses réseau (NAT - Network Address Translation) uniquement lors de la création de ce service. Pour modifier l'IP publique d'un service NAT, il est nécessaire de supprimer le service NAT existant et de le recréer avec la nouvelle IP publique.
:::

[Exemple de requête : Attacher une IP publique ↗](/openapi/#tag/compute/PUT/compute/spaces/%7BspaceId%7D/publicIps/%7Bid%7D/link)
