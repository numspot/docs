# Obtenir des informations sur vos Public IP

Vous pouvez obtenir des informations sur les **Public IP** (adresses IP publiques) allouées à votre compte.

Par défaut, cette action décrit toutes vos Public IP, qu'elles soient disponibles, associées à une **[VM](/docs/compute/concept/)** (Virtual Machine) ou à une interface réseau, ou utilisées pour une **[NAT Gateway](/docs/network/nat/concepts/)** (passerelle NAT).

Des informations sur vos Public IP sont également disponibles depuis les VM elles-mêmes.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.publicIp.get**

:::

## API {#tabhead-api}


La commande `GET /compute/spaces/{spaceId}/publicIps` permet de lister les Public IP.

[Exemple de requête : Lister toutes les Public IP](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/publicIps)

La commande `GET /compute/spaces/{spaceId}/publicIps/{id}` permet de récupérer les informations d'une Public IP.

[Exemple de requête : Récupérer les informations d'une Public IP](/openapi/#tag/compute/GET/compute/spaces/%7BspaceId%7D/publicIps/%7Bid%7D)
