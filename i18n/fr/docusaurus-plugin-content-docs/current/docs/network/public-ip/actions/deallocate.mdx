# Libérer une IP publique de votre compte

Vous pouvez libérer une IP publique allouée à votre compte si vous n'en avez plus besoin. Cette IP publique redevient disponible pour être allouée par un autre compte.

## Permissions

:::info
Cette action nécessite les permissions **IAM** (Identity and Access Management) suivantes :

- **compute.publicIp.delete**

:::

:::warning
La libération d'une IP publique est **définitive** : une fois libérée, elle ne pourra plus être réattribuée ni récupérée. Dissociez-la au préalable de toute ressource.
:::

1. Depuis le menu latéral gauche, cliquez sur **Réseau** → **Public IP** ;
2. Sur la ligne de l'IP publique à libérer, ouvrez le menu **Actions** ;
3. Cliquez sur **Libérer**.

   La boîte de dialogue **Libération d'une Public IP** apparaît ;
4. Une confirmation forte est nécessaire : saisissez le **nom** de l'IP publique dans le champ, puis cliquez sur **Libérer**.

## API {#tabhead-api}

:::info
### Avant de commencer

1.  Assurez-vous qu'aucune application ou script n'utilise l'IP publique que vous voulez libérer.
2.  Stoppez l'utilisation de l'IP publique par vos ressources :

- Détachez l'IP publique de toute **[VM](/docs/compute/concept/)** ou interface réseau.
- Supprimez toute [nat gateway (passerelle NAT)](/docs/network/nat/concepts/) à laquelle l'IP publique est associée.
:::

Vous ne pouvez libérer que les IP publiques associées à votre compte. La commande `DELETE /compute/spaces/{spaceId}/publicIps/{id}` libère une IP publique. Cette adresse est renvoyée dans le pool d'IP publiques et peut être réutilisée par une autre personne. Avant de libérer une IP publique, assurez-vous d'avoir mis à jour toutes les ressources communiquant avec cette adresse.

[Exemple de requête : Libérer une IP publique](/openapi/#tag/compute/DELETE/compute/spaces/%7BspaceId%7D/publicIps/%7Bid%7D)
