# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in the Numspot platform or in this
documentation site, please do **not** open a public issue or pull request.

Contact the [Numspot support](mailto:support-client@numspot.com) and describe:

- the affected component (website, API, console, …)
- the steps to reproduce the issue
- the potential impact

We acknowledge every report and keep the details confidential until the
vulnerability is fixed.

## Scope

- This repository contains documentation content only. Vulnerabilities in the
  Numspot platform (APIs, console, infrastructure) follow the same reporting
  path.
- Vulnerabilities in third-party dependencies of the site are also in scope —
  include the dependency name and version in your report.
